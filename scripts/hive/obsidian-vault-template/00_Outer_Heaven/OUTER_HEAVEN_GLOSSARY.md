# Outer Heaven glossary

Plain naming so agents do not confuse systems.

| Term | Means | Not |
|------|-------|-----|
| **Outer Heaven** | The multi-agent operator experience — Telegram topics + Grok Bot + shared hive canon | A separate GitHub product |
| **Philanthropy** | The tool API repo (`philanthropic-ai-agent`) — "hands" agents invoke | The Telegram UI or Scorpion |
| **OpenClaw** | Gateway runtime on VPS for Telegram agents | Grok Bot on Mac |
| **Grok Bot** | Mac-side 9-agent console (daily primary with Cursor) | Replacement for n8n or CE |
| **Big Boss** | Coordinator agent (Telegram + Grok) | The operator (Evens) |
| **Client Engine / CE** | Money desk at `/pro` | Scorpion, ProofCheck, AutoFlow |
| **Scorpion** | Ops brain / cockpit | Money OS or agent face |
| **n8n** | Automation bus on **evenslouis.ca/n8n only** | n8ncloud.tech (deprecated) |
| **Living library** | This vault folder + git mirror | A single infinite markdown file |
| **Chronicle** | Append-only save file (`CHRONICLE/`) | Deletable logs |
| **Survivors** | Human-approved patterns in `PATTERNS/SURVIVORS.md` | Raw chat dumps |
| **Tier 3 / HITL** | Operator-only: money, send, deploy, secrets | Agent auto-execute |

## Two agent faces (by design)

- **Daily:** Grok Bot + Cursor on Mac
- **Fallback / 24×7:** Telegram → OpenClaw → Philanthropy tools

Both read the same library via git mirror.
