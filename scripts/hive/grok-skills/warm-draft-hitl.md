# Warm draft + dual HITL

**Stack:** Cursor + Grok Bot. Communications drafts. HITL Operator owns the cards. Evens sends.

## When
Margin green (or CONDITIONAL with operator waiver) and a warm note is wanted. Named client after `four-blank-sku`. Not a cold blast. Not a Path C page.

## Owners
- Communications Manager — draft text
- HITL Operator — APPROVE DRAFT, then APPROVE SEND
- Consultant/GTM — constraint + CTA facts only
- Evens — both boxes, two sittings. Cursor never checks them.

## Steps
1. Confirm POSITION + SKU band exist. Missing → Consultant / `four-blank-sku`.
2. Draft **short** in **Evens voice** (plain, local, leak-first). Channel first: email vs LinkedIn.
3. First line = public FACT only (site leak, hours, mutual). No invented ops sigh.
4. CTA: 20-min constraint call and/or **public** proof. Speed-to-lead → Loom until public Vercel. Never `127.0.0.1` / `:3007` in send copy.
5. Strip educator/vendor $, hive internals (17-agent, CE, n8n), OF/farm/hustle voice.
6. HITL card 1 — **APPROVE DRAFT** (or deny = stop/revise). Do not check this box from Cursor.
7. Only after draft approve: send package. HITL card 2 — **APPROVE SEND**. Second sitting. Do not check both at once.
8. Evens sends from his inbox. Denial or expiry at either gate = stop. No “meanwhile” fan-out.
9. After a real send with no reply → `no-reply-follow-up` (still draft-only).
