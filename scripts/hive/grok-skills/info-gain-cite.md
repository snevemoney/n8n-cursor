# Info-gain cite

**Stack:** Cursor + Grok Bot. Julian Goldie course / Indexceptional / Claude writer = on tape only.

## Loop

one fresh question (lane we already operate) → one hands-on page on a surface we already own → HITL publish → ask Grok the question → note cite or miss

## Steps

1. **Pick** — Researcher: one question people just started asking in an operating lane. X explore or Grok “what is heating up” is a topic picker, not a hunt.
2. **Write** — Publishing: one page. Honest, hands-on, specific. Information gain from something we ran (proof, numbers we measured, screens we clicked). Not a generic AI rewrite of the SERP.
3. **Surface** — one channel we already own (`one-channel-deep`). No second site, Reddit thread, IG, or video farm for the same keyword.
4. **Publish** — HITL. No paid indexer SKU.
5. **Check** — Watchdog or Researcher asks Grok the same question. Cite = note. Miss = learn. Do not quote 24-hour first page as FACT.

## Never

Indexceptional / Indexational · rank-everywhere farm · Julian course / AI boardroom as a SKU · “3,700 businesses” / 24h #1 as proof · new `icp_id` · SEO agency lane · rotate hunt off Normand · Claude as the writer.
