# Slice build (funnel)

**Stack:** Cursor Agent (Forge) plans then implements. Grok Creative owns the bible.

## When
Any build larger than a one-file fix. Website page, game system, paid V1.

## Steps
1. **Bible first** (Creative): 4–6 colors / motion / light. Nothing enters without it. Cinematic lane → `cinematic-recipe`: 3 loved motion refs, taste on a strong model, hero = video not fake 3D (`CONTENT/website-building/cinematic/PLAYBOOK.md`).
2. **Plan turn** (Cursor): what and why. One system only. Write `api-macro-vision` LADDER if a browser/vision agent is in play.
3. **Implement turn** (Cursor): that system. Placeholders OK. Light does the heavy lift. Keys stay in env (`vault-not-prompt`).
4. **Verify:** `click-live-site` then `verify-after-browser` — open the shipped URL on the host path (Cursor → `cursor-ide-browser`; Grok Bot → Grok Bot web browser), click the CTA, write ACT / EXPECTED / OBSERVED / COMPARE / NEXT. Reject 70% done. "Looks good" without a click, or a click without OBSERVED = fail. Watchdog grades (`separate-verifier`).
5. Next session = next system. Not the rest of the product.

## Stop
Custom domain / Stripe / prod deploy → HITL + `paid-slice-funnel` smoke.

## Anti-patterns
- One prompt for the whole game/site
- Realistic meshes / cinematic one-shot
- Preview host as proof of production
- Skipping `click-live-site` after a page ship
- Selling "cinematic" as the offer (sell the outcome; recipe is delivery)
