# Slice build (funnel)

**Stack:** Cursor Agent (Forge) plans then implements. Grok Creative owns the bible.

## When
Any build larger than a one-file fix. Website page, game system, paid V1.

## Steps
1. **Bible first** (Creative): 4–6 colors / motion / light. Nothing enters without it.
2. **Plan turn** (Cursor): what and why. One system only.
3. **Implement turn** (Cursor): that system. Placeholders OK. Light does the heavy lift.
4. **Verify:** click paths, mobile, forms. Reject 70% done.
5. Next session = next system. Not the rest of the product.

## Stop
Custom domain / Stripe / prod deploy → HITL + `paid-slice-funnel` smoke.

## Anti-patterns
- One prompt for the whole game/site
- Realistic meshes / cinematic one-shot
- Preview host as proof of production
