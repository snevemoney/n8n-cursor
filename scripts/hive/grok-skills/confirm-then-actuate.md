# Confirm then actuate

**Alias of:** `ask-principal` — do not run a second doctrine. Load that file.

**Stack:** Cursor + Grok Bot. HITL owns the card. Evens actuates.

**Spine:** `send-removed` → `confirm-then-actuate` → `input-required-gate`. One HITL system.

## When
A draft, book slot, pay, deploy, or writeback is ready. Before anyone sends or books.

## Card (one string)
`ACTION / WHY / AGENT / RISK / REVERSIBILITY`

Roster `APPROVE` / `EDIT` / `REJECT` maps onto **ACTION**. No TARGET. No second schema.

## Steps
1. **Gather** — cheap research / draft / slot. Do not actuate.
2. **Escalate** — HITL posts the five-field card. `input-required-gate` so any instance can resume.
3. **Evens yes** — spoken, written, or box checked by Evens. Silence / expiry / Cursor-checked box = no.
4. **Then** send / book / deploy / writeback — Evens does the hard step. Desk resumes after.

## Stop
