# List-anneal funnel

**Stack:** Grok Lead Hunter + Cursor scripts. No second list vendor required.

## When
Need **volume** — many accounts for an ICP. Not a dial factory.

**Use `lead-web-find` instead** when you already have a named URL, or you want 1–5 owner-operator sites with a visible leak. Do not anneal 50 and also MUST-score all 50.

## Steps
1. Campaign brief: who + why (one ICP).
2. Pull a first **50**.
3. Score each: great / marginal / borderline. Target **60–70%** great.
   - Too high → you killed valid companies.
   - Too low → noise.
4. Agent proposes exclusion/inclusion changes. Operator accepts. Run again.
5. Nuance: “software” leaks agencies. Don’t exclude “marketing” if you want marketing **software**. Use funding, model, size.
6. After companies, find people (growth / head of growth).
7. Enrich only if needed. API keys as args — never hardcode.
8. Handoff: append “target market” line. Stop. Do not send.

## Stop
1. Pick **3–5** with leak + contact.
2. Each → `lead-web-find` (if leak not captured) → `prospect-must-score` → Path A in `website-offer-funnel`.
3. Outreach only after margin green: `outbound-playbook-funnel` + `warm-draft-hitl`.
No auto-dial. No send from this skill.

## Anti-patterns
- Installing a Claude Code lead-list CLI
- Instagram / OTP farms
- Skipping the score loop
- MUST-scoring the raw 50
- Treating anneal output as ready-to-send
