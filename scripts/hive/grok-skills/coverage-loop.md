## Funnel

**In:** a business-model row (from BUSINESS-MODEL-FIT) **or** a new YouTube tape. Channel / new YouTube URL as a *queue* → `channel-walk` (catalog → one uningested tape), then this loop on that packet.

**Stages:**

1. **Teach** — ingest transcript / packet, then study with `deep-video-learning` (A–K globally) + `multimodal-youtube-learning` (caption-honest). Captions only. Do not invent `full.txt` or click traces. If the input is a **channel**, run `channel-walk` for **one** tape first. Do not caption-dump the channel. Never steal first / skip the transcript. Do not re-walk the 82.
2. **Spawn** — 17 desks write independent A–L + Steal takes (`hive-spawn-desks --video-id`). **Parent launches.** This skill does not HTTP Grok Bot unless Evens asks. Do not spawn from this skill if desks are already walking.
3. **Extract** — steal machines vs operate-never payload, **informed by A–K**. Never “understand only, don’t steal.” Do not pre-vote Evens’s never-list.
4. **Atoms (layer 2)** — Researcher emits atoms into `knowledge/atoms/by-video/{id}.jsonl`. Speech≠behavior and sequences go to mismatches/behaviors. **Do not jump to a mega-workflow.** Patterns and compiled workflows are later slices (`workflow-compiler` only when Evens names a project).
5. **Capability + last-mile** — `capability-acquisition`: six extractions + THINK/BEHAVE/TRICKS/USE. If the procedure is **distinct** → write SKILL.md (3 places) + hive-funnels row + inventory (WIRED). Merge only when steps match (labeled dissent). **Remap-as-done forbidden.** Compile **one named workflow** for this tape (`workflow-compiler` + `knowledge-audit`). Reproduce card on owning desks. Do not clone the YouTuber. Not 147→1.
6. **Score** — update that model’s Our-now / Missing on BUSINESS-MODEL-FIT (and canvas data if safe). Set `can_complete_task` · `blocking_missing` · `last_loop`.
7. **Wire ONE system** — the named machine from this tape if it raises “can complete the task,” else the smallest existing funnel. Sequence, not dump. HITL spine already exists. Clients parked — do not wire a Path A send. Not a blend of the 146.
8. **Dry-run** — Paths A/B/C + case types against that model. Hard steps stay HITL (**draft only**).
9. **Loop** — only if the `checkable-stop` card is filled. Then pick next tape (`channel-walk` as a **new** iteration) or next lowest-coverage model. Cap is this session. Do not raise it.

**Out / hard step:** send, pay, deploy, book, publish stay Evens.
