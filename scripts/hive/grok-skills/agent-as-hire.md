# Agent as hire

**Stack:** Cursor + Grok Bot. Claude Code `/goal` is on tape only.

## Loop

onboard (context) → one small real task → review output → correct → expand scope → connect tools (gated) → score ROI

## Steps

1. **Talk** — `session-bootstrap`: goal, good/bad examples, boundaries, who you are, done-when.
2. **One SOP** — `interview-to-desk`: one recurring task you would actually use. Iterate until the output is usable. Do not stack connectors yet.
3. **Review** — operator or Watchdog rejects/fixes. Do not blind-accept.
4. **Connect** — only after the SOP works. Existing plugins only. Ask before write. Lead Hunter never Gmail. Send/pay/deploy stay HITL.
5. **Score** — hours or leads saved this month vs before. No job-loss % as FACT.
