## Steps

1. Write the PRD / spec first (`session-bootstrap` dump + done-when).
2. Interview: how much autonomy, loop steps, how we check, when to escalate. Default level 3.
3. Three files on disk: global rules · stricter factory rules · mission.md (goals **and** out-of-scope so the agent can **reject**).
4. Queue: one spec = one ticket. Labels = accepted / in progress / needs review. Cadence Evens names — `hosted-neq-scheduled` default no new host.
5. Builder (Forge) runs one bite. Hold-outs written **before** work; builder must not see them.
6. Validator is a **different** session (`separate-verifier`). Watchdog fills GRADE. Builder must not.
7. Priority each tick: fix open misses → review → next accepted → triage (accept / reject / split).
8. Name a deploy strategy (blue-green on-tape). **Evens flips.** Merge to preview ≠ prod. A queue that only opens PRs is a PR bot, not a factory.
9. Next SKU: read `primitives.json` first. Implement the contracts. Do not rebuild login / payments / social-share. After a ProofCheck bite, update the Path C offer surface (`PROMOTION.md`). Do not publish.
