# Outcome-offer funnel

**Stack:** Grok Consultant + Product GTM write the sentence. Publishing picks one channel. Cursor builds proof only after the sentence exists.

## When
New offer, new lane, or “what do we sell” as **marketing language**.

This is not Path A diagnosis:
- Their ops sigh → `constraint-position` (after MUST)
- Engagement scope → `four-blank-sku`
Write the sentence here; do not skip those two on a named client.

## Steps
1. Write the dental-clinic sentence:  
   `I help [ICP] get [numbered outcome] via [proof].`  
   Bad: “I do marketing with AI.”
2. Four-blank if scoping a build: Bucket / KPI / Baseline / 60-day win.
3. **Time-to-aha:** when does the user feel it? If it takes 3–5 generations, they churn.
4. Proof: walkthrough, before/after, testimonial — not a workflow screenshot.
5. **One channel deep.** Warm network before spray. Space posts; don’t stack.
6. Money Desk: count checkout + warm conversions. Quarantine YouTube $ claims.

## Stop
Publish / send / ads spend = HITL.  
Named client → `website-offer-funnel` Path A (MUST + margin + private-book).  
Volume list → Path B. Our page/Stripe → Path C.

## Anti-patterns
- “I do AI” positioning
- Strangers-pay-in-10-hours myth without receipts
- Mass-DM / account farms (same *shape* as multi-surface, different ethics)
