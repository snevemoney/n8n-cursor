# Four-blank SKU

**Stack:** Cursor + Grok Bot. Consultant + Product GTM write. Money Desk checks margin after.

## When
Path A named URL after `constraint-position`. Engagement scope — not the marketing sentence alone (`outcome-offer-funnel`) and not the ops sigh (`constraint-position`). Write all three.

## Steps
1. Write the dental-clinic sentence on the packet:  
   `I help [ICP] get [numbered outcome] via [proof].`  
   Bad: “I do AI.” Normand shape: 1 intake→book path via the public site read.
2. **Bucket** — ACQUIRE or CUT first. Not GROW.
3. **KPI** — **one** numbered metric (clock hours, count of live rails, booked slots). Not two unnumbered phrases.
4. **Baseline** — owner numbers only. TBD / HOLD once is allowed. Label UNVERIFIED. Do not invent a live form/phone count.
5. **60-day** — number N only if the packet has evidence. Else N = HOLD / UNVERIFIED. Rail items (1 CTA, 1 alert) may be numbered without inventing volume.
6. Map pattern → `usecase-to-sku`. Then `pricing-margin-roi-guardrails`.
7. Append or keep `HUNT_LOG.md` `stage=qualified` once MUST + these blanks exist.

## Stop
Send / pay / book / publish = operator. Draft stays in `warm-draft-hitl`.

Invent job $ or owner volume · quote tape/YouTube $ · two KPIs pretending to be one · skip UNVERIFIED · Claude Cowork/Code, Codex, ChatGPT, Gemini, Coda, Vapi, Abacus · operate farms.
