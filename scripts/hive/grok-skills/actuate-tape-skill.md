## Steps

1. Write the checkable-stop (`DONE-CHECK` · `CAP` · `COST`). Cap the machines. No 145 restamp. No live Stripe.
2. Factory pack **first** (`dark-factory`): PRD · interview (level 3) · global-rules · factory-rules · mission.md (in + out, may reject) · one ticket.
3. Watchdog writes **hidden hold-outs** before Forge codes. Forge must not paste those IDs into HTML comments.
4. Build the named bite. For Seedance: award refs + signature motion on the page · scroll maps to frame · CTA before scroll · unique CTA color · `prefers-reduced-motion` → poster. Stand-in stills from existing Higgsfield AE proof are allowed. Creative already owns Higgsfield — do not invent OAuth.
5. Write `SEEDANCE-NEXT.md` (or the equivalent later-step). Generate = **later**, named, not a refuse and not a fake clip.
6. **Pause.** Watchdog writes GRADE against the hold-outs. Fix-first if fail. Builder does not self-score in the HTML pass (`separate-verifier`).
7. Run the sibling machines as artifacts, not essays: beat graphic (`script-beat-motion`) · FDE gym (`forward-deployed-gap`) · handoff **draft** (`specialist-handoff`, send-removed) · Path C **offer page** (`checkout-in-one-sitting`, Stripe later).
