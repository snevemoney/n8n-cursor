# Clip factory

**Owner:** Publishing Engine. Pair with `one-channel-deep`. **Stack:** Cursor + Grok. Path C / creator-longform.

## When
A longform (podcast, walkthrough, tape) needs shorts/clips for HITL preview. Not a farm.

## Steps
1. Load `CONTENT/job-cards/takes/publishing-engine.md` then this skill.
2. Pick one source we ran or own. Cut a small pack (title, hook, file list). No new account.
3. Route assets through `one-channel-deep` — one destination.
4. Package for HITL preview. Creative Studio may cut; Publishing formats. Do not go live.

## Stop
Publish · schedule live · paid boost = operator.

## Never
- Publish or schedule across platforms
- Account farms / OTP / mass-DM
- A “how I make $85K” / RPM proof page
- Treat clipengine `beta` can-act as permission to publish
