# Transcript self-teach

**Stack:** Cursor + Grok. Captions only — not CHAPTERS, not the steal sheet, not last week’s roll-up.

**Scoreboard:** `docs/hive/outer-heaven/CONTENT/job-cards/LESSONS-FROM-TAPE.md`  
**Captions:** `~/.grokbot/research-packets/**/transcripts/{id}/full.txt` (+ `.vtt`)

## When

One new `full.txt` exists. Do not re-walk the old 18.

## Steps

1. **Read** the new `full.txt` (chunk if huge). Fetch captions first if missing. Skip = fail.
2. **Transcript said** — 4–8 sentences from the captions. This is a pointer, not a substitute for `full.txt`.
3. **17 takes** — INDEX order. Each desk writes 2–5 sentences only that desk would write. If two takes are interchangeable, rewrite.
4. **Roll-ups** — update skills / business / leverage / QoL / never only where something landed.
5. **Park** — learning ≠ hunt. Do not add an ICP or a `business-lanes.json` row.

## Never

Daily full-corpus re-read · brief VTT dump · auto-write every proposed `SKILL.md` · quote transcript $ / job-loss % as FACT · rotate off the live hunt because a video was interesting.
