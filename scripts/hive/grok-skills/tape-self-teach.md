# Transcript self-teach

**Stack:** Cursor + Grok. Captions only — not CHAPTERS, not the steal sheet, not the cursor-draft.

**Scoreboard shell:** `docs/hive/outer-heaven/CONTENT/job-cards/LESSONS-FROM-TAPE.md`  
**Canonical takes:** `docs/hive/outer-heaven/CONTENT/job-cards/takes/{slug}.md`  
**Not canonical:** `LESSONS-FROM-TAPE.cursor-draft.md`  
**Captions:** `~/.grokbot/research-packets/**/transcripts/{id}/full.txt` (+ `.vtt`)

Evens is the visionary. Desks cowork. Cursor does not pre-vote the never-list.

## When

One new `full.txt` exists. Do not re-walk the old 18 on a morning routine.

**Fleet walk (operator-ordered):** Evens says spawn the desks / tape walk in Cursor. Each desk writes **only** `CONTENT/job-cards/takes/{slug}.md`. Do not edit `LESSONS-FROM-TAPE.md` during the walk. Do not copy the cursor-draft. Do not flatten to CUT. Researcher + Librarian merge unique desk wording after Evens keeps.

**Default path (Cursor):** skill `hive-spawn-desks` — `python3 scripts/hive/cursor-spawn-desks.py --job tape-self-teach --write` then 17 `Task`s in this chat. Never Grok Bot.

**Optional (Grok):** `python3 scripts/hive/grokbot-dispatch-tape-self-teach.py` — only if Evens names Grok Bot.

## Steps

1. **Read** the new `full.txt` (chunk if huge). Fetch captions first if missing. Skip = fail. Ugly tapes stay in the room.
2. **Transcript said** — 4–8 sentences from the captions. This is a pointer, not a substitute for `full.txt`.
3. **Desk take** — 2–5 sentences only this desk would write. Steal the machine even from extreme tapes. Job card is the lens, not a muzzle.
4. **Roll-up** — skills / other business (parked) / leverage / QoL / one never. Never = what this desk will not **operate**, not what it will not look at.
5. **Park** — learning ≠ hunt. Do not add an ICP or a `business-lanes.json` row.

## Never

Daily full-corpus re-read · brief VTT dump · auto-write every proposed `SKILL.md` · quote transcript $ / job-loss % as FACT · rotate off the live hunt because a video was interesting · skip a tape because Cursor wrote CUT · operate farms / OTP / fake identity / mass-DM.
