# Paid-slice funnel

**Stack:** Grok Consultant/GTM names. Cursor Agent builds. Grok Watchdog attacks. Stripe/domain stay HITL.

## When
*Our* checkout or *our* custom domain. Not a client Cal.com install.

**Use `private-book-install` instead** when the job is their book button / intake (AI Partner Path A delivery).

## Steps
1. Pain you already know → literal name (one promise).
2. `session-bootstrap` dump, then `slice-build` one V1 (not the whole OS).
3. Auth + waitlist HTML first; kill waitlist when checkout works.
4. `.env` / webhook / host env — never commit keys.
5. **Dual smoke:** preview URL **and** custom domain. Watchdog lists release blockers.
6. **Aha:** user feels the result before 3–5 generations. If not, shrink the slice.
7. Monetize later is allowed. Receipts > YouTube income claims.

## Stop
Stripe live keys, domain DNS, prod deploy = operator only.

## Anti-patterns
- Codex / Abacus / other site-gen vendors
- “Preview works” = shipped
- Quoting unverified $ dashboards
