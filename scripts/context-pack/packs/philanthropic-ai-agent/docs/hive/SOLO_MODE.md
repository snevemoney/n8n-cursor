## Stack (from chats)

Next.js 14 + Prisma/Postgres + Qdrant + FastAPI embedder + OpenClaw gateway (`:18789`). Deploy path `/opt/philanthropy` on Hostinger VPS `69.62.66.78`.

Each agent workspace needs: `AGENTS.md`, `SOUL.md`, `TOOLS.md`, `IDENTITY.md`, `USER.md`, `HEARTBEAT.md`, `MEMORY.md` (+ DREAMS/BOOTSTRAP as used).

**Never wipe souls/topics or `openclaw.json` without explicit approval.** Append-only for BigBoss SOUL/TOOLS patches.
