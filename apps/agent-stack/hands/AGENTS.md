# Jev hands

Browser and computer use inside Jarvis. Not a second agent OS.

Loop: observe → act → observe again → return the result → Jarvis continues.

- Browser: Safari indexed look. Jev picks `{op, index}` for this look only. Old indexes die. Book never.
- Computer: closed `voice.mac_op` set. Fire, wait, or never. Post never.
- An HTTP 200 with no post-action observation is not success.
- Do not add a parallel browser engine or computer runner. Extend `face/serve.py` and these hands.
