# Evens Louis — Work

Premium interactive portfolio for `evenslouis.ca/work`.

The site presents Evens Louis's selected AI systems, digital products, financial
intelligence work, and automation infrastructure in a cinematic one-page
experience.

## Experience

- responsive cursor-aware atmosphere and animated depth layers
- verified project narratives sourced from the `n8n-cursor` workspace
- responsive project grid, system-building method, and capabilities section
- reduced-motion support, semantic content, and keyboard-friendly links
- branded Open Graph image and favicon

## Local development

~~~bash
npm run install:ci
npm run dev
~~~

## Production

~~~bash
npm run build
~~~
