## 📋 **Quick Start Guide**

### 1. **Switch to Interactive Setup**
In Cursor Background Agents:
- Choose **"Setup Machine Interactively"** (not Dockerfile)
- The environment will use the configuration in `.cursor/environment.json`

### 2. **Run Initial Setup**
Click the **"✅ Verify Setup"** terminal to confirm everything works.

### 3. **Generate Visuals**
Click **"🚀 Generate All Visuals"** to create diagrams and attempt screenshots.

### 4. **Enable Screenshots (Optional)**
Edit `.env` file with your real n8n credentials:
```env
N8N_BASE_URL=https://n8ncloud.tech
N8N_EMAIL=your-actual-email@example.com
N8N_PASSWORD=your-actual-password
```

## 🎯 **Available Commands**

### **Core Workflow Commands**
```bash
npm run gen          # Generate Mermaid diagrams + SVG exports
npm run watch        # Live file watcher (auto-updates)
npm run capture      # Screenshot n8n UI for all workflows
npm run refresh      # Full regeneration (gen + capture)
npm run sync         # Sync everything to GitHub
```

### **Chat → Workflow Pipeline**
```bash
npm run spec:validate <spec.yaml>    # Validate YAML specification
npm run spec:build <spec.yaml>       # Compile to n8n JSON
npm run explain <workflow.json>      # Generate human explanation
npm run import <workflow.json>       # Import to n8n (if available)
```
