# 🎨 Visual Debugging System - Complete Guide

Your n8n workflow system now includes professional visual debugging with Mermaid diagrams, SVG exports, and automated n8n UI screenshot capture.

## 🌟 What You Have

### ✅ Automatic Mermaid Diagrams
- **Rendered in Cursor** with proper `\`\`\`mermaid` code blocks
- **SVG exports** for crisp visuals in any application
- **GitHub-ready** diagrams that render everywhere
- **Live updates** via file watcher

### ✅ n8n UI Screenshots
- **Automated capture** of actual n8n editor interface
- **Side-by-side comparison** with Mermaid diagrams
- **Professional review docs** with checklists
- **Cross-device accessibility** via GitHub

### ✅ Complete Chat → Visual Loop
1. **Chat** → YAML spec generated by Cursor
2. **Validate** → `npm run spec:validate`  
3. **Compile** → `npm run spec:build` (creates JSON)
4. **Visualize** → `npm run gen` (creates Mermaid + SVG)
5. **Capture** → `npm run capture` (creates n8n screenshots)
6. **Review** → automated comparison docs
7. **Iterate** → Cursor fixes based on visual feedback

## 🛠️ Available Commands

### Core Workflow Management
```bash
npm run gen          # Generate Mermaid diagrams + SVG exports
npm run watch        # Live file watcher (auto-updates)
npm run capture      # Screenshot n8n UI for all workflows
npm run refresh      # Full regeneration (gen + capture)
npm run sync         # Sync everything to GitHub
```

### Chat → Workflow Pipeline
```bash
npm run spec:validate <spec.yaml>    # Validate YAML specification
npm run spec:build <spec.yaml>       # Compile to n8n JSON
npm run explain <workflow.json>      # Generate human explanation
npm run import <workflow.json>       # Import to n8n (if available)
```

## 🎯 Usage Examples

### 1. Create Workflow from Chat

**Step 1: Generate YAML Spec**
- Open `ai/prompts/chat-to-spec.md` in Cursor
- Describe: "Create a webhook that validates email addresses and sends to CRM"
- Cursor generates YAML spec

**Step 2: Build & Visualize**
```bash
# Save Cursor's output as ai/specs/email-validator.yaml
npm run spec:validate ai/specs/email-validator.yaml
npm run spec:build ai/specs/email-validator.yaml
npm run gen  # Creates Mermaid diagram + SVG
```

**Step 3: Review & Iterate**
- Check `visualizations/email_validator.md` for Mermaid diagram
- View `visualizations/email_validator.svg` for crisp export
- Make changes to YAML spec and repeat

### 2. Visual Debug Existing Workflows

**Step 1: Generate All Visuals**
```bash
npm run refresh  # Creates diagrams + attempts n8n screenshots
```

**Step 2: Review Results**
- Check `visualizations/index.md` for overview
- Open individual `*.md` files for workflow details
- Compare `*.svg` exports with n8n UI (if captured)

**Step 3: Create Review Session**
```bash
# Set credentials for n8n screenshot capture
export N8N_BASE_URL="https://n8ncloud.tech"
export N8N_EMAIL="your-email@example.com"
export N8N_PASSWORD="your-password"

npm run capture  # Generates review docs in visualizations/reviews/
```

### 3. Complete Visual Loop

**Scenario:** "Fix the AI SaaS workflow - it's not handling errors properly"

1. **Analyze Current State**
   ```bash
   npm run refresh
   # View visualizations/ai-saas-master-scaffold.md
   # Check visualizations/reviews/<timestamp>-review.md
   ```

2. **Create Improved Spec**
   - Chat with Cursor: "Add error handling to the AI SaaS workflow"
   - Save as `ai/specs/ai-saas-v2.yaml`

3. **Build & Compare**
   ```bash
   npm run spec:build ai/specs/ai-saas-v2.yaml
   npm run gen
   # Compare old vs new in visualizations/
   ```

4. **Deploy & Verify**
   ```bash
   npm run import workflows/ai_saas_v2.json  # Import to n8n
   npm run capture  # Screenshot the deployed version
   npm run sync     # Commit to GitHub
   ```

## 🔧 Troubleshooting

### Mermaid Not Rendering in Cursor
1. Install "Markdown Preview Mermaid Support" extension
2. Enable in Settings: Markdown › Preview: Mermaid  
3. Use Cmd+Shift+V to preview Markdown

### SVG Generation Failing
```bash
# Check Puppeteer dependencies
sudo apt-get install libatk1.0-0t64 libgtk-3-0t64 libnss3

# Test manual generation
npx mmdc -i test.mmd -o test.svg --no-sandbox
```

### n8n Screenshot Issues
- Verify N8N_EMAIL/N8N_PASSWORD environment variables
- Check n8n URL accessibility  
- Update selectors in `tools/capture.js` for custom themes
