### **1. Port Management**
```bash

SYSTEM_N8N_PORT=5678      # System service
DOCKER_N8N_PORT=15678     # Docker service
DOCKER_PROXY_PORT=15680   # Proxy service
STATUS_PORT=15682         # Status monitoring
MONITORING_PORT=15683     # Real-time monitoring
BACKUP_PORT=15684         # Backup operations
```

### **2. Health Monitoring**
```bash
# Health scoring system
HEALTH_THRESHOLD=3        # Minimum acceptable health
RECOVERY_ATTEMPTS=3       # Max recovery attempts
MAX_FAILURE_COUNT=5       # Max consecutive failures
```

### **3. Backup Strategy**
```bash
# Multi-layer backup
PRIMARY_BACKUP="Full system state"
SECONDARY_BACKUP="Running state and logs"
CLOUD_BACKUP="Critical configurations"
RETENTION_DAYS=30         # Backup retention period
```

### **4. Integrity Validation**
```bash

    "nginx-smart.conf"
```
