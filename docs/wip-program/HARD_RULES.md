# Evenslouis hard rules (all WIP phases)

Canonical program: fused 20-phase WIP plan (artifact). Code registries: `packages/shared-config/src/repo-registry.ts`, `product-registry.ts`.

1. **One money OS** — Client Engine (`/pro`) only  
2. **One agent face** — OpenClaw / Telegram Outer Heaven  
3. **One ops cockpit** — Scorpion (`/scorpion`)  
4. **One Lightning story** — monorepo `apps/lightningflow` parked at `/lightningflow`  
5. **One emergency brand** — SENTINEL (`shield-buddies`)  
6. **One stream clipper** — ClipEngine (≠ Bookflix, ≠ `#creator`)  
7. Product candidates use **own domains** — no new apex product paths on `evenslouis.ca` until launch decision  
8. Never wipe OpenClaw souls/topics or `n8n_data` volumes  
9. Never put basic_auth on n8n webhooks or `/claw/hooks*`  
10. Never feature LightningFlow or operator tools on the public portfolio hero  
11. **HITL always** for: spend · client send · prod deploy · delete data · secrets · `openclaw.json`  
12. Future repos default **`side_wip` + `NO_PATH`** until promotion PR updates the registry  
13. One MCP **broker** holds secrets — agents do not each store every API key  
14. Public story = `/` + `/work` only for visitors
