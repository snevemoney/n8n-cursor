# Prospect qualification criteria (AI Partner / Money Desk)
**Date:** 2026-08-12 · **Owner:** Money Desk (+ GTM / Lead Hunter / Consultant)  
**Purpose:** Only advance prospects where need + our delivery capability + low execution risk line up.  
**Rule:** Public web / Grok-native first. No CE required. No client send without HITL.

Label: **MUST** = hard gate · **SHOULD** = strong preference · **NICE** = bonus

---

## A) What they need / want (problem fit)

### MUST
1. **Clear constraint we can name in one sentence** (e.g. “inquiries don’t become booked calls”).
2. **Outcome bucket fits our ladder:** ACQUIRE (leads→booked) and/or CUT (hours/errors), not “build me an empire / run my ads.”
3. **Evidence of demand leakage or admin pain** on public surfaces (broken CTA, email-only, no booking, manual apply, slow reply signals) — or owner confirms on a short call.
4. **Owner-operator buyer** (or ops manager with budget authority) — not enterprise committee as first deal.

### SHOULD
5. Already paying for tools / coaches / software (they’re in market).
6. Scarcity or capacity language (“select few,” booked out, waitlist) without a clean intake path.
7. Local/service business or solo expert where calendar + trust matter more than brand redesign.

### DISQUALIFY (need side)
- Wants cold DM / ads agency / “10x revenue guarantee”
- Pure brand/website vanity with no booking/revenue path
- Needs licensed clinical/legal/financial advice we don’t deliver
- Wants us to replace their whole team in week one

---

## B) What we can deliver (capability fit)

### In scope (default first offer — Rung 0–1)
| We can deliver cleanly | Examples |
|------------------------|----------|
| Booking / intake path | Calendar link, apply→qualify→book, SMS/email alert to owner |
| CTA / funnel fix on existing site | Squarespace/WordPress/Webflow light changes — not full redesign |
| HITL messaging assists | Drafts + operator approve before send |
| Short audit / diagnosis | Constraint brief + ROI blanks + recommended install |
| Light automation | Forms, reminders, triage rules — **not** custom SaaS |

### Out of scope for first deal (park / later)
- Custom app / Client Engine / 17-agent hive pitch
- Paid media management
- Full brand + site rebuild
- Autonomous client messaging or money moves
- Anything needing prod deploy / secrets without Tier 3

### MUST (capability)
8. **Delivery fits ≤ ~40% of fee** in time/tools (margin guardrail).
9. **DONE_WHEN is observable in ≤60 days** (e.g. booking live + reply SLA + N intros tracked).
10. **Forge only if scope expands** past install — default is workflow/config, not engineering project.
11. **First-ask band:** CAD ~$750–1.2K (Rung 0) or ~$1.5–3.5K (Rung 1). Higher only with verified volume.

---

## C) Deliver without issues (risk / access / ops)

### MUST
12. **Public contact path exists** we can use after HITL (email, form, IG) — not only a dead `mailto:null` with no fallback.
13. **Reversible first step** (15-min diagnosis / sandbox CTA) — no irreversible rebuild.
14. **Human risk acceptable:** owner won’t require us to hide the change from a hostile partner; “select few” brand compatible with booking (or we design private apply→book).
15. **No Tier-3 landmines in v1** (no payment processor rebuild, no medical records, no prod infra).
16. **Single throat to choke** — one owner to approve scope; not 5 stakeholders for a $2K job.
17. **Data/access:** we can work with screenshots + their existing site/tools; no waiting months on IT.

### SHOULD
18. Timezone / language workable for Evens (Atlantic/Eastern/near).
19. Social proof surface (IG/Google/LinkedIn) so warm note isn’t totally cold.
20. Cart/commerce or package prices visible → easier ROI math.

### DISQUALIFY (delivery risk)
- Only path is spammy cold call / bought lists
- Requires regulated PHI/PCI we aren’t set up for
- Owner wants “set and forget chatbot that closes sales” with no HITL
- Scope keeps expanding past margin guardrail before kickoff

---

## D) Economics (Money Desk)

### MUST before APPROVE send
21. **Four blanks drafted:** Bucket · KPI · Baseline (known or explicitly TBD) · 60-day target  
22. **Pain $ narrative labeled UNVERIFIED** until owner numbers  
23. **Price ≤ ~10–20% of plausible annualized pain** only if volume confirmed; else fixed Rung 0–1 band  
24. **Cash path clear:** invoice/deposit expectations; no free custom build

### Score (quick)
Score each MUST 0/1. **Advance only if all MUSTs = 1** (or explicit operator waiver).  
SHOULD: aim ≥5/8. NICE: bonus.

---

## E) Gate sequence (who does what)

1. **Lead Hunter** — web find; fill A + C evidence (URL, contact path, constraint sentence)  
2. **Researcher** — FACT pack; no outreach  
3. **Consultant** — POSITION (constraint, adoption risk, reversible step)  
4. **Product GTM** — four blanks + SKU inside bands  
5. **Money Desk** — margin / pain / price challenge  
6. **HITL / operator** — APPROVE draft → second HITL before actual send  
7. **Forge** — only after greenlight if build exceeds install
