## 1) One ladder (CAD) — Money Desk SoT

| Rung | Name | Band | Sell when | Default delivery | Walk when |
|------|------|------|-----------|------------------|-----------|

## 2) Scoring (Consultant + Researcher) — before SKU

1. **MUST binary** all = 1 (or operator waiver). Else STOP / HOLD / DQ.  
2. **Scorecard only after MUSTs** (0–100): constraint · ICP · readiness · budget · access · #14 brand.  
3. **Advance:** 80–100 → POSITION→SKU · 60–79 → diagnosis/Rung 0 or HOLD · <60 → walk/DQ.

Full table: Consultant half §1.

## 3) POSITION (Consultant) — before any propose

**CE steal:** no proposal without positioning. Felt problem ≠ stated ask.

**POSITION pack (every prospect):** stated ask · felt constraint · leakage evidence · adoption risks · #14 brand fit · recommended path (diagnosis / R0 / R1 / HOLD / DQ) · discovery question gating Rung 1 · reversible next step (no build language).

| Pattern | Bias |
|---------|------|
| Broken rails (404 / dead mailto / no book) | Rung **1** after MUSTs |
| Working slow premium SLA | **Rung 0 / diagnosis** until ops sigh |
| No usable contact / committee for micro-fee | DISQUALIFY (or paid audit w/ champion) |

---

## 4) SKU packaging (Product GTM) — after POSITION

1. Four blanks: Bucket · KPI · Baseline · 60-day (Baseline may be TBD once).  
2. Bucket first: ACQUIRE / CUT (GROW later).  
3. Shrink scope, not price.  
4. Pain-% only with verified volume; else fixed band.  
5. Private apply→book for premium; loud Book free only when brand fits.  
6. Diagnosis before install when SLA may be intentional.  
7. **Proofs (public):** cinematic · MCP · Speed-to-Lead when public — never localhost in client drafts.  
8. **PASS delivery:** Cal.com/Calendly · Typeform/Tally · site CTA · alert · private book · reminders · Loom.  
9. **FAIL first ask:** custom Next · CE/hive · redesign · ads · autonomous send.
