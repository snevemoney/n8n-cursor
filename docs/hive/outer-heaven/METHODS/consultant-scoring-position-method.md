## 1) Scoring method (Consultant + Researcher)

### Gate 0 — MUST binary
All hive MUSTs = 1 (or operator waiver). Else STOP / HOLD / DISQUALIFY.  
Scorecard (0–100) runs **only after** MUSTs pass.

### Post-MUST scorecard (BANT-fit for $750–3.5K owner deals)
| Dimension | Points | What good looks like |
|-----------|--------|---------------------|
| Constraint clarity | 0–20 | One sentence + public leak evidence |
| ICP / buyer | 0–20 | Owner-operator / single throat; already pays tools |
| Readiness / timeline | 0–15 | Pain active; ≤60d fix appetite |
| Budget signals | 0–15 | Can approve first-ask band without committee |
| Access / risk | 0–15 | Usable contact; reversible; no PHI/PCI landmine |
| Brand / #14 fit | 0–15 | Private vs public book call is clear |

**Advance bands**
- **80–100** → write POSITION → GTM SKU (still HITL)
- **60–79** → discovery / Rung 0 diagnosis path, or HOLD
- **<60** or any MUST=0 → walk / nurture / DISQUALIFY

Researcher owns FACT table; Consultant owns advance/HOLD call on constraint + brand fit.

## 2) POSITION method (before any SKU)

**CE axiom we steal:** no proposal without positioning. Felt problem ≠ stated ask.

### POSITION pack fields (every prospect)
1. **Stated ask** (what they would request)
2. **Felt problem / constraint** — one sentence where ops sighs (or **UNVERIFIED**)
3. **Leakage evidence** — URL facts (404, mailto:null, form+SLA, no calendar…)
4. **Adoption risks** — tool loyalty, committee, intentional scarcity, brand
5. **#14 brand fit** — PASS only with private apply→qualify→book when premium/confidential
6. **Recommended first path** — diagnosis / Rung 0 / Rung 1 / HOLD / DQ (XOR first-ask; never stack 0+1)
7. **Discovery question** that gates Rung 1 (chase pain vs intentional SLA)
8. **Reversible next step** for operator (warm ask / call / park) — no build language

### Patterns → path (aligns with GTM use-case table)
| Pattern | Consultant bias |
|---------|-----------------|
| Broken rails (404 / dead mailto / no book) | Rung **1** candidate after MUSTs |
| Working slow premium SLA | **Rung 0 / diagnosis** until ops sigh confirmed |
| No usable contact | DISQUALIFY |
| Committee for micro-fee | DISQUALIFY or paid audit w/ champion |

### Anti-patterns
- Feature-list offers
- Default Calendly/install on intentional premium brands
- Inventing volume / pain $
- Competing ladder bands (Money Desk wins CAD)
- Quoting educator **$3–10K/mo** retainer as our early default (**UNVERIFIED** stretch only)
