## What you asked

- 1.	Install BlackHole 2ch. Easiest via Terminal: brew install blackhole-2ch — or download the installer from Existential Audio’s site. Restart isn’t usually needed.
	2.	Open Audio MIDI Setup (Applications → Utilities → Audio MIDI Setup).
	3.	Create a Multi-Output Device so you still hear your music while it’s routed: click the + at bottom-left → Create Multi-Output Device. In the right pane, check both your real output (MacBook Speakers or your headphones) and BlackHole 2ch.
	4.	Set your real output as the master/clock in that Multi-Output Device (top of the device list), and tick Drift Correct
