# Intro psychology: method first, then biology, then named subfields (clustered)

**Use when:** a task asks how to **place a psychology intro question** in the Saylor PSYCH101 school — history/method, gene-environment, biological systems, or which live subfield owns the phenomenon.

**Do not use when:** SOC101; POLSC*; PHIL102 logic; ENGL; sitting ACE SAYA-0007; exam reconstruction.

This is **one** skill. Eleven live units, one argument: **most students already have a disorders / pop-psych story; this course's pass is scientific psychology — foundations and biology first, then named subfields, including I/O and health/stress that the five-CLO list under-names.**

### Check B — Foundations (Unit 1)

History of the field. Scientific method + research methodology + types of analysis. Before disorders.

### Check C — Biology (Unit 2 + CLOs 3–4)

Nature vs nurture → **gene-environment interaction**. Major biological systems studied in psychology.

### Check D — Core subfields (Units 3–8)

Sensation ≠ perception. Learning ≠ cognitive. Development. Motivation/emotion/personality. Clinical / psychopathology. CLO 5's compare-list lives here plus Unit 5/7.

### Check E — Social, work, health (Units 9–11)

Social psychology. I/O. Health and stress. Do not drop 10–11 because CLO 5 is shorter.

### Check F — ACE

SAYA-0007 is real. Encode it. **Do not sit.** Free 70% cert ≠ ACE transcript.
