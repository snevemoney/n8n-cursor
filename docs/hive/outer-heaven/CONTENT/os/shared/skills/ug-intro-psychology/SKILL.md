# Intro sociology: imagination first, then method, then institutions (clustered)

**Use when:** a task asks how to **place a sociology intro question** in the Saylor SOC101 school — what sociology is, which of the three perspectives, how research is done, or how imagination maps a trouble onto culture/groups/stratification/institutions/change.

**Do not use when:** PSYCH101 mind/behavior; POLSC* as government; HIST103 dates; ENGL; exam reconstruction.

This is **one** skill. Seven live units, one argument: **most students already have a psychology or a hot-take story; this course's pass is society as system — imagination connects biography to structure, then three perspectives, then named seats.**

## 0. Hygiene

- Label **school**. Undergraduate **introduction to sociology** (Saylor SOC101). **31 h / 3.1 CEU.** LMS **742** (`/course/soc101`). ACE **N** — do not invent SAYA. Cert **70% / 14-day / max 3**. Syllabus **2025-10-03 15:31**. No guest-visible textbook.
- Seven **live** units. Eight **live** CLOs.
- Spine: **sociological imagination** (personal experience ↔ larger social issues).

## 1. Procedure — six checks

### Check A — Identity

| Prompt smells like | Hand off |
|---|---|
| Mind, disorders, subfields of psychology | **PSYCH101** |
| US government / comparative politics | **POLSC*** |
| Take the final | **refuse** |
| Personal trouble as public issue / institution / inequality | **this skill** |

### Check B — What it is (Unit 1)

Define sociology and its purpose. Imagination/perspective. Three perspectives: **functionalism, conflict theory, symbolic interactionism**.

### Check C — Method (Unit 2)

Qualitative vs quantitative data collection and analysis. Sociology *uses* methods; it is not PSYCH101's scientific-method unit as this map.

### Check D — Culture and groups (Units 3–4)

Culture. Socialization, groups, social control. Power of groups over individual behavior.

### Check E — Stratification and institutions (Units 5–6)

Stratification (income, gender, race, ethnicity, aging). Phenomena: racism, sexism, deviance. Institutions: family, media, education, economics, politics (plus culture/socialization as listed in CLO 5).

### Check F — Change (Unit 7)

Apply concepts to observable events and social issues. Social change.

- Qual = quant.
- Institutions as civics.
- ACE invented (catalog residue is not live SAYA).
- PSYCH101 social psychology reused for groups.
- ENGL collision.

## 3. Refuse

Exam reconstruction; inventing SAYA; sitting the final; ENGL harvest.

## 4. Adjacent

PSYCH101, POLSC*, HIST103, ACE sitting (none).

## 5. Output shape

1. Name the school (SOC101 intro sociology) and what it is not.
2. Name the **unit seat**.
3. If a person is in the prompt: run **imagination** (biography ↔ structure).
4. If a theory: name **one of the three**. Do not sit the final.
