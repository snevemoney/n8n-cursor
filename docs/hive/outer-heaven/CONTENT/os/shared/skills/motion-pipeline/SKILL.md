## Code-film engine (`seek(t)`) — full study 2026-10-10 (VERIFIED on box)
Source cluster (X, Sep 25–Oct 6): @RaphaelAubryy article + repo, @twoclipping "$10K launch videos" article (XML spec prompts), @0xMovez 12-step course, @rexan_wong / @ArchiveExplorer reference→renderer→components→storyboard pipeline, @RoundtableSpace motion-video-kit, @0xCodila / @0xMovez prompt sheets. Packet: `/workspace/research/packets/signals-2wk-fullstudy-20261010/`.
**What actually works (the "one prompt" captions hide this):** the prompt is ~10% of the film; the harness is the rest.
1. **Engine:** one HTML file exposing `window.seek(t)` — every style is a pure function of `t` (no CSS transitions, no timers, no state across frames). Playwright calls `seek`, screenshots `#stage`, ffmpeg encodes. Deterministic → a fix is a one-line edit + re-render of the changed seconds.
2. **Springs:** closed-form damped step `1 - e^(-zωτ)(cos ω_dτ + (zω/ω_d) sin ω_dτ)` (f≈3, z≈0.6); a value with several targets = sum of one spring per change. Lets you render frame 812 without simulating 0–811.
3. **Motion blur:** N subframes per frame (8 for fast moves; 4 ghosts) → `ffmpeg -framerate FPS*N … -vf "tmix=frames=N,select='eq(mod(n\,N)\,N-1)',setpts=N/FPS/TB"`. Cost ≈1–1.5 min render per film-second at 8 subframes. Never blend across a hard cut.
4. **Flow:** inputs (brand, real screenshots, song, format) → beat map (every scene on a beat, drop on the key visual) → **4 stills approved** → draft (540p) → full render → pop scan + frozen-time scan → audio → mux.
5. **Audio:** never trust an auto beat grid — find the drop by low-band energy bar by bar, then 20 ms windows; place each SFX by its *measured peak*; two-pass loudnorm to −14 LUFS. Real downloaded SFX (Mixkit), not synthesized, for product films.
6. **Self-critique:** contact sheet at 2 fps + 12-frame strip around each fast move + 360-px phone sheet; score hook/readability/motion/variety/composition/data accuracy/sound sync 1–10; fix top 3 with timestamps; repeat until all ≥8. Builder ≠ judge for client work (motion-video-kit "Gauntlet": fresh critic each round, ledger).
7. **Anti-"AI look" defaults:** without a reference Opus does centered text + gradient + fade-ins. Name a style / give 1–2 reference films (grammar not content); 2D warm-white minimal beats dark 3D; nothing fades — shapes morph; one camera move at a time; something on every beat.
8. **Honesty:** illustrative numbers labelled "Example data"; only real integrations on screen; captions true ("made in 10 min" gets checked).
**Spec-prompt skeleton (twoclipping/verbove):** `<inputs>` (what to ask for + defaults) · `<direction>` (look, palette hex, fonts, banned list) · `<structure>` (BPM, beats → states) · `<build>` (seek(t), springs, subframes, peaks) · `<gotchas>` · `<start>` (ask inputs, show beat map + 4 stills before full film).
