# Marketing pattern block

## When

## Do
1. Add a short block: homepage promise, Google snippet if visible, IG cadence/visuals, private vs loud brand.
2. Language for POSITION / talk track only.
3. ACQUIRE first remains inquire to book. Not an ads SKU.
