# Professional writing: purpose, audience, channel, polish (clustered)

**Use when:** a workplace writing task needs **purpose among major genres**, **audience/context**, a **chosen channel**, **ethics**, and **revision** — Saylor PRDV002, 12 h adult-learner professional writing.

**Do not use when:** reconstructing exams; **PRDV010** evaluating sources/references; **PRDV009** grant proposals; **PRDV102** resumes (and never *send* employment email); **PRDV008** presentations as a *course*; **ENGL*** composition (Publishing); promising ACE; inventing a graduate writing twin.

This is **one** skill. Four live units are one loop: **know purpose → know audience and channel → draft → polish.**

## 0. Hygiene

- School: **PRDV professional writing** (Saylor PRDV002). LMS **729**. **12 h / 1.2 CEU**. **70%**; **14-day**; **max 3**. ACE **N**. Not a degree course. Not ENGL101.
- Claim vs data: units not opened; no guest textbook; stale SNLS 3-unit / 7-day **do not encode**.
- Channels named live: blogs, contracts, emails, reports, presentations, press releases, social media posts. Collaborative team environment.
- No exam items. Summarize OER. Do not dump. **Do not send** the document — HITL if it would go to an employer or client.

## 1. Checks

**A Identity.** Workplace professional writing in print/digital? This skill. Sources/citations as the *course* → PRDV010. Grant → PRDV009. Resume → PRDV102. Slide-deck as a course → PRDV008. Essay/comp → ENGL (not this desk).

**B Purpose / genre (CLO 1, Unit 1).** Identify the purpose among major genres of professional writing.

**C Audience and channel (CLO 2–3, Unit 2).** Adapt to contexts and audiences. Combine audience + purpose to write **through a chosen channel**.

**D Draft + ethics (CLO 4, Unit 3).** Draft the message. Explain how to avoid **common ethical problems** in professional writing.

**E Polish (CLO 5, Unit 4).** Editorial strategies for revising and improving. Edit and proofread so it is polished, competent, professional.

## 2. Patterns (shape only)

**"Need a note to the vendor that we will miss Friday."**
A (workplace) → B (purpose: inform + next step) → C (vendor; email) → D (accurate, no blame-shift ethics) → E (short polish). Not a grant. Not ENGL.

**"Blog vs press release for the same launch."**
C (channel + audience). Same purpose, different channel.
