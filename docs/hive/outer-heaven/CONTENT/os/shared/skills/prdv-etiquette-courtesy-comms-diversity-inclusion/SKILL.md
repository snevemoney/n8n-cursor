# Workplace etiquette: courtesy, communication, inclusion (clustered)

**Use when:** a prompt needs **workplace etiquette** — manners/respect/ethics, verbal and nonverbal (and virtual as overlay) communication, and cultural difference / inclusion as a *school CLO* about employer competitive edge — in the Saylor PRDV104 **Professional Etiquette** school (6 h). **Never send.**

**Do not use when:** reconstructing exams; **PRDV102** résumé; **PRDV103** interview; **PRDV008** presentations; **PRDV211** foundations of human communication; **PRDV212** interpersonal; **PRDV213–215** group/org/mass; **SOC101** (Creative — do not write that packet); promising ACE; **sending** a note; writing operator HR policy; treating this as BUS OB.

This is **one** skill. Three live units, three CLOs. Loop: **courtesy/ethics → communication (verbal/nonverbal + virtual overlay) → diversity/inclusion as competitive-edge claim.** Do not mint a fourth CLO for virtual.

## 1. Procedure — six checks

Run in order. Stop if Check A says another school or send.

### Check A — Identity overlay (always)

| Prompt smells like | Hand off |
|---|---|
| "Fix the résumé / cover letter" | **PRDV102** |
| "Prep / sit / follow up an interview" | **PRDV103** |
| "Stand up and give the talk" | **PRDV008** |
| "What is communication as a survey" | **PRDV211** (and 212–215 as named) |
| "Sociology / intro society" | **SOC101** (Creative — leave) |
| "Workplace manners, mixed-channel comms, cultural difference at work" | **this skill** |
| "Send this note / post this" | **HITL — refuse send** |

**Primary goal:** navigate common workplace obstacles with courtesy, clear communication, and cultural awareness. Named failure mode: sending, lecturing DEI as policy, or turning Unit 2 into a speech course.

### Check B — Courtesy, respect, ethics (when "that's rude / what's the protocol" is in play)

CLO 1. Unit 1.

**Describe how courtesy, respect, and ethics contribute to a positive work environment.** Live intro: professional manners, respect, common courtesy.

Shape: name the obstacle (personality clash, slight, ethics pinch), then the courtesy/respect/ethics move that keeps the environment workable. Do not write a employee handbook. Do not send an apology email from this skill.

### Check C — Verbal and nonverbal (when "how do I say it / they can't see me" is in play)

CLO 2. Unit 2.

**Describe factors that should be considered for effective verbal and non-verbal communication.** Live intro also names **virtual** techniques — overlay on this check, not a fourth CLO.

Shape: channel first (in person, voice, virtual), then verbal vs nonverbal factors (tone, body, timing, what the other person can actually see/hear). Hand **PRDV008** if they need to *deliver a presentation*. Hand **PRDV211/212** if they want communication *as a survey*. Stay here for workplace etiquette of the exchange.

### Check D — Diversity / inclusion CLO (when "culture / inclusion / who is in the room" is in play)

CLO 3. Unit 3.

**Explain how diversity and inclusion in the workplace foster a competitive edge for employers.** Live intro: respond to and respect cultural differences to create a friendlier, more inclusive workplace.

Shape: encode the school's *competitive-edge* claim as a CLO, plus respect/response as the intro job. Do not write SOC101. Do not invent operator DEI policy. Do not treat cultural difference as a problem to erase.

### Check E — Obstacle routing (when "this meeting is a mess" is in play)

Named obstacles: conflicting personalities, miscommunication, cultural differences. Route: personality → B; miscommunication → C; cultural difference → D. Mixed: B then C then D, do not skip to a send.

### Check F — Send / adjacent courses

Drafted etiquette advice is still **not send**. Interview thank-you is PRDV103 follow-up, still HITL. Crisis comms is PRDV107 (later). Do not auto-promote.
