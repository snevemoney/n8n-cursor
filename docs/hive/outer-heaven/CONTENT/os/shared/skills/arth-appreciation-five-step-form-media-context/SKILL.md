# Art appreciation: five steps, then form, medium, theme, time (clustered)

**Use when:** a task asks how to **look at a work of visual art** in the Saylor ARTH101 **undergraduate art appreciation** school — what it physically is, how form is arranged, what medium/process made it, what it means at which level, which worldly or otherworldly theme it examines, or (only then) which Western or Near Eastern period/style it belongs to.

**Do not use when:** the job is reconstructing or taking a Saylor (or any) exam, dumping Gardner/Janson/Stokstad or quiz banks, running an **art-history survey as a whole course**, running a **studio** production brief, filing **OERu ART100 / WikiEducator** eleven-module numbers as Saylor units, treating the free 70% certificate as **ACE SAYA-0036** credit, sitting the **webcam ACE** exam, or answering **HIST103 / ENGL405 / PHIL102 / COMM100**.

This is **one** skill. It is not "Unit 1 skill + Unit 2 skill…". ARTH101's nine live units are one argument: **most viewers already have a judgment; this course's pass is description → analysis → context → meaning, with judgment last — through categories, meaning-levels, visual language, media, architecture, themes, and only then a timeline.**

## 1. Procedure — answer an art-appreciation question in six checks

Run in order. Skip a check only if the user already constrained the frame.

### Check A — Identity, five-step, overlay (always)

**The course question:** is the user asking for a **studio how-to**, a **history-survey date**, a **philosophy of beauty as PHIL**, or a **five-step look** that has to keep form, medium, meaning, and period in their own seats?

Live test:

| Prompt smells like | Hand off |
|---|---|
| "Draw this / mix this pigment as a studio assignment" | **studio course** (not this) |
| "World history 1600–present as events" | **HIST103** |
| "Is this valid reasoning / fallacy" | **PHIL102** |
| "OERu module 9 architecture as their course" | **not this unit numbering** |
| "Take / reconstruct the Saylor or ACE exam" | **refuse** |
| "What am I looking at; how is it made; what does it mean; where in time" | **this skill** |

**Primary goal:** interpret with the **five-step system** and connect **formal attributes with meaning** (CLO 6). That is not "I like it" first (judgment without description fails), and not "this is Impressionism" first (period without looking fails).

**Named live failure mode:** skipping to **judgment** (or to a period label) before description/analysis/context/meaning.

**Level check:** if the prompt is actually a Gardner-style survey midterm covering twenty centuries as the *whole* course, recap Unit 9 only after Checks B–E. If it is MBA/ACE exam-taking, **refuse exam reconstruction**.

### Check B — Form, category, continuum (when "what kind of art / is it abstract / form vs content" is in play)

CLO 1 overlay + Unit 1.

Name, in order:

1. **Form vs content.** Form = physical construction / arrangement. Content = message / subject / meaning. They connect; they are not synonyms.
2. **Category:** fine (museum/gallery heritage objects — *Mona Lisa* as the named example) vs popular (posters, graffiti, advertising, street texture) vs decorative / "craft" (skilled making, often utilitarian — a Mexican painted ceramic as the named SNLS example). A work can sit in more than one. Craft is not "not art."
3. **Continuum:** **representational** (strong visual reference to the real world; "figurative" even when there are no figures) → **abstract** (derived from real-world imagery, simplified/distorted/geometric — Picasso *Girl Before a Mirror*) → **nonrepresentational / non-objective** (no recognizable real-world reference — Delaunay *Le Premier Disque*). Abstract ≠ nonrepresentational. Romanticism / Impressionism / Expressionism loosened exact depiction; they are not automatically nonrepresentational.

**Hand off Unit 4** if they only need to name an element. Stay here for "what kind of object, which step of looking."

### Check C — Meaning levels (when "what does it mean / symbol / context" is in play)

CLO 3 / 6. Unit 3.

Climb **formal → subject → context → iconography**, then **critical perspectives** if the prompt asks whose reading. Subject is not meaning. A crucifixion as subject is not yet a saint's attribute as iconography, and neither is yet judgment.

Five-step **Context** (historical / religious / environmental) and **Meaning** (content/message/narrative) live here.

**Hand off Unit 8** if the symbol is myth/spirit/ritual as the *theme*. **Hand off Unit 9** if they need a date. Stay here for "which level of meaning is the question asking."

### Check D — Visual language (when "line / color / balance / composition" is in play)

CLO 1. Unit 4.

**Elements** (building blocks — Gildow/SNLS labels; confirm live list): point (figure-ground the instant a mark hits the ground; Seurat Pointillism as optical mix); line (actual vs implied; contour; hatch / crosshatch; calligraphic); shape (geometric vs organic; figure-ground); mass; space (linear perspective as a **Western pictorial convention**, not a universal; vertical placement elsewhere; Cubism flattens the window); value (light/dark — **not market value**; tint = hue+white, shade = hue+black; high-key / low-key; high vs low contrast); color (hue / value / saturation; traditional RYB primaries; complementary pairs; warm/cool); texture (actual vs implied; impasto).

**Principles** (orchestration into composition): balance (symmetrical / asymmetrical / radial); repetition; scale and proportion; emphasis; time and motion; unity and variety.

Live unit title says **Principles**; encode elements anyway. Quiz trap: **element ≠ principle**.

**Hand off Unit 5** for "what is the binder." Stay here for "name the visual language."

### Check E — Medium, process, architecture (when "what is it made of / fresco or oil / is it a building" is in play)

CLO 2 / 4. Units 5–6.

**Medium ≠ technique ≠ style.** Medium = material/support. Technique/process = how it is worked. Style = look/school. Period = time/place.

**2-D:** drawing dry (graphite, charcoal, pastel) vs wet (ink); painting (fresco, tempera, oil, acrylic, watercolor as the public comparison set — confirm live); printmaking; collage.

**Camera:** still, film, video, digital.

**3-D:** sculpture (carve / model / cast / construct-assemble); decorative arts; installation.

**Architecture is Unit 6, not a 3-D subsection.** Architecture = art **and** science of structures/spaces **for human use**; related to sculpture but occupiable. Archive map: traditional methods (post-and-lintel, arch, vault, dome — confirm live labels) · China and the Far East · cross-cultural · Industrial Revolution · modern "new language" · postmodern/contemporary · green.

**Hand off Unit 9** for "is this Gothic or Romanesque." Stay here for "what is it made of, for whose use."

### Check F — Theme, then time-and-place (when "identity / war / spirit / what period" is in play)

CLO 5 / 7. Units 7–9.

**Our World (Unit 7).** Live short title; archive topic list: nature, the body, identity, sexuality, politics, and power. Archive seats: identity · self-portraits · natural world · social/collaborative · politics/conflict/war · memorials · peace. A war memorial is **this** unit, not Other Worlds.

**Other Worlds (Unit 8).** Mortality, spirit, fantasy. Myth as world-view narrative; dreams; spirituality; ritual/mask/costume. Iconography is the *method* (Unit 3) used on spirit subjects (Unit 8).

**Time and place (Unit 9).** Live title: **Western and Near Eastern World**. Do **not** skip Mesopotamia/Egypt. Named-work jobs (SNLS/Smarthistory residue, confirm live): Naram-Sin; Hammurabi; Egyptian materials/techniques; kouros vs Polykleitos *Doryphoros*; Nike of Samothrace; Augustus of Primaporta; Early Christian basilica after Constantine; Justinian mosaics; fibulae / "barbarian" metalwork; Ottonian Hildesheim; Romanesque vs Gothic (Chartres jambs); Cimabue vs Giotto; Masaccio *Holy Trinity*; Campin *Merode*; High Renaissance (Raphael *School of Athens*, Leonardo *Last Supper*, Michelangelo *David*); Baroque vs Rococo (Fragonard *The Swing*); Neoclassicism vs Romanticism; Courbet Realism; Manet hinge (*Déjeuner*, *Olympia*); Impressionism (Monet Rouen, Renoir *Moulin de la Galette*); Post-Impressionism (Seurat *La Grande Jatte*, van Gogh Roulin, Cézanne apples, Gauguin *Vision after the Sermon*); Fauvism; Futurism; art between the wars / Nazi Germany; Abstract Expressionism / New York School.

**Style ≠ period. Medium ≠ movement. Near Eastern is on the live title.**

**Hand off Unit 1** if they have not yet described the object. Stay here for "this theme, this date."

## 2. Worked patterns (shape only — not exam items)

**"Is this abstract?"**
Check A (five-step: describe what is actually there) → Check B (continuum: derived from the real world = abstract; no real-world reference = nonrepresentational). Picasso can be abstract and still a figure. Delaunay discs are the named nonrepresentational example. Do not call Impressionism nonrepresentational just because brushwork is loose.

**"What does this painting mean?"**
Check C (formal → subject → context → iconography). If the subject is a myth or a saint, add Check F Unit 8. If they want a date, Check F Unit 9 last. Do not start with judgment.

**"Oil or tempera? Is the cathedral sculpture?"**
Check E. Medium vs process. A cathedral is architecture (Unit 6) that also has sculptural programs (Unit 5 / Unit 9 Gothic jambs). Occupiable space = architecture.

**"Why is the vanishing point behind Christ?"**
Check D (linear perspective as a Western convention; *Last Supper* as the named example) → Check F Unit 9 (High Renaissance job). Not a photography question (camera is Unit 5).

**"Is this ACE credit if I pass the free final?"**
No. Certificate 70% ≠ SAYA-0036. ACE is a **different**, proctored, $5, max-3 exam. This skill does not take that exam.
