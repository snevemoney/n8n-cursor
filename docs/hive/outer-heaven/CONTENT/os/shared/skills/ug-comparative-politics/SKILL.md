# Comparative politics: method first, then system type, then behavior (clustered)

**Use when:** a task asks how to **compare political systems** in the Saylor POLSC221 school — which paradigm/method, which nation-state path, democracy vs democratization, institutions vs behavior vs policy, or how to use cases without inventing a roster.

**Do not use when:** POLSC101 discipline survey; POLSC201 Plato-to-Mill canon; GEOG101 regions; HIST103 dates; PHIL103 justice philosophy; ENGL; PSYCH; exam reconstruction.

This is **one** skill. Seven live units, one argument: **most students already have a US-civics or a Great Books story; this course's pass is comparison — method, then types of state and democracy, then structures, behavior, policy, then cases as method.**

## 0. Hygiene

- Label **school**. Undergraduate **comparative politics** (Saylor POLSC221). **75 h / 7.5 CEU.** LMS **344** (`/course/polsc221`). ACE **N**. Cert **70% / 14-day / max 3**. Syllabus **2025-10-03 15:14**. No guest-visible textbook.
- Seven **live** units: Social Sciences and Comparative Politics; The Nation-State; Democratic States and Democratization; Comparing Political Structures and Institutions; Political Behavior; Comparing Ideology, Policy, and Decision-Making; Comparative Case Studies.
- Live intro: formal public sphere; systematic comparison of **types of government and political systems**; sample questions: which representative democracies are more effective; why some countries are prosperous and others poor.
- Do not invent Unit 7 country names. Confirm on login.

## 1. Procedure — six checks

### Check A — Identity

| Prompt smells like | Hand off |
|---|---|
| Power/participation/IR as *intro survey* | **POLSC101** |
| Plato/Hobbes/Marx as canon | **POLSC201** |
| World *regions* | **GEOG101** |
| Take the final | **refuse** |
| Why these two systems differ / how to compare democracies | **this skill** |

### Check B — Method (Unit 1)

Paradigms in the social sciences; comparative methodologies. Comparison is a *method*, not a continent tour.

### Check C — State and democracy (Units 2–3)

Nation-state as compared form; developmental path → long-term outcomes. Democracy/democratization: **multiple approaches** for studying democracy. Not "the US template."

### Check D — Structures (Unit 4)

Institutions compared across countries. Bureaucracy has reasons. Public vs private sector effectiveness is a comparison job.

### Check E — Behavior and policy (Units 5–6)

Party ID → voting; turnout trends; media on public and state. Ideology, policy, decision-making compared. Policymaking process and forces that impact it.

### Check F — Cases (Unit 7)

Method seat. Political economy/development and challenges in **selected countries** — names are **login**. Continents in the course description are a *scope*, not a unit map. Resource-rich vs not is a development comparison, not a country list.
