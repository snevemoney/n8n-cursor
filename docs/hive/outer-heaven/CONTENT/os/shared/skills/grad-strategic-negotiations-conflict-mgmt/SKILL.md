## 1. Procedure — answer a graduate strategic-negotiations question in six checks

Run in order. Skip a check only if the user already constrained the frame.

### Check A — Identity overlay (always)

**The course question:** is the user asking for an **undergrad negotiations inventory**, an **OB conflict chapter**, a **law ADR** job, an **HRM labor** cycle, a **change** course, or a **manager** move that is supposed to **keep the workforce moving through difficult conflict**, including assisting employees?

**Level check:** if the prompt is actually undergrad homework in BUS403's five CLOs / Course Map, **hand off BUS403** and recap only. If it is MMGT606's proctored 80% exam, **refuse exam reconstruction**; this skill is the *content* overlay, not the degree exam.

### Check B — Differentiate negotiation vs conflict management, and the steps (when "is this a negotiation or a conflict / what are the steps" is in play)

CLO 1, CLO 7, CLO 2. Unit 1.

**Differentiate** negotiation from conflict management. Then **differentiate the steps** of managing conflict. Then **apply methods** in the workplace. Verbs are *differentiate* and *apply*, not "define conflict."

Live intro: some conflict may be good for productivity; this course reviews the **more difficult** types.

Saylor OB ch.10 overlay (summarize; confirm live names): types, causes/outcomes, handling. Encode the *job* (which of these is a negotiation, which is conflict management, which step we are on). Do not freeze TKI as live CLO language.

**Hand off BUS403** for the intro inventory. **Hand off BUS640** for three-level OB conflict. Stay here for "this manager, this difficult conflict, these steps."

### Check C — Communication and convincing (when "what do I say / how do I persuade" is in play)

CLO 8, CLO 3. Unit 2.

**Examine communication skills** needed in negotiation and conflict management. **Select ways to convince others** in a business setting. Communication is **its own unit**.

**Hand off BUS210 / COMM** for a communications *course*. Stay here for "this message, this conflict, this convince-others job."

### Check D — Creating value / costs vs benefits / stakeholders (when "is this worth it / who wins / joint gains" is in play)

**Hand off BUS608** for ethics+strategy as a *course*. Stay here for "these costs, these stakeholder outcomes, this process."
