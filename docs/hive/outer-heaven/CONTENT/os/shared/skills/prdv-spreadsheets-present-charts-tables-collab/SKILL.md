# Spreadsheets III: chart the data, table it, present together (clustered)

**Use when:** a prompt already past beginner Excel/Sheets needs to **present data** — the right chart for this set, a **scatterplot with trendline and equation**, worksheet **graphics/headers/footers**, a **created and filtered table**, or **collaboration features** so others can see it — in the Saylor PRDV007 **Spreadsheets III: Presenting Data** school (10 h; Spreadsheet Mastery spec).

**Do not use when:** reconstructing exams; **PRDV004** beginner workbooks/formulas/budgets (CFO stub — do not treat that 5 h as this course); **PRDV006** formatting and functions (CFO stub); **PRDV433** gen-AI spreadsheets; **PRDV200** communicating with data as a *comms* course; **BUS204** statistics as a *course*; vendor Excel/Sheets cert dumps; starting an Excel 365 **paid trial**; moving money or treating a chart as Personal CFO FACT; promising ACE.

## 1. Procedure — five checks

Run in order.

### Check A — Identity overlay (always)

| Prompt smells like | Hand off |
|---|---|
| "What is a cell / SUM / budget sheet as intro" | **PRDV004** (CFO stub; do not overwrite unless assigned) |
| "VLOOKUP / nested IF / heavy formatting" | **PRDV006** |
| "ChatGPT write me a macro / Claude clean this sheet" | **PRDV433** |
| "Tell the story of this chart in a memo" | **PRDV200** |
| "Infer / hypothesis / p-value" | **BUS204** |
| "Which chart, scatter+fit, filter this table, share the workbook" | **this skill** |

**Primary goal:** present data so a user *gets it* — the right visual, the right table, together. Named failure mode: dumping every chart type, or treating a pivot rumor from SNLS as a live CLO.

### Check B — Chart that fits the data (when "bar or pie / which chart" is in play)

CLO 1. Unit 1.

**Illustrate** a **line, column/bar, pie, and stacked column/bar** chart that is **appropriate for the given data**. Verb is *illustrate*, with a fitness test. Encode the *job* (what comparison this data is actually making). Do not freeze combo/sparkline as live until login.

### Check C — Scatter, trendline, equation (when "are these correlated / fit a line" is in play)

CLO 2. Unit 2 ("More Work with Charts").

**Diagram a scatterplot with a trendline and line equation** for a data series. Correlated data; fit to an equation. This is still *presenting*, not BUS204 inference.

**Hand off BUS204** if they need stats-as-a-course. Stay here for "this scatter, this fit, this picture."

### Check D — Graphics and chrome of the sheet (when "logo, link, header, make it look like a handout" is in play)

CLO 3. Unit 3.

**Explain how to add graphics, symbols, hyperlinks, headers, and footers** to a worksheet so we communicate better with users. Not Word (PRDV003). Not a slide course (PRDV008).

### Check E — Table, filter, collaborate to present (when "sort this list / share the file" is in play)

CLO 4–5. Units 4–5.

**Create and filter a table.** **Arrange collaboration features** to present data in various contexts. Live intro: database functions of tables to organize; collaboration last.

Do **not** answer with "build a pivot" as if that were a live CLO. SNLS named pivots; this syllabus did not. If they need a pivot, say that is **not guest-confirmed live** and encode create/filter instead.
