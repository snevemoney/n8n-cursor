# Managerial cost, CVP, relevant-cost, and control (clustered)

**Use when:** a task asks how managerial accounting differs from financial accounting, how to classify product vs period or variable vs fixed costs, how to cost a job or a process, how to apply overhead or ABC, how to find break-even / target profit / margin of safety, whether to make-or-buy / drop a line / take a special order, how to build a master or flexible budget, how to split a variance, or how to read ROI / RI / EVA or an internal cash/ratio view.

**Do not use when:** the job is reconstructing or taking a Saylor (or any) exam, dumping Heisinger/Hoyle or OpenStax, running **BUS103** GAAP journals / the accounting cycle / constructing the four statements, **BUS101** survey-only "what is an income statement," **BUS202** TVM / securities / capital-structure, **BUS300** operations transformation, **BUS208** POLC-as-the-manager's-job, **BUS210** audience/channel/tone, or tax-prep / audit-engagement procedures.

This is **one** skill. It is not "Unit 1 skill + Unit 2 skill…". BUS105's eleven units are one argument: **managerial accounting produces internal cost, price, and profit information so managers can plan, control, and decide** — costing systems assign DM/DL/OH; CVP translates volume into profit; relevant-cost analysis picks among alternatives; budgets and variances close the loop.

## 1. Procedure — answer a managerial-accounting question in five checks

Run in order. Skip a check only if the user already constrained the frame.

### Check A — Identity, audience, cost objects (always)

**Financial ≠ managerial.**

| | Financial (BUS103) | Managerial (this skill) |
|---|---|---|
| Audience | External (investors, lenders, regulators) | Internal (managers, segments, teams) |
| Rules | US GAAP / FASB | **No GAAP constraint** — customize the report |
| Time | Historical | Forward / what-if, plus actual-vs-plan |
| Focus | Firm as a whole; four statements | Cost object: product, job, customer, department |
| Data | Monetary, auditable | Monetary **and** nonfinancial (hours, units, quality) |

If the prompt is journalize, adjust, close, or *construct* an income statement / balance sheet under GAAP, **stop and hand off BUS103**.

**Three jobs this school names:** planning (budget), controlling (flexible budget + variances), decision-making (relevant-cost analysis). OpenStax also says "evaluating"; treat it as the performance-metrics end of control (Check E).

**Product vs period (inventoriable vs expensed now):**

- **Product / manufacturing:** direct materials + direct labor + manufacturing overhead (indirect materials, indirect labor, factory rent/utilities/insurance/depreciation).
- **Period:** selling + administrative.

Cost **flow follows physical flow** (CLO 2): Raw materials → WIP (add DM, DL, applied OH) → Finished goods → COGS. A pizza parlor is the archive's picture, not a journal-entry drill.

**Contribution-margin IS ≠ absorption IS.** CM statement: Sales − VC = CM − FC = operating income. Absorption is the GAAP manufacturing IS BUS103 can build. This course *lives* on the CM statement from Unit 4 on.

**Cross-functional (CLO 5):** a cost object that operations, sales, and finance do not share is a report nobody can act on. Encode the team; do not run BUS208 POLC or BUS209 OB.

### Check B — Assign the costs (job / process / ABC)

If the prompt is "what does this product / job / batch cost," pick a system **before** you arithmetic.

1. **Name the cost object.** One custom order → **job**. Homogeneous units through departments → **process**. Many activities driving OH, and plant-wide rates are lying → **ABC**.
2. **Trace DM and DL** to that object. Everything else in the factory is OH.
3. **Apply OH.**
   - Predetermined rate = estimated OH / estimated base (DL hours, machine hours, …). Apply as work happens.
   - Under-/over-applied OH exists because the rate was a *plan*. Close it at period end (intro default: to COGS). Do not pretend the rate was actual.
4. **If process costing:** equivalent units (how complete is WIP?) → cost per EU → production cost report (transferred out + ending WIP). Weighted-average is the Saylor-archive default. Do not require FIFO EU unless asked.
5. **If ABC:** same DM/DL; OH split by **activity cost drivers**. Plant-wide vs departmental vs ABC is three ways to slice one pool. "Sales up, profit down" is the named failure of a bad OH system (SailRite). Activity-based *management* changes the work, not just the price.

Service firms still run job/ABC on labor + OH when DM is small.

If the prompt already has a unit cost and is asking "should we drop it / how many do we sell," skip to C or D.

### Check C — Cost behavior and CVP (volume → profit)

Rearrange the same costs as **variable / fixed / mixed**. A salaried factory worker with a bonus is DL in Check B and mixed here.

- Variable: total moves with activity; per-unit ~ constant **in the relevant range**.
- Fixed: total constant in the range (committed vs discretionary); per-unit falls as volume rises.
- Mixed: split with high-low (intro default), scattergraph, or regression. High-low uses only two points — say so.

**CVP kit (single product first):**

- CM per unit = selling price − VC per unit. CM ratio = CM / SP.
- Break-even units = FC / CM per unit. Break-even $ = FC / CM ratio.
- Target-profit units = (FC + target) / CM per unit. After-tax: gross the target up for tax, then use the same formula.
- Margin of safety = expected (or actual) − break-even.
- Degree of operating leverage = CM / operating income. High FC → sales swings hit profit harder.

Multiproduct: hold the **sales mix**, use weighted-average CM. Constrained resource: maximize **CM per unit of constraint**, not CM per unit of product.

Sensitivity: change one input and recompute. A break-even number is not a forecast.

Variable vs absorption income: only when production ≠ sales and the user asks why income moved. Otherwise stay on the CM statement.

### Check D — Relevant-cost decisions (alternatives)

**Relevant = future cash that differs among alternatives.** Sunk is never relevant. Allocated common fixed costs usually **will not disappear** if you drop a line — leaving them in the "savings" column is the intro-level lie.

Run the contribution-margin / differential format. Named families:

| Decision | Keep in | Leave out |
|---|---|---|
| Make or buy | Avoidable manufacturing costs vs purchase price + any extra handling | Unavoidable FC; sunk equipment |
| Drop / keep a product or customer | Traceable VC + traceable FC that die; lost CM | Common FC that get reallocated |
| Special order | Incremental VC + extra FC; opportunity cost if at capacity | Full absorption cost as a floor when idle |
| Constrained mix | CM per constraining unit | Ranking by CM per unit of *product* |

If revenue is the same, pick the lowest relevant cost. If not, pick the highest relevant profit. Watch **long-run price** damage on special orders.

Pricing cousins (not a marketing-mix unit): **cost-plus** (cost + markup) vs **target costing** (market price − desired profit = allowable cost). 4Ps / segmentation → **BUS203**. "Should I incorporate?" → **BUS101**.

**Long-term assets / capital screen (CLO 3; archive nested under Unit 7):** NPV and IRR consider time value; payback is a coarse screen. Hurdle = required return. Nonquantifiable factors still exist. **Hand off BUS202** as soon as the user needs TVM as a finance toolkit (securities, WACC construction, capital structure). Stay here for "should operations buy this machine."

### Check E — Plan, control, evaluate (budgets, variances, segments, cash)

**Plan — master budget.** It is a *set*, not a spreadsheet tab: sales → production → DM / DL / OH → selling & admin → income statement → capex → cash → balance sheet. **Sales drives the rest.** Participative vs imposed; slack/padding is the named ethics problem (planning vs control conflict). Merchandising / service / NFP skip some manufacturing schedules; they still budget.

**Control — flexible budget + standards.** Restate the master at *actual* activity before you call a cost "over." Standard cost = standard price × standard quantity (per unit).

Split every variance you bother to name:

- Materials: price vs quantity
- Labor: rate vs efficiency
- Variable OH: spending vs efficiency
- Fixed OH: spending vs production-volume

Investigate by materiality, controllability, and whether the investigation is worth its cost. ABC firms set several OH standards (one per driver); the *process* does not change.

**Evaluate — responsibility accounting.** Hold a manager only for what they control (cost / revenue / profit / investment center). Segmented income: traceable vs common (same drop-decision logic as D).

- **ROI** = operating income / operating assets (margin × turnover).
- **RI** = operating income − required return × assets.
- **EVA** = RI with accounting adjustments.

A high-ROI division rejecting a project that still beats the company hurdle is the named goal-congruence failure; RI/EVA is the intro fix. Balanced scorecard / nonfinancial measures sit on top so you do not manage only the ratio. Strategy-map depth → **BUS401**.

**Cash and ratios as *internal* reads (Units 10–11), not as BUS103's fourth statement:**

- SCF still splits operating / investing / financing. Indirect method is the intro default. "Profitable but no cash" is working-capital and investing uses — a control problem, not a rounding error.
- Trend (horizontal) → common-size (vertical) → ratios **with a baseline** (own history, competitor, industry). Archive families: profitability, liquidity, solvency, market. A lone current ratio is a number.
- Hand off **BUS103** to *construct* the SCF from a closed cycle; **BUS101** to only name IS vs BS.

## 2. Worked micro-patterns

**"What is managerial accounting / how is it not financial?"**
Check A in one paragraph. Audience, GAAP, time, cost object, nonfinancial data. Hook: the same pizza's cheese is DM for the manager and inventory-then-COGS for the lender.

**"What does this job / batch cost?"**
Check B. Name the object, trace DM/DL, apply OH (or ABC), show under-/over-applied if the period is closing. Process: EU + production cost report.

**"How many do we have to sell?"**
Check C. CM, BE, target, MOS. If they name two products or a bottleneck, mix / CM-per-constraint. Do not quote a BE number as a sales forecast.

**"Should we outsource / drop this / take the order?"**
Check D. List what differs. Kill sunk and allocated common FC. Idle vs at-capacity is the special-order fork.

**"Why is actual worse than budget?"**
Check E. Flexible-budget the volume story first, then split price/qty (or rate/efficiency). Do not investigate every line.

**"Is this division earning its keep?"**
Traceable vs common (D + E), then ROI vs RI. If they only have firm-wide statements, you are in BUS103/BUS101 territory until someone gives you a segment.

**"We're profitable and still bouncing checks."**
Check E cash. Classify the lag (AR, inventory, capex). Do not rebuild the whole accounting cycle unless they also need BUS103.
