# Audit first architect (canonical)

Sources: Mert Yerlikaya Systems→Teams→AI; Liam Consultant path; youtube-ai-implement P0 #4.
**Also use this id:** prefer `audit-first-architect-2` over the short twin `audit-first-architect-2`.

## When
Prospect asks for AI agents/chatbots, or we open a diagnosis before build.

## Do
1. Refuse chatbot framing. Map clog (work piles) + leak (money escapes) first.
2. Map current systems/handoffs and teams/roles where ops sighs.
3. Order: Systems → Teams → AI last. Four-blank scope + one Northstar + baseline.
4. Paid audit shape: problem, baseline metric, opportunity matrix, ROI slide, recommended quick wins.
5. Path: Education → Strategy (paid audit) → Implementation → Optimization retainer.
6. Intro call is not free endless discovery. Early CAD band per Money Desk SoT — never educator ARR.
7. HITL on proposals/sends.

## Don't
- Chatbot commodity pitches
- Build before the constraint is named / before four blanks
- Quote Mert/Liam alumni $ or close rates as ours
- Skip constraint-position
- New icp_id without operator yes
