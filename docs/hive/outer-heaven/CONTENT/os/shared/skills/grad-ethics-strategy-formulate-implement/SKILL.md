# Graduate ethical + strategic management: formulate and implement under ethical models (clustered)

**Use when:** a task asks how a firm should build and live a strategy that is both a functional roadmap and ethically survivable — how to read internal/external constraints, how to turn mission/goals into a plan, which generic / BCG / SPACE / structure to pick, how to run deontology / rights / virtues on the pick, how to resource and motivate implementation, how to build a culture that will hold the decision, or how to score results with measures vs referents (including ethics/sustainability) — in the Saylor BUS608 **graduate** ethical-and-strategic-management school.

**Do not use when:** the job is reconstructing or taking a Saylor (or any) exam, dumping Porter / Kaplan-Norton HBR / Kohlberg / SOX, running **BUS200** undergraduate business-ethics survey checklists (integrity, CSR vs greenwashing, seven units, ACE SAYA-0047), **BUS501** undergraduate strategic-management capstone (goal ≠ strategy, five units, MSM at intro-capstone depth), **BUS208** POLC-as-the-manager's-job, **BUS401** leadership-vs-management theory, treating the free 70% certificate as **MBA608** / **MMGT610** / **MEI606** 80% proctored exams, promising ACE/transfer credit, or writing a collusion / market-manipulation script.

This is **one** skill. It is not "Unit 1 skill + Unit 2 skill…". BUS608’s four live units are one argument: **ethics is how formulation and implementation stay one managerial job** — a strategy the ethical models can bless, resourced and cultured so it holds, scored against referents that include sustainability.

## 1. Procedure — answer a graduate ethical-and-strategic-management question in six checks

Run in order. Skip a check only if the user already constrained the frame.

### Check A — Identity, overlay, ethical models (always)

**The course question:** is the user asking for an **ethics survey**, an **undergrad strategy capstone**, a **standing-manager POLC** answer, or a **manager’s strategy decision** that has to survive ethical models *and* still be a roadmap?

Live test:

| Prompt smells like | Hand off |
|---|---|
| “Define integrity / legal≠ethical / CSR vs greenwashing / seven ethics units” | **BUS200** |
| “A goal is not a strategy; SWOT; which generic; execute” as undergrad capstone | **BUS501** |
| “Plan, organize, lead, control the department” | **BUS208** |
| “Trait/behavioral/transformational leader” | **BUS401** |
| “Journal this / SOX as a *law* course” | **BUS205** |
| “Kant seminar / what is a right *in philosophy*” | **PHIL103** |
| “Which method for this *project*” | **BUS605** |
| “Bias vs data / People Analytics” | **BUS607** |
| “Can this strategy be formulated and implemented so the ethical models and the culture hold” | **this skill** |

**Primary goal: a roadmap every function can use** (live intro) whose strategy **aligns with ethics and sustainability goals**. That is not “maximize this year’s NI,” not “keep every stakeholder equally happy as a second objective that replaces the map,” and not “pass an ethics quiz.”

**Three named models (CLO 4) as tests on a strategy, not as a survey:**

| Model | Asks of the strategy | Fail if |
|---|---|---|
| **Deontology** | What *duty / rule* are we following, regardless of payoff? Are persons treated as ends? | The plan works only by using people as mere means, or it is a one-time exception to a rule the firm claims to live by |
| **Rights** | Whose *ethical* claims constrain the move (employees, customers, communities, owners)? | A stakeholder right is treated as a PR problem. Legal minimum → **BUS205**; survey ranking of claims → **BUS200** |
| **Virtues** | What *character* does this firm have if it does this repeatedly? Will the culture hold it? | The pick requires heroes or silence. Virtue-as-a-unit → **BUS200**. Culture-as-a-course → **BUS209 / BUS640** |

Run all three. A strategy that passes one and fails two is not “ethical enough.” Utilitarianism (greatest good) is the usual fourth lens from BUS200 — name it if the prompt is a harm/benefit fight; do not pretend CLO 4 listed it.

**Level check:** if the prompt is actually undergrad homework in BUS200’s seven units or BUS501’s five, **hand off** and recap only. If it is MBA608/MMGT610/MEI606’s proctored 80% exam, **refuse exam reconstruction**; this skill is the *content* overlay, not the degree exam.

### Check B — Formulation: mission, constraints, diagnosis (when “what is our strategy / where are we / SWOT” is in play)

CLO 1, 3, 5. A goal is not a strategy (same test as BUS501, spent here as the ethical overlay).

**Mission / vision / goals (CLO 1):** write the reason the firm exists and the direction the functions will share. If the goal cannot be said out loud under deontology/rights/virtue, it is not a formulation yet (CLO 3: ethics in *development*).

**Internal and external constraints (live intro; Unit 2):**

| Side | Public school (MSM overlay; confirm live labels) | Ethical overlay |
|---|---|---|
| External | PESTEL; five forces; strategic groups as closest-rival *referents* | A legal gap is not an ethical permission. A force that requires harming rights is a constraint, not an opportunity |
| Internal | Resources / capabilities; **VRIN** for a *sustained* advantage; value chain; SWOT with cautions | Core capabilities you will not use because they fail the models are not “strengths.” Do not list a *move* as an opportunity |

SWOT is brainstorming, not a selection algorithm. **Hand off BUS501 Unit 2** for the undergrad diagnosis lab. Stay here for “the diagnosis has to be one the models can still bless.”

**CLO 5 in diagnosis:** a **measure** (margin, NPS, emissions, safety) without a **referent** (own history, industry, strategic group, ethical/sustainability target) is a number, not an analysis. Balanced scorecard (financial / customer / internal process / learning and growth) resists one-number fixation. Triple bottom line (people / planet / profit) is the ethics referent set the live intro’s sustainability goal implies.

### Check C — Formation: pick the generic, the portfolio, the structure (when “which strategy / BCG / SPACE / org chart” is in play)

Indexed Unit 3 LOs 3a–3d (confirm live wording on login).

**3a Porter generic** (after analysis, not instead of it):

| Generic | Public school | Ethical overlay |
|---|---|---|
| Cost leadership | Acceptable quality, low price, broad market; scale / efficiency | “Cheap” that depends on unsafe work or deception fails rights/virtue. Cost leadership is not junk |
| Differentiation | Premium for uniqueness, communicated | Uniqueness that is a lie fails deontology. “Won’t pay extra” is the market kill; “shouldn’t pay extra because we hid the harm” is the ethics kill |
| Focus (cost or differentiation) | Niche / segmentation | A niche you can only hold by trapping the customer fails rights |
| Best-cost | Low price *and* unique — rare, attacked from both sides | Same two tests at once |
| Stuck in the middle | Neither cheap enough nor unique enough | Not an ethics fail by itself; it is a *strategy* fail. Do not dress it up as “balanced” |

**3b tools (names; do not dump matrices):**

- **BCG:** star / cash cow / question mark / dog (share × growth). Use it to *focus effort*, not to “kill dogs” as a moral slogan — a harvestable unit can still have rights-bearing people in it.
- **SPACE:** aggressive / conservative / defensive / competitive. Pick a posture that the constraints and the models can fund.
- **Balanced scorecard** as a *formation* tool: the pick has to leverage resources across four perspectives, not only this year’s NI.
- SWOT named in the vocab list — Check B’s cautions still apply.

**3c structure:** **functional** vs **matrix** (MSM’s other building blocks as overlay). A pick the structure cannot carry is theater. CLO 6 starts here: which resources does this structure need.

**3d ethics in the pick:** lead by example; ethics training; a **code of ethics** that actually defines expected behavior. The pick is not done until 3d has a home. Then Unit 4 *lives* it.

Corporate-level overlay (MSM 8, likely here): concentration, vertical integration, related vs unrelated diversification, retrenchment. Encode the tools; confirm live unit home on login. **Hand off BUS501** for the undergrad generic/corporate lab. Stay here for “which pick survives 3d.”

### Check D — Implementation: resources, people, culture (when “can we actually do this / who / how much” is in play)

CLO 2, 6. Resource planning. Motivating people. Culture that will support the decision (live intro).

- Name the **resources** the pick consumes (CLO 6). If VRIN said a capability was the advantage and implementation starves it, the formulation was theater.
- People overlay is **not** BUS603 / BUS640 as a course. Encode as implementation: can this staff live the code, take the training, and copy the example leadership is actually setting (3d).
- Structure from 3c is now *run*: functional clarity vs matrix dual-report. Control systems exist so Unit 2’s measures have owners.
- **Hand off BUS208** if they want POLC as the standing job. **Hand off BUS605** if the object is a PMI project. **Hand off BUS603** if they want the graduate managing-people course. Stay here for “can this strategy be resourced and staffed without failing the models.”

Global overlay (catalog “global and ethical context”): the same three models travel. “Different country, different ethics” is not a live CLO. Do not turn this into BUS613.

### Check E — Score: measures vs referents, including ethics (when “are we winning / is this sustainable / what number matters” is in play)

CLO 5. A measure without a referent is a glance, not a judgment.

| | Measure (metric) | Referent (benchmark) |
|---|---|---|
| Financial | Profits, margin, ROA, stock price | Own history; industry; strategic group |
| Customer | Attraction, satisfaction, retention | Same, plus the right the customer actually has |
| Internal process | Cycle time, quality, safety | The duty you claimed in Check A |
| Learning and growth | New skills, innovation rate | Can we still improve (MSM scorecard question) |
| Ethics / sustainability | CSP-class / triple-bottom-line indicators | The code, the models, the sustainability goal — not “we donated once” |

MSM teaching example (course-era numbers, keep the *logic*): 20% margin looks fine until last year was 35% and the industry is 40%. Graduate overlay: a “great” quarter that fails deontology/rights/virtue is a referent fail on the ethics dimension, even if NI is up.

Do not dump a 40-line KPI warehouse (**BUS607** / **BUS610**). Stay at “which measure, which referent, does it change the strategy.”

### Check F — Hold: code, training, example, close the loop (when “will this last / culture / scandal / can we still claim this strategy” is in play)

Unit 4 + 3d. Implementation is where character shows (ALS: the decisions define credibility).

- **Code of ethics** — expected behavior, specific enough to decide. A poster is not a code.
- **Training** — people can identify and resolve ethical situations the strategy will actually produce.
- **Lead by example** — if leadership’s private strategy contradicts the public one, virtue already failed.
- Boards / governance / SOX-as-named: **course-era** check on reporting and personal responsibility, not 2026 legal advice (**BUS205**). Scandal-class stories (Enron-era) are why this unit exists; **do not dump the film**.
- If the strategy cannot be *claimed* by the people who have to live it, you are back in Check C. A project that never ends has become operations (**BUS300**). A strategy that cannot be said under the three models was never formulated.

## 2. Worked micro-patterns

**"What is ethical and strategic management / how is it not ethics class or the strategy capstone?"**

**"Write the mission / is 40% growth a strategy?"**
Check B. 40% is a **goal**. The strategy is how, under which constraints, surviving which models. If they cannot name the duty/rights/virtue test, they are not in Unit 1 yet.

**"SWOT this firm / five forces / are we VRIN?"**
Check B. Diagnosis with cautions. Then Check E: which measure, which referent. Do not run BUS501’s undergrad lab as a new science.

**"Cost leadership or differentiate / BCG this portfolio / SPACE says aggressive."**
Check C. Pick, then 3d. A BCG dog that employs people still has rights. SPACE “aggressive” that requires deception fails deontology.

**"Functional or matrix / what resources do we need / how do we motivate this?"**
Checks C 3c + D. Structure must carry the pick. CLO 2 / 6. Culture that will support the decision. Hand off BUS603 if they want the people *course*.

**"Is this number good / balanced scorecard / triple bottom line?"**
Check E. Measure vs referent. Financial plus customer / process / learning. People/planet/profit as the ethics referent set. One-number victory is the named fail.

**"We have a code / training / the CEO does the opposite."**
Check F. Example is the virtue test. The code that leadership will not live is not implementation.

**"Define deontology / virtue / CSR vs greenwashing as a survey."**
Wrong course. **BUS200**. Recap the three named models only if this prompt still needs them as *strategy tests*.

**"A goal is not a strategy / five units of SWOT-to-execute."**
Wrong course. **BUS501**. Recap a process step only if this prompt still needs it, then run the ethical overlay here.

**"Plan-organize-lead-control the department."**
