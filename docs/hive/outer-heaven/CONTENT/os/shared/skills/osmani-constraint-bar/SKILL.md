# Osmani constraint bar

Source: addyosmani/agent-skills `constraint-driven-development` (MIT).

## When
New CapEx, product slice, or quality bar drift.

## Do
1. Write constraints: HOLD list, DONE_WHEN, verifier≠builder, token-meter, Tier-3 HITL.
2. Put constraints in the plan note / eval contract before generate (preflight-eval-before-generate when CapEx).
3. Refuse unnamed tools (BUS206 five components).

## Don't
Quietly drop live `/` HOLD, send, or HITL to move faster.
