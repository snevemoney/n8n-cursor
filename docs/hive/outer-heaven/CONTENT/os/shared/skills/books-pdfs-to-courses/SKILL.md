# Books PDFs to courses

Demkinn #38 hardened. Owner Researcher.

## When
Operator uploads a long PDF or book and wants a study pack.

## Do
1. Chunk by chapter or section.
2. For each: key ideas, examples, questions, exercises, flashcards, one hive application if relevant.
3. Write pack under research-packets. Run claim-verifier on any money or percent claims.
4. Promote durable lessons with wiki-ingest and research-signal-to-skills.

## Don't
- Auto-publish or sell without operator yes
- Open a course-business icp_id from one PDF
- Quote book income as FACT
