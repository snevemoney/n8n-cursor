# Track industry months

Demkinn #46 hardened. Owner Researcher.

## When
Operator names an industry to track on a standing basis.

## Do
1. Same template every month: top moves, primary sources, hive impact, open questions.
2. Append month files. Do not overwrite history.
3. Rank by business importance, not virality.
4. Claim-verify money or percent claims before FACT.
5. Close skill-relevant steals with research-signal-to-skills.

## Don't
- One-off dump with no prior month compare
- New business-lanes row from a trend piece
- Educator ARR as direction signal

## Tools
| Need | Path |
|---|---|
| Prior briefs | research packets dated — **PROVE** |
| Web | WebSearch — **PROVE** |

## Prompts
**Industry delta**
```
Industry: … · Window: months
What changed vs last brief · durable vs hype · hive angle
Write dated delta on disk.
```
