## 1. Procedure — answer a PRDV005 question in five checks

Run in order. Skip a check only if the user already constrained the frame.

### Check A — Identity overlay (always)

**The course question:** is this **workplace/life time-and-stress PD**, **intro psychology**, **clinical care**, **decision-making as a course**, or **the POLC job of the manager**?

| Prompt smells like | Hand off |
|---|---|
| "What is psychology / memory / psychopathology" | **PSYCH101** (not this desk) |
| "Diagnose this, treat this, panic attacks, meds, therapy plan" | **not this skill** — clinical; stop |
| "Decision-making models as a *course*" | **PRDV228** |
| "Plan-organize-lead-control as the manager's job" | **BUS208** |
| "Intro management as a *course*" | **PRDV221** |
| "How do I budget today, cut this distractor, set this goal, stay productive with the team without burning out" | **this skill** |

**Primary goal:** budget time and run a system that **identifies, evaluates, and eliminates** personal and work distractors and stressors so output, efficiency, and engagement go up. Named failure mode: treating stress as a personality flaw, or treating time as an app, instead of a PD loop of goals → priority/delegate → productivity with others → stress skills.

### Check B — Time management for output (when "I have no time / I'm inefficient" is in play)

CLO 1. Unit 1.

**Discuss the importance of time management** and **describe techniques** to foster better quality of output, more productivity, and efficiency. Live intro: budget time in daily life; identify/evaluate/eliminate **distractors**.

Encode the *job* (what is stealing the day, what "better output" means here). Do not freeze a named technique list as live Saylor CLO language.

### Check C — Goal-setting, delegate, prioritize (when "what should I actually do first / I do everything myself" is in play)

CLO 2. Course description.

**Identify the factors that enhance goal-setting outcomes.** Live description also names **delegating tasks** and **prioritizing your work**.

Stay here for "this goal, this priority, this hand-off." Not PRDV221's management *course* and not BUS208's POLC.

### Check D — Workplace productivity with others (when "the team is slow / I work better alone / meetings eat the day" is in play)

Unit 2. CLO 1 overlay.

Time-management strategies as a **more productive and engaged worker** — whether working **by ourselves or with others**. Solo vs collaborative is live intro language.

**Hand off PRDV213 / PRDV224** if the prompt is group communication or leadership-and-teams *as a course*. Stay here for "this time system, this workplace, these people."

### Check E — Stress skills without going clinical (when "I'm fried / this job is loud / I can't shut it off" is in play)

CLO 3. Unit 3.

**Describe how to implement time management and stress management skills** to reduce or prevent stress, maintain good health, and increase productivity. Live intro: reduce stress in work *and* daily lives; eliminate **stressors** the same way as distractors (identify, evaluate, eliminate).

If the prompt is medical, diagnostic, or a crisis: **stop**. This is a PD overlay. Do not write a treatment plan. Sensitive health stays out unless the operator asked.

## 2. Worked patterns (shape only — not exam items)

**"My calendar is full and the real work is unpaid overtime."**
Check A (workplace PD) then Check B (budget; which distractors) then Check C (goals, priority, what to delegate) then Check D (productivity with others — meetings as a distractor). Not BUS208 POLC.

**"I hit every goal and still feel wrecked on Sunday."**
Check C (goal-setting factors — more goals may be the problem) then Check E (stress skills as PD). If it turns clinical, stop.

**"The team is fine; I am the bottleneck because I won't hand work off."**
Check C (delegate) then Check D (engaged worker *with others*). Not PRDV225 managing-employees as a *course* unless they actually need that overlay.
