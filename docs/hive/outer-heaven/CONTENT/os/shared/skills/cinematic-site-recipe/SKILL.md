# Cinematic site recipe (ai-partner-websites)

Run in order. Skip none. Do not copy jailbreak / GOD-MODE prompts or tweet prices.
Sources enriched: Ed Hill ugly-sites craft yt:NNv80mMzFDs; ComfyUI official MCP pattern yt:cNaOJg47Z2A. Agent drives an existing renderer via connector; do not install ComfyUI/Higgsfield as a second desktop.

## 1. Three reference sites to style bible
Pick 3 live sites whose motion we love. For each record mood, type, pacing, and WHY each motion exists. No code until this exists.

## 2. One-paragraph brief
Write one paragraph: niche + cinematic scroll + every animation has a job. If a motion cannot be named there, it does not ship.

## 3. House rules
- No template hero
- No stock gradients as the look
- Nothing moves without a reason
- Taste work stays on a strong model
- Hero is video driven by scroll + cursor, not WebGL / Three.js

## 4. Fail-the-build pass
Second pass only job: FAIL the build vs a motion designer can't tell this from an agency. Close the biggest gap. Repeat until complaints run out. Then ship a live preview URL. Open the URL and click (mobile + reduced-motion). Docs are not done.

## 5. Hero is video
Creative Studio owns stills to previs to clip to grade. Forge wraps muted loop, poster, scroll-scrub + cursor, reduced-motion static poster.

## 6. Renderer MCP (optional craft assist)
If an MCP client can talk to the motion tool we already use: agent picks workflow, checks the machine, recommends before download, then runs. Pattern only.
Never: comfyui-desktop-install, higgsfield-swap, DeepSeek-as-desktop, run random install blocks from YouTube descriptions, Skool course as a hive SKU.

Owners: Forge (wrap + fail pass), Creative Studio (bible + clip).
SoT: CONTENT/website-building/cinematic/PLAYBOOK.md
