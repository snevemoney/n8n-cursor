# Graduate ideation: mindset, create, vet, choose (clustered)

**Use when:** a founder needs to **develop and vet an idea** against personal/professional goals — creativity methods, ideation vs innovation, feasibility (SWOT / competitive analysis / BMC), then choose via feasibility plans and opportunity assessments — in Saylor BUS652.

**Do not use when:** BUS651 law; BUS650 leadership; BUS653 launch; BUS305 undergrad; BUS604 innovation/sustainability as a course; MEI607 exam; ACE promises; dumping Osterwalder/Timmons chapters; exam reconstruction; spend/money movement.

This is **one** skill. Four units = **mindset/create → ideate/innovate → evaluate → plan the next step / choose.** Five CLOs. **Choosing is planning, not BUS653 launch.**

Market and financial constructs; feasibility plans; opportunity assessment tools. Next steps are **planning**, not BUS653 execution.
