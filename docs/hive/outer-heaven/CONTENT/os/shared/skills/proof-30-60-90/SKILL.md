# Proof 30 / 60 / 90

## When
Post-install / post-enablement for a paid client. Not for unpaid warm asks.

## Steps
1. ~30d: is the rail live? Binary yes/no + blockers.
2. ~60d: KPI vs baseline — owner-provided counts only; gaps = UNKNOWN.
3. ~90d: keep retainer ($500–1K/mo early) / upsell Rung 2 / stop.
4. Check delivery hours vs fee; if margin broke, shrink scope next time.
5. Short memo to operator + GTM; HITL before client-facing claims.

## Anti-patterns
Invented close rates; educator case studies as this client’s results; retainer before 30d rail-live proof.
