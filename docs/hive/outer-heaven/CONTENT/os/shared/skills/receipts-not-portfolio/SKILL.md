# Receipts, not portfolio

## When
After a hive or client build ships (even a tiny self-build).

## Do
1. Write one **before** number and one **after** number (hours, missed leads, reply time). If the owner did not give a number, label **UNVERIFIED** and write “need baseline.”
2. Save a 60–90s walkthrough (Loom or screen) of the outcome, not the canvas.
3. Put both in the packet / proof-30-60-90 note.
4. Never lead a talk track with “we built an agent.” Lead with the receipt.

## Don’t
- Collect workflow screenshots as proof
- Quote educator income as the receipt
- Invent the before number
