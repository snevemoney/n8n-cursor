# Reference-driven video production mode

Objective: the best investment show using the right tool mix. Remotion is one crew member, not the whole studio.

## Platform / Install
- **Platform:** Grok Bot + Cursor + Remotion (box)
- **Install:** `none (process-only)` for this doctrine skill; Remotion engine already on box. Blender CLI / DaVinci = **not** installed yet — do not claim they ran.

## Pipeline
NEWS/DATA/PORTFOLIO → story → viewer need → assets → medium choice → storyboard → build/retrieve kits → Blender (when spatial/product) → Remotion (data/programmatic) → edit/grade/sound → visual+financial QA → render → save editable artifacts for next episode.

Architecture shorthand: Research → Story Director → Asset Director → Blender → Remotion → Edit/Grade → QA → Final.

## Tool routing
- **Remotion:** charts, live data, typography, dashboards, timelines, portfolio/decision simulations, scorecards, dynamic UI, scenario fans, FACT/ESTIMATE labels. **PROVE** (portfolio-brief engine LIVE).
- **Blender (when available):** products, company objects, 3D/2.5D environments, cinematic cameras, product reveals, factories, data centers, physical supply-chain travel. **BLOCKED** on box until CLI present — would work if Blender installed; Remotion 2.5D silhouettes **WORKAROUND**.
- **NLE (DaVinci or controllable editor):** assembly, pacing, color, audio, music, sound design, finishing. **BLOCKED** until wired — Remotion composite + Juno **WORKAROUND**.
- **Hosted Remotion MCP:** **BLOCKED** (sunset 2026-08-31). Official `npx remotion skills add` **WORKAROUND**.
- **AI NLE / Adobe-shop copilots (bookmark watch):** RESEARCH-OK as references only. Do not auto-switch hive finishing to Adobe, CapCut, or an unnamed AI editor from influencer posts.
- **Named frontier “model edited this video” demos (e.g. GPT-6 Astra claims):** product name + clip provenance = **UNVERIFIED** until primary docs. Keep FACT/RUMOR visual treatments. Finishing stays Remotion+Juno; generative plates via Higgsfield (prove-this-session). Do not install a third NLE as hive face.

## Reference videos
When the user provides a reference (link or MP4): create `reference_breakdown` with shot duration, camera, framing, lighting, background, text/typography, object motion, transition, sound cue, information density, narrative job. Learn grammar; do not copy branding or exact creative. Prefer approve storyline/layout/copy before heavy animation; refine few hero scenes; reuse as references.

## Reusable digital sets
Maintain kits per company/industry (logos, product models/silhouettes, materials, camera presets, lighting, animation presets). Prefer reuse over regenerate. Store under a kits path + document inventory. Continuity > novelty.

## Story rules
1. Products are actors (close-up → transform → pull to chart/event).
2. Camera explains relationships (follow the money spatially).
3. FACT vs RUMOR/CONCEPT/UNCONFIRMED vs SCENARIO — persistent visual treatments; never let cinema make speculation look like history.
4. Keep product on screen while finance viz draws (one composition, not chart-mode cuts).
5. Data drives object scale/split/multiply (Services block, racks, customer share, margin layers, capital split).
6. Decision simulations are a signature (hold/lock forks × bull/base/bear → dollar outcomes → capital flow).
7. Director/critic loop: draft → inspect frames → fix legibility/timing/misleading viz → re-render. One-pass is not done.
8. Keep editable sources: .blend, Remotion components, timeline project, brand assets, narration, source-data JSON, chart data, visual decisions — not only the MP4.
9. Sound is its own layer (reveals, tension, flow cues, stingers) — Juno VO still required when Wealth audio lock is active.
10. Financial accuracy outranks cinematic drama.

## Pre-render shot plan
For each shot: story → narration → visual subject → assets → camera → data viz → motion → audio → transition → duration.

## Post-render QA checklist
Boring/repetitive layouts, bad framing, unreadable charts, weak motion, excess text, wrong products, unsupported claims, misleading scales, bad VO sync, FACT/RUMOR confusion.

## Wealth locks that still apply
Findings/report product (not teach-me unless asked), advise-only L4, never invent prices, live book when claiming live, mandatory Juno when that lock is on, equal holding depth / no NVDA centerpiece when covering the book.

## Anti-triggers
- Do not treat Remotion as the whole studio.
- Do not promise Blender/NLE shots when those layers are absent.
- Do not copy reference branding.
- Leisure / meme video farms = NO-SKILL.
- Do not treat Adobe/AI-NLE hype bookmarks as a hive tool switch.

# Wealth video narration and composition

## Highest-impact fails (do not ship with these)
1. **Empty composition** — meaningful content stuck in the upper quarter; vacant canvas. Fix: product, chart, or main figure is the largest element; fill the frame.
2. **Dead time** — long quiet gaps while graphics sit still. Flag holds **>2 seconds** unless a reveal/comparison earns them. Time the timeline to completed narration + reading time. Prefer a shorter cut over padded runtime.
3. **Narration that reads production instructions** — never speak: “Stamp Confirmed,” “Path Draws,” “Decision Sim,” “Preference Snaps,” “Catalyst chip,” “dense MG,” scene ids, or animation stage directions. Those belong only in animation direction fields.

## Three fields per beat (required)
| Field | Purpose |
|---|---|
| **Narration** | Natural speech: cause, consequence, uncertainty. Conversational. |
| **On-screen text** | Short labels, figures, evidence status (CONFIRMED/RUMORED/SCENARIO). |
| **Animation direction** | What moves/appears/stays — never spoken. |

Pipeline: research findings → conversational script pass that strips storyboard jargon, unexplained acronyms, repeated conclusions, and number dumps → design 3 representative scenes (product, chart, portfolio comparison) at readable size → assemble timed to VO cues → render-review gate.

## Visual hierarchy
- Preserve FACT vs speculation color discipline.
- Readable supporting text; restrained source line.
- No viewer-facing labels like `PATH · DRAWS` or `dense MG`.
- Stamps only for meaningful status changes — not decorative spam.
- Transitions carry the subject forward (silhouette continuity), not empty title interludes.
- Products need substantial screen space; concept/unannounced designs clearly labeled.
- Charts: proportional time axes (or label “Selected closing prices”); shared scales for scenarios; never let a counting animation disagree with the final probability; separate return ranges from probability weights; show all scenarios together when comparing.
- Decision sim: dollar outcomes for hold vs trim under same scenarios from verified position data — not a preference stamp alone.
- Capital flow: animate amount splitting; timeline advances with what evidence appears when.

## Story spine
Build around developing tension (e.g. great product vs priced-in expectations). Each visual answers curiosity the previous shot created. Finish with one decision, the strongest reason, and what observation would change it — do not triple-repeat the recommendation.

## Render-review gate (before ship)
Check: text size, wasted space, narration↔visual alignment, quiet intervals >2s, number labels vs chart geometry, whether each scene adds information. Review actual rendered frames/audio — not only the script.

## Pacing note
More slides/effects alone does **not** fix composition, dead air, or robotic VO. Prefer fewer, larger, narration-timed boards over stamp spam.
