# Existentialism: figure first, then the theme (clustered)

**Use when:** a task asks how to **place an existentialist claim** in the Saylor PHIL304 **undergraduate existentialism** school — which figure owns it, whether it is a definition of the movement or one thinker's slogan, how freedom/body/God/responsibility sit, or how Beauvoir and Du Bois are inside the map rather than optional.

**Do not use when:** reconstructing or taking a Saylor (or any) exam; PHIL102 logic; PHIL103 moral/political justice; PHIL203 environmental ethics; Descartes/Hegel rationalist surveys; LSAT; inventing ACE credit; sitting webcam ACE (this course has **none**); inventing PHIL104.

This is **one** skill. Nine live units, one argument: **most students already have a Sartre slogan; this course's pass is historical-by-figures — Unit 1 defines the movement without collapsing it into Sartre, then each named thinker keeps their own approach.**

## 1. Procedure — six checks

### Check A — Identity (always)

| Prompt smells like | Hand off |
|---|---|
| Validity / soundness / Venn / fallacy | **PHIL102** |
| Rawls / Kant / rights / markets as justice | **PHIL103** |
| Anthropocentrism / Muir / NEPA | **PHIL203** |
| Take / reconstruct the Saylor final | **refuse** |
| Which figure owns this existential theme | **this skill** |

**Named live failure mode:** defining the whole course as **Sartre's "existence precedes essence."**

### Check B — What the movement is (Unit 1)

Define without stealing Unit 7: concrete individual; not a rational creature in a well-designed universe; body and circumstance; freedom/responsibility/God as *questions*. Pascal is **back-trace**, not a unit title.

### Check C — 19th-century seats (Units 2–4)

Keep separate: **Kierkegaard** (faith/leap/individual before God) ≠ **Dostoevsky** (literary-philosophical, underground/freedom/suffering) ≠ **Nietzsche** (God's death, affirmation, not a Camus footnote).

### Check D — Du Bois and Heidegger (Units 5–6)

**Du Bois** is the live persons-of-color seat (CLO 7). **Heidegger** is not "German Sartre" — Being, thrownness, authenticity as *his* jobs; confirm live labels on login. Do not skip Unit 5.

### Check E — French cluster (Units 7–9)

**Sartre:** existence precedes essence; bad faith; freedom as burden — **his** seat.
**Beauvoir:** feminist existentialism; situation of woman; CLO 7. Not PHIL103 virtue ethics.
**Camus:** the absurd; revolt vs suicide/leap — **his** seat, not Kierkegaard's leap and not Sartre's bad faith.

### Check F — Compare / underrepresented (CLOs 5–7)

If the prompt is "compare X and Y," name **two live figures** and the **theme** (freedom, God, body, responsibility, race, gender). If the prompt drops Beauvoir or Du Bois, **put them back**.
