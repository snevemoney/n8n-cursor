### Check B — Meaning, sources, necessary vs sufficient (when "what does this mean / is this a good definition / can I trust this source" is in play)

CLOs 1–3. Unit 1.

Name, in order:

1. **What critical thinking is.** Breaking claims down to underlying structure so we can see whether they are rational (SNLS Unit 1 residue). Not "being cynical." Not "having an opinion."
2. **Meaning analysis.** Literal vs implication; definitions; verbal vs factual dispute; **necessary vs sufficient**; ordinary-language imprecision. CLO 3 lives here.
3. **Sources (CLO 2).** Credibility and reliability processes — scholarly vs internet, peer review — **before** symbolizing. This is not COMM100's gatekeeper.

**Hand off Unit 2** if they want validity. Stay here for "what does this sentence mean, and is the source usable."

### Check C — Argument vs explanation, validity vs soundness, deduction vs induction (when "is this an argument / is it valid / is it sound" is in play)

CLO 4, CLO 8 overlay. Unit 2.

Name the **distinctions** before naming a fallacy:

1. **Argument ≠ explanation ≠ quarrel.** Premises intended to support a conclusion vs premises intended to explain why something already granted is so. Conclusion often precedes premises in ordinary language.
2. **Validity vs soundness.** Valid = conclusion follows. Sound = valid **and** true premises. Invalid ⇒ unsound. Valid + false premises ⇒ unsound, and the conclusion need not be false. True conclusion does not make an invalid argument valid.
3. **Deduction vs induction.** Deductive: if premises true, conclusion must be. Inductive: premises support, they do not guarantee. Analogical arguments are inductive (SNLS 2.4 residue).
4. **Visualization.** Mapping / arrows are Unit 2's CLO 8 job. Venn waits for Unit 4.

Quiz trap: **valid ≠ true.** **Sound ⇒ valid**, not the reverse. **Charity** when supplying hidden premises (SNLS) is a Unit 2 job, not a Unit 5 "straw man" reverse.

**Hand off Unit 3** for truth tables. **Hand off PHIL103** for "but is the conclusion just." Stay here for "argument, valid, sound, deductive or inductive."

### Check D — Sentential vs categorical/Venn (when "symbolize / truth table / all-some / syllogism" is in play)

CLO 6, CLO 8. Units 3–4.

Pick the **seat** before drawing:

1. **Sentential (Unit 3).** Small formal seat. Connectives; WFFs; truth tables; tautology / contradiction / contingency; "unless"; antecedent/consequent. **Cannot** capture "every" / "all" (SNLS 3.2.9). Not a proofs course (live intro: *small amount* of formal logic; SNLS: not elaborate inference-rule proofs).
2. **Venn / categorical (Unit 4).** A/E/I/O; two- and three-circle; existential commitment (universal does not imply particular); syllogism. Venn tests **validity, not soundness**.
3. **Do not run a truth table on a syllogism** or a Venn on a purely truth-functional conditional.

Quiz trap: **affirming the consequent / denying the antecedent are Unit 5 formal fallacies**, not Unit 3 valid forms (MP/MT). **"Most cooks…" is a Venn limitation**, not MP.

**Hand off Unit 5** for named fallacies. Stay here for "which formal tool."

### Check E — Formal vs informal fallacy, then science vs strategy (when "fallacy / bias / cause / creative solution" is in play)

CLOs 5, 7, 9. Units 5–7.

1. **Fallacies (Unit 5).** Classify **formal vs informal** first. Formal: denying the antecedent, affirming the consequent. Informal jobs (name why the inference fails; do not dump a catalog): straw man, ad hominem, begging the question, red herring, false dichotomy, slippery slope, appeal to authority/ignorance/people, gambler's fallacy, complex/loaded question, non sequitur. Cognitive biases (availability, representativeness, confirmation) are SNLS residue inside this unit.
2. **Scientific reasoning (Unit 6).** Empirical, often inductive, confirmation/disconfirmation, not "proved true." **Correlation ≠ causation.** Hypothetico-deductive method; Ockham as a *criterion*, not a proof; Mill's methods. This is **not** Unit 4's syllogism and **not** PHIL203's environmental values.
3. **Strategic / creative (Unit 7).** Pólya; classifying problems; decision under risk; creativity cycle. Novelty with **procedures**, not "logic is over."

Quiz trap: **fallacy-name bingo is not the pass.** **Gambler's fallacy is Unit 5 in the SNLS tree**, even though Van Cleave files statistical fallacies in an inductive chapter. **Confirmed ≠ true.** **Creativity is not a license to skip validity.**

**Hand off COMM100** for advertising-as-channel. **Hand off PHIL103** for justice. Stay here for "what kind of miss, or what method."

### Check F — Visualization, sources, real-world application (when "diagram it / is this source enough / apply this" is in play)

CLOs 2, 6–9. Course-wide.

1. **Visualization (CLO 8).** Unit 2 maps; Unit 4 Venns; Unit 6 causal diagrams / Unit 7 flowcharts. Name the **tool**.
2. **Sources (CLO 2)** can re-enter at application time — a valid argument from a junk source is still unsound if the premises fail.
3. **Real-world** (CLOs 6–9) means apply the *distinction*, not narrate PHIL103's case or COMM100's audience.

**Hand off ENGL101** for the paragraph. Stay here for "which distinction does the work."

## 2. Typical traps (encode these; they are the pass)

- **Argument ≠ explanation ≠ quarrel.** Unit 2. Do not grade an explanation as unsound.
- **Validity vs soundness.** Valid ≠ true. Sound = valid + true premises. Invalid ⇒ unsound. True conclusion does not rescue an invalid argument.
- **Deduction vs induction.** Must-follow vs support. Science (Unit 6) is typically inductive; syllogism (Unit 4) is deductive.
- **Formal vs informal fallacy.** DA/AC are *formal*. Straw man / ad hominem / begging the question are *informal*. Do not dump a list as the pass.
- **Sentential ≠ categorical/Venn.** "All/some/none" is Unit 4. Truth-functional connectives are Unit 3.
- **Necessary ≠ sufficient.** Unit 1, and again inside the conditional in Unit 3.
- **Verbal ≠ factual dispute.** Unit 1.
- **Correlation ≠ causation.** Unit 6. Common cause and accident are the named leaks.
- **Venn tests validity, not soundness.**
- **A small amount of formal logic ≠ a proofs course.**
- **Not PHIL103.** Justice / Kant / Rawls / value of a human life are the neighbor course.
- **Not COMM100.** Channel, audience, interpersonal/org/mass comm are the neighbor course.
