# Graduate financial management: package → TVM → capital → value (clustered)

**Use when:** a task asks how a manager should create shareholder value with the firm’s capital — how to read the financial package, how internal cost signals feed a decision, how to compute PV/FV and a cost of capital, whether to accept a project (NPV/IRR/PI/payback) at WACC, how free cash flow measures performance or prices a claim, or how to forecast the plan that funds those projects — in the Saylor BUS601 **graduate** financial-management school.

**Do not use when:** the job is reconstructing or taking a Saylor (or any) exam, dumping OpenStax / Boundless / Welch, running **BUS202** undergraduate principles-of-finance checklists (eight-unit intro corporate finance), **BUS103** GAAP journals / the accounting cycle / *constructing* the four statements, **BUS105** job/process/ABC / CVP worksheets / make-or-buy as a *course*, **BUS614** international finance, treating the free 70% certificate as **MBA601**’s 80% / 3-credit proctored exam, promising ACE/transfer credit, or CFA item-set coaching.

This is **one** skill. It is not "Unit 1 skill + Unit 2 skill…". BUS601’s seven live units are one argument: **management creates shareholder value** by being literate in cost and in the financial package, analyzing performance, discounting expected cash at a risk-priced cost of capital, spending only on projects whose incremental FCF clears that hurdle, and forecasting the plan that funds them.

## 1. Procedure — answer a graduate financial-management question in six checks

Run in order. Skip a check only if the user already constrained the frame.

### Check A — Identity, goal, overlay (always)

**The course question:** is the user asking for a **GAAP construction**, an **undergrad principles recap**, a **cost/CVP lab**, or a **manager’s capital decision** that is supposed to create shareholder value?

Live test: “journal this / close the books” is **BUS103**. “What is finance vs accounting, eight units of TVM-to-working-capital” is **BUS202**. “Break-even units / make-or-buy / split this variance” is **BUS105**. “Should we spend this capital, at what hurdle, given this package, and can we fund the plan” is **this skill**.

**Primary goal: maximize owner / shareholder wealth** (market value of equity) by investing the firm’s capital for a **positive return**. That is not “maximize this year’s net income,” not “maximize size,” and not “keep every stakeholder equally happy.” Liquidity, risk, ethics, and day-to-day operations constrain the path; they are not a second objective that replaces value.

Three decision types this school names (same split as undergrad PoF, spent here as the *manager’s* job):

| Decision | Asks | Later check |
|---|---|---|
| Investment | What real assets / projects do we buy? | E (NPV / FCF) |
| Financing | Debt, equity, or internals? | D–E (WACC / structure) |
| Planning / payout | Can we fund the path? Return cash or reinvest? | F (forecast / EFN) |

**Agency:** principal (owners) vs agent (managers). Also named: shareholders vs bondholders (equity likes upside; debt likes not being looted). Governance exists to make the wealth-max goal *believable*. SOX-as-taught is **course-era**, not 2026 legal advice. A CSR / stakeholder *ethics* write-up → **BUS200**.

**Level check:** if the prompt is actually undergrad homework in BUS202’s eight units, **hand off BUS202** and recap only. If it is MBA601’s proctored 80% / 3-credit exam, **refuse exam reconstruction**; this skill is the *content* overlay, not the degree exam.

If the prompt is journalize / adjust / close / *construct* an IS+BS, **stop and hand off BUS103**.

### Check B — Literacy and the package (when statements, ratios, cost signals, or “are we healthy” are in play)

CLO 1–4. You do not build the books here. You **read them to decide**. You also need enough **managerial** literacy to know that internal cost/price/profit numbers are a different question than GAAP.

**Financial vs managerial (Unit 1, literacy only):**

| | Financial (BUS103’s product) | Managerial (BUS105’s course; here an input) |
|---|---|---|
| User | External (investors, lenders, regulators) | Internal (managers) |
| Constraint | GAAP | No GAAP constraint; tailored to the decision |
| Time | Historical | Forward-looking |
| Object | The firm’s four statements | Cost, price, profit for a unit / product / project |

**Hand off BUS105** the moment they need job/process/ABC, a CVP worksheet, a variance split, or ROI/RI as responsibility accounting. Stay here for “this cost number changes the project CF or the operating plan.”

**Four statements, finance-side questions (CLO 2):**

| Statement | Time | Manager’s question |
|---|---|---|
| Income statement | Period | Did operations earn? EBIT is the operating-profit line capital budgeting starts from |
| Statement of retained earnings | Period | Did NI stick as RE or leave as dividends? |
| Balance sheet | Snapshot | What assets are we funding, and with whose money? |
| Statement of cash flows | Period | Where did cash actually move? (O/I/F) |

**Free cash flow** (CLO 6, named live) is what valuation and project analysis eat — cash operations could distribute without hurting the asset base. Accrual NI with negative operating cash is a warning, not a rounding error.

**Ratio families (always with a baseline — own history, peer, or industry):**

| Family | Asks | Survey examples | Manager use |
|---|---|---|---|
| Liquidity | Can we pay soon? | Current; quick | Working-capital overlay (Check F) |
| Asset management | Are assets working? | Inventory turns; DSO; TAT | Cash trapped in the cycle |
| Debt management | How much is borrowed? | D/E; TIE | Cost of capital / distress (Check D) |
| Profitability | Are we earning? | Margins; ROA; ROE | DuPont: **ROE = PM × TAT × equity multiplier** |
| Market | What is the claim priced at? | P/E; M/B | Valuation (Check E) |

Horizontal = trend. Vertical = common-size. A lone current ratio is a number. CLO 3 / 4: the analysis has to **change a decision** (live intro: plant, product, R&D, staffing, expansion).

Depreciation methods: enough to treat dep. as **noncash** on the SCF and as a **tax shield** in project CF. The journal → **BUS103**.

### Check C — Time value of money (the toolkit)

CLO 7. If money moves at different dates, you **cannot add the nominal amounts**. Graduate overlay: TVM is how you *apply* analysis to investment decisions, not a calculator course.

**Lump sums**

- Compound: **FV = PV (1 + r)^n**
- Discount: **PV = FV / (1 + r)^n**
- Simple vs compound: simple ignores interest-on-interest. More frequent compounding raises FV.

**Non-annual compounding:** periodic rate = r/m, periods = n·m. Effective annual: **EAR = (1 + r/m)^m − 1**. Compare products on EAR, not on the tattooed APR. Live intro’s credit-card / mortgage hooks live here as *applications*.

**Multiple cash flows:** move each flow to the *same* date, then add. If they are the same size, same gap, same r:

| Pattern | Intro formula (ordinary / end-of-period) |
|---|---|
| Ordinary annuity PV | PMT × [1 − (1+r)^(−n)] / r |
| Ordinary annuity FV | PMT × [(1+r)^n − 1] / r |
| Annuity due | ordinary × (1+r) |
| Perpetuity PV | PMT / r |

Yield / I/Y is the rate that prices the stream — this is the bridge to **YTM / cost of debt** (Check D) and **IRR** (Check E).

Do not paste a 12-key financial-calculator sequence unless the user asks. Show the relation, then the number. BUS202 owns the undergrad drill; recap, do not re-teach as a new science.

### Check D — Price the risk; price the capital (when required return, β, WACC, or “cheap debt” is in play)

CLO 8 (+ Unit 4). Capital has a cost. You cannot accept a project until you know what return you **owe**.

**Risk and return:**

- Stand-alone: expected return = Σ pᵢ rᵢ; σ as spread.
- **Systematic** (market; survives diversification) vs **unsystematic** (specific; diversification kills it). Do not promise zero risk.
- **β:** move vs the market. β=1 with the market; >1 amplifies; <1 dampens.
- **CAPM / SML: r = r_f + β (r_m − r_f)**. This *is* the required return that feeds cost of equity and, through WACC, NPV. If they hand you a “higher profit plant in a riskier country vs a safer smaller plant,” do not pick on profit alone — match the hurdle to the risk.

**Cost of capital:**

| Claim | Intro cost | After tax? |
|---|---|---|
| Debt | YTM / market rate on the bond (PV of coupons + PV of par) | **Yes:** r_d (1 − T_c) |
| Equity | CAPM or dividend-growth k | No |
| Preferred | dividend / price | No |

**WACC = w_e r_e + w_d r_d (1 − T_c)** (+ w_p r_p). Weights at **market** value. WACC is the NPV discount rate when project risk ≈ firm risk. A riskier project needs a higher hurdle, not the company WACC by default.

**Structure overlay:** mix of debt + equity. Tax shield vs distress. M&M as taught: perfect markets → structure does not change firm value; with taxes, interest is deductible; in reality, find a *balanced* structure. Pecking order: internal cash → debt → equity last. **Hand off BUS202** if they need the undergrad structure lab (M&M proofs, book vs market drills). Stay here for “this mix just changed the hurdle.”

### Check E — Spend and value: projects, FCF, claims (when “should we buy this,” NPV, or “what is it worth” is in play)

CLO 5 / 6. Capital budgeting **creates** the FCF that valuation **prices**.

**Process:** identify → estimate **incremental** CF → evaluate → select → monitor.

Relevant CF = future cash that **differs** with the project. Sunk is out. Cannibalization / synergies in. NWC up-front, recover at the end. Depreciation tax shield in. Financing CF (interest) stays **out** of project CF when you discount at WACC — don’t double-count.

| Rule | Accept if | Good at | Failure if used alone |
|---|---|---|---|
| **NPV** | NPV > 0 | Value added; the default when methods fight | Garbage CF / wrong r |
| **IRR** | IRR > hurdle | Intuitive % | Mutually exclusive scale/timing; multiple IRRs on sign-flipping CF |
| **PI** | PI > 1 | Ranking when capital is rationed | Same scale fights as IRR |
| **Payback** | Years < cutoff | Liquidity / “how fast am I out” | Ignores TVM and cash after cutoff (discounted payback is the patch) |

ARR is named on the MA side (OpenStax Vol. 2 ch.11). Do not require it. **Hand off BUS105** if the real question is make-or-buy, drop-a-line, or special order (relevant *operating* cost, not a multi-year project). Stay here for “does this long-lived project earn more than the cost of capital.”

**Valuation (Unit 6):** FCF is both a **performance measure** (CLO 6) and the input to a DCF. Bond price = PV of coupons + PV of par at y (this is also the cost-of-debt input). Stock intro default: **Gordon / constant-growth P₀ = D₁ / (k − g)** with g < k; no-growth = D / k. Enterprise vs equity as a named split if they ask what the *firm* is worth. Do not run Black-Scholes or a full LBO model unless asked.

### Check F — Plan and fund (when forecast, pro forma, “we’ll grow 40%,” or cash timing is in play)

Unit 7. A beautiful NPV does not save a firm that cannot make payroll or cannot raise the EFN.

**Pro forma / percentage-of-sales:** project the IS, plug the BS, read **external financing needed**. Forecast ≠ wish. Growth the firm cannot fund is not a plan.

**Cash budget** is timing (when cash actually moves), not a GAAP statement. BUS105’s *master budget* is an internal operating plan — different course.

**Working-capital overlay** (not a live unit title; login gap Unit 3 vs 7): NWC = CA − CL. Four named buckets from the undergrad neighbor: **cash, AR, inventory, AP**. CCC ≈ inventory days + AR days − AP days. Short-term sources: trade credit, bank lines, paper, factoring. Match maturities. Poor short-term management is a named reason firms die.

If asked “can we afford this growth / this project,” run Check E for the project *and* this check for the plan that has to fund it.

## 2. Worked micro-patterns

**"What is financial management / how is it not accounting?"**
Check A in one paragraph. Past vs decide-what-to-do. Shareholder-wealth goal. Hook: invest capital for a positive return, applied day-to-day. Name the overlays: BUS103 builds the package; BUS105 costs internally; BUS202 teaches the undergrad toolkit; this course *spends* them as the manager’s job.

**"Should we take this project / buy this plant?"**
Checks D–E. List incremental CF (including NWC and dep. shield). Discount at a hurdle that matches risk (WACC if firm-like). Report NPV first; IRR/PI/payback as supporting screens. If methods fight, say why and keep NPV. Then Check F: can we fund it.

**"What’s this bond / stock / firm worth?"**
Check E. Bond: PV coupons + PV par at y. Stock: DDM if a dividend path is given; otherwise say which input is missing rather than inventing g. Required k from CAPM if they gave β. Firm: FCF discounted at WACC, then subtract net debt for equity.

**"Is this firm healthy / should we lend or invest?"**
Check B with a baseline, then D (price vs book / CAPM required vs expected) and E (leverage + FCF). Profitable + negative operating cash is the trap.

**"How much should we borrow / what’s our hurdle?"**
Check D. Name the tax shield *and* distress. Compute WACC at two mixes only if they gave costs; don’t optimize a 40-line model.

**"We’ll grow 40% next year."**
Check F. 40% is a **goal**. Pro forma the package; read EFN. If EFN is large, the goal is not yet a plan (same instinct as BUS501’s goal-vs-strategy test, different object: *financing*).

**"FIFO or LIFO / journal this / close the books."**
Wrong course. **BUS103**.

**"Break-even units / make-or-buy / drop the line / split this variance."**
Wrong course. **BUS105**. (If they then ask “and should we buy the machine that replaces the line,” come back here for NPV.)

**"Walk me through undergrad TVM → WACC → working capital as eight units."**
Wrong course. **BUS202**. Recap a formula only if this prompt still needs it.

**"FX / Eurozone / emerging-market finance."**
