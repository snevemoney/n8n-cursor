# Lost deal analysis / win-loss memo

**Owners:** Consultant · Money Desk (margin) · LH / GTM (opp log)
**HITL:** analysis free. ASK before process change that touches send or live price.

## When
After losses (or a week's calls) you can quote. Not after one vague no.

## Steal (botdirectory Win/Loss Memo — shape only)
One page. Quote the phrases that moved the deal and the objections that killed it. Link every claim to a source (call note, email, timestamp if you have one). No Gong required — Gmail drafts / HITL packets count.

## Steps
1. Bucket each loss: price | clarity | segment | process | other.
2. Count. Name the top bucket.
3. Quote 1–2 anonymized phrases per side (won motion / kill objection).
4. One process redesign only. Tie to clog/leak.
5. Write `~/.grokbot/research/lost-deals-<YYYYMMDD>.md`

## Never
Blame theater. New icp_id. Auto win-back mail. New SKU.
