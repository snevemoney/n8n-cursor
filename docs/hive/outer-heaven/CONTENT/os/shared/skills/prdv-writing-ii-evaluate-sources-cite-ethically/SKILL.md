# Writing II: research process, evaluate, websites, cite ethically (clustered)

**Use when:** a prompt needs **ethical use of information** — find, evaluate, analyze, and integrate sources so the audience still trusts the writer (researcher, contractor, or journalist) — in the Saylor PRDV010 **Professional Writing II: Evaluating Sources and References** school (7 h). Live intro: currency, relevance, authority, accuracy, and purpose.

**Do not use when:** reconstructing exams; **PRDV002** (purpose/audience/channel *writing*); **PRDV009** grant proposals; **PRDV201** information literacy as a *course*; **ENGL*** composition (Publishing — do not write those packets); promising ACE; dumping APA/MLA manuals.

This is **one** skill. Four live units are one loop: **research process → evaluate sources → extra caution on websites → integrate and cite ethically.**

## 1. Procedure — four checks

### Check A — Identity overlay (always)

| Prompt smells like | Hand off |
|---|---|
| "Write the email / know the audience / pick the channel" | **PRDV002** |
| "Grant / RFP / funder" | **PRDV009** |
| "Information literacy as a *course*" | **PRDV201** |
| "Essay / composition" | **ENGL*** (Publishing) |
| "Is this source usable, is this website junk, how do I cite without stealing" | **this skill** |

**Primary goal:** use information ethically so the chosen sources make the writer look thorough and credible. Named failure mode: citing the first Google hit, or treating a website like a peer-reviewed article.

### Check B — Research process (when "where do I even start looking" is in play)

CLO 1 overlay. Unit 1.

**Explain the importance of checking your sources** sits on a reviewed **research process**. Encode the *job* (what the project is: paper, business report, article). Do not dump a 12-step library tutorial as live CLO language.

### Check C — Criteria framework (when "is this source any good" is in play)

CLO 2. Unit 2.

**Develop a criteria framework to evaluate, analyze, and rate sources.** Live intro criteria: **currency, relevance, authority, accuracy, purpose**. Use those five. CRAAP as a mnemonic is optional public residue — do not require the acronym. Do not freeze APPEAL/RADAR as live.

### Check D — Websites (when "I found it online" is in play)

CLO 3. Unit 3.

**Explain the special considerations involved in critically evaluating online sources.** Same five criteria, extra caution. Encode the *job* (what would make this page unusable).

### Check E — Integrate and cite ethically (when "how do I put this in the draft" is in play)

CLO 4. Unit 4.

**Describe how to integrate research into writing in an ethical manner.** Live intro: including **citing your sources**. Support the argument; don't steal. Not a license to dump APA/MLA chapter text — name the job (attribute, don't pass off).

## 2. Worked patterns (shape only)

**"Business report, three blog posts and one journal."**
Check A (this skill, not 002) then C (five criteria on each) then D (blogs as online) then E (cite; don't treat blogs as peer review). Audience = reliable contractor.

**"The Wikipedia page is current — can I cite it as authority?"**
Check C (currency vs authority) then D (website specials) then E (ethical integrate). Don't invent a live Saylor ban-list; encode the criteria.
