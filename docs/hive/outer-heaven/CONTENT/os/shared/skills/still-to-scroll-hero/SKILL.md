# Still to scroll hero

Sources: monokern bookmark; Qwen cinematic tape; cinematic playbook.

## When
Building the hero for a cinematic marketing site.

## Do
1. Two to four AI or client stills, not a 3D team.
2. Short motion clip, then Forge wraps scroll-scrub + muted loop + poster.
3. Reduced-motion static poster required.
4. Pair with motion-pipeline and cinematic-site-recipe.

## Don't
- WebGL/Three.js as the default hero
- Hire a 3D studio this cycle
- Ship without fail-the-build pass

## Batch-4 extract — Qwen 3.8 + Higgsfield roofing demo (`yt:0Yin3Er9DX0`) 2026-09-01

FACT from tape: local Qwen 3.8 27B (4-bit MLX) in **pi.dev** (Claude Code stand-in) + **Higgsfield** stills/video + Anthropic frontend-design skill as a slop-kill pass.

### Hive remap (do this)

1. Stills: Higgsfield (or client photos) — **same camera, one change** (tape: roof before/after).
2. Motion: one scrollable scene clip, then Forge wraps scroll-scrub + muted loop + poster ([cinematic-site-recipe](sand-workflow:cinematic-site-recipe)).
3. Compose in Cursor Cloud (not pi.dev, not local Qwen required). Daily desk = Grok + Cursor.
4. Slop-kill: Anthropic frontend-design skill / [design-tokens](sand-workflow:design-tokens) — strip emojis, white-on-white, generic AI layout. Fail-the-build pass.
5. Copy: client facts only ([assemble-normalize-fill](sand-workflow:assemble-normalize-fill)). No invented testimonials.

Local Qwen / Mac Studio MLX / pi.dev = optional lab card only ([local-private-agent-lab](sand-workflow:local-private-agent-lab)). Not required to ship.
