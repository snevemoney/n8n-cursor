# Graduate brand management: equity, audit, architecture (clustered)

**Use when:** a task asks how a firm should **build, measure, or manage brand equity** — which terminology/theory applies, how consumer-focused brand theory should inform the manager without becoming a CB course, how to audit equity and health (strategy vs tactics), which portfolio architecture (masterbrand / sub-brand), which strategy framework including SCA, or how research/macro, IMC positioning, CRM, UX, or technology change the brand-management job — in the Saylor BUS631 **graduate** brand-management school.

**Do not use when:** the job is reconstructing or taking a Saylor (or any) exam, dumping Keller/Aaker item banks, running **BUS203** undergraduate principles of marketing (mix / STP / IMC; branding as an *offering chapter*), **BUS630** graduate consumer behavior (choose / purchase / discard; **emotional branding is a BUS630 message CLO**), **BUS602** graduate marketing *management* (MBA602 / MMKT601 / MMGT602 / MEI602), **BUS632** digital marketing / advertising as a *course*, **BUS633** sales as a *course*, **BUS634** marketing research as a *course*, **BUS615** international marketing as a *course*, treating the free 70% certificate as **MMKT603** 80% proctored exams, promising ACE/transfer credit, inventing **MBA631 / MMGT631 / MEI631 / MMKT631**, or inventing a live Keller-pyramid / Interbrand-method stack.

This is **one** skill. It is not "Unit 1 skill + Unit 2 skill…". BUS631's ten live units are one argument: **brands exist to help the organization hit marketing and corporate goals — equity is an asset you build, measure, manage, leverage, and portfolio, not a logo you decorate.**

## 1. Procedure — answer a graduate brand-management question in six checks

Run in order. Skip a check only if the user already constrained the frame.

### Check A — Identity, overlay (always)

**The course question:** is the user asking for an **intro principles / mix / STP / packaging** answer, a **consumer-behavior** explanation (including **emotional branding as a message**), a **marketing-management** decision, a **digital-marketing course**, a **sales process**, a **research-methods** study, an **international-entry** plan, or a **brand-management overlay** that has to build, measure, and manage **equity as an asset** — including audit, architecture, and portfolio?

Live test:

|---|---|
| "What are the 4Ps / STP / IMC / packaging as intro" | **BUS203** |
| "Why this consumer chose / discarded; internal vs external; emotional branding as a *message*" | **BUS630** |
| "Run the marketing function / MBA marketing management" | **BUS602** / **MMKT601** / **MBA602** |
| "Paid media / SEO / ad ops as a course" | **BUS632** |
| "Sales funnel / quota / selling process as a course" | **BUS633** |
| "Survey design / research methods / capstone" | **BUS634** |
| "Country entry / global mix" | **BUS615** |
| "Build / measure / manage equity; audit the brand; masterbrand vs sub-brand; portfolio architecture" | **this skill** |

**Primary goal:** **brand equity as an asset** that is built, measured, managed, leveraged, and portfoliod so brands help the organization hit **marketing and corporate goals**. That is not "pass Keller," not "write the emotional ad" (**BUS630** CLO 8), and not "define the mix" as intro (**BUS203**).

**Named live failure mode:** treating brand as the **logo / the package / the one-shot ad** and skipping audit, architecture, health, and management over time / geography / segments.

**Named live job** (encode this; do not silently shrink it): utilities of branding; process of building brands; methods of measuring equity; ways to leverage equity; strategies in managing brand portfolios; management of brands **over time, geographic boundaries, and consumer market segments**.

### Check B — Terminology, theory, strategic principles (when "what is a brand / which terms / which theory" is in play)

CLO 1. Unit 1. CLO 4 starts here.

Apply **fundamental branding terminology** and **enhanced analytical skills theory**. Live syllabus: keep a **glossary**. Theory is a toolkit the manager uses, not a trivia list.

Tanner overlay (summarize): brand = name / picture / design / symbol that differentiates offerings; branding = the activities that create the brand and position it in consumers' minds; the offering (price / quality) has to support the position; the **brand manager** runs the brand as if it were its own business.

OpenStax overlay (summarize): brand as feeling + intangible asset with tangible value; **brand value** (financial asset at transaction) vs **brand equity** (additional value over a substitute). Do **not** freeze Keller's identity → meaning → judgments → resonance pyramid as live CLO language until login.

**Hand off BUS203** for intro brand-name-on-the-package. Stay here for "this graduate terminology, this theory, this brand-manager job."

### Check C — Consumer-focused brand theory: loyalty, preference, equity (when "why they stay / prefer / pay more for the brand" is in play)

CLO 2. Unit 2. CLO 3 overlays.

**Analyze the consumer-focused theory of brand management.** The consumer is in the title so the *brand manager* can build equity. Live unit title names three seats together: **loyalty, preference, and brand equity**.

OpenStax overlay (summarize, do not freeze as doctrine): preference as a behavior-leaning metric; loyalty degrees; lift / engagement / preference as *named public-school metrics* — **unconfirmed live**.

**Hand off BUS630** for learning / attitudes / groups / culture / choose-purchase-discard / **emotional branding as a message**. Stay here for "this consumer's loyalty and preference as *inputs to equity the brand manager measures*." Do **not** steal BUS630's emotional-branding CLO.

### Check D — Audit equity and health; strategy vs tactics (when "is the brand healthy / what is it worth / audit this asset" is in play)

CLO 3. Unit 3. CLO 6 starts.

**Measure a brand's equity and health** by analyzing the **differences and integration of brand strategies and brand management tactics**. The **brand audit** is a first-class live unit. Equity is an **asset you audit**, not a logo you polish.

Encode the *job*: what is healthy, what is strategy vs tactic, what strength / weakness / challenge the methodology will surface. Do **not** invent a named audit instrument (BrandZ / Interbrand / Keller CBBE worksheet) as live Saylor doctrine until login.

**Hand off BUS634** for research-methods as a course. Stay here for "this brand, this audit, this health reading."

### Check E — Portfolio architecture + SCA + strategy frameworks (when "masterbrand vs sub-brand / which brands to keep / is this defensible" is in play)

CLO 5. Unit 4. CLO 4 / Unit 5.

**Analyze a brand portfolio masterbrand and sub-brand architecture management.** Those two nouns — **masterbrand** and **sub-brand** — are live CLO language. Encode architecture of the *portfolio*, not "pick Oreo flavors."

Unit 5: **sustainable competitive advantage** as a **brand seat** (why equity is defensible over time). Live intro already named **management of brands over time**. CLO 4: brand managers **select effective frameworks** for brand strategy decisions.

Tanner / OpenStax overlay (summarize): brand extension vs new brand; cannibalization; line vs brand vs multi vs new-brand matrix. **Do not freeze that 2×2 as live CLO language.**

**Hand off BUS203** for intro brand-name-on-the-package. **Hand off BUS602** for marketing-management-as-a-course. Stay here for "this masterbrand, these sub-brands, this SCA, this framework."

### Check F — Research/macro, IMC positioning, CRM, UX, technology (when "trends / position the brand / CRM / experience / tech changed the job" is in play)

CLO 6 overlay. Units 6–10.

**Brand research and macro trends (Unit 6).** Evaluate strengths / weaknesses / challenges with an analytical methodology. Research *for the brand*, **not** BUS634 methods-as-a-course. Do not invent a live trend list as doctrine.

**Positioning using IMC (Unit 7).** Brand position expressed through an integrated message system. **Not** BUS203's IMC survey. **Not** BUS632 ad ops.

**CRM (Unit 8).** Brand relationship infrastructure — loyalty from Check C needs a system. **Not** BUS607 D3M/CRM-as-decision. Do not invent Salesforce as live CLO language.

**UX (Unit 9).** Brand touchpoint the manager is accountable for — not a CS wireframe course.

**Impact of technology (Unit 10).** How the manager's job changes, **not** how to run digital marketing (**BUS632**). Live intro already named geographic boundaries and segments as management dimensions; tech is why those expand. Do not invent a live stack (AI brand agents / NFTs / retail media) as doctrine.

**Hand off BUS632** for digital-as-a-course. **Hand off BUS634** for research-as-a-course. **Hand off BUS615** for international-as-a-course (geography here is a *brand-management dimension*). **Hand off BUS630** if they want the consumer's experience as CB. Stay here for "this brand's research reading, this position, this relationship system, this experience, this technology."
