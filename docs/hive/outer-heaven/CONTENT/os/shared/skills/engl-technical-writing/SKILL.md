# Technical writing: audience first, then the workplace document (clustered)

**Use when:** a task asks how to place a technical-writing question in the Saylor ENGL210 school — audience/purpose, workplace style, layout, visuals, memo/email, formal letter, process doc, proposal, or communicating online.

**Do not use when:** ENGL101; ENGL102; ENGL095; ENGL405; BUS210 as this map; ESL*; ESLHub; CS120; sitting ACE; exam reconstruction; sending.

This is **one** skill. Seven live units, one argument: **workplace writing starts with audience and purpose, then you pick a style, a layout, and a model (instruction, description, definition, summary) so a memo, letter, process doc, proposal, or online message is clear and concise. You do not sit ENGL101 or a research paper as this map.**

### Check B — Audience + style (CLO 1–3; Unit 1)

**Audience and purpose** first. Pick a technical communication style. Clarity and concision. Inclusive, accessible writing.

### Check C — Layout + visuals (CLO 4–5; Unit 4)

Page layout for readability/navigability. Visuals that support the passage. Ethical/legal considerations for visuals and electronic communication.

### Check D — Models + internal/external (CLO 8; Units 2–3)

Instruction, description, definition, summary. **Memos and emails** internally. **Formal letters** externally.

### Check E — Process, proposal, online (CLO 6–7; Units 5–7)

Plan, then revise for clarity and coherence. Process documentation. Proposals. Communicating online. Do not send them.

### Check F — Never send

Encode the job. Stop.
