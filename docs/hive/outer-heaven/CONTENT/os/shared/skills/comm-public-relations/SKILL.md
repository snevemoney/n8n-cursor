# Public relations: plan, then the right outlet, then ethics (clustered)

**Use when:** a task asks how to place a PR question in the Saylor COMM411 school — fundamentals, stakeholders, writing for PR, social media, ethical PR and crisis response, or PR careers.

**Do not use when:** ENGL210; COMM101; BUS203; PRDV107 as this map; ESL*; ESLHub; CS120; sitting ACE; exam reconstruction; sending a release or pitch.

This is **one** skill. Six live units, one argument: **PR is researched influence, not marketing-but-nicer — identify stakeholders, write the piece for the right outlet, keep ethics (including crisis), and do not send the release.**

- Label **school**. Public relations (Saylor COMM411). **15 h / 1.5 CEU.** LMS **793** (`/course/comm411`). ACE **N**. Cert **70% / 14-day / max 3**. Syllabus **2025-10-02 15:53**. Description: PR work in start-ups, international companies, political campaigns, social programs, personal development, outreach.
- Six **live** units: Fundamentals; Stakeholder Identification and Prioritization; Writing for Public Relations; Social Media and Public Relations; Ethical PR and Crisis Response; PR Careers and Development.
- Seven **live** CLOs.
- Rest family after ENGL405. Skip redo ARTH101 PHIL102–304. Stay off ESLHub CS120 Sci/Math. Chrome FREE (exam closes paused; do not sit BUS607). **Never send.**

### Check B — Fundamentals + plan (CLO 1–2; Unit 1)

Origins, purpose, methods. Research into a **thorough PR plan**. Named parallel: **RACE** (research–action–communication–evaluation).

### Check C — Stakeholders + writing (CLO 3–4, 6; Units 2–3)

Prioritize stakeholders. Communications that reach **commercial and social** campaigns. Media-relations **outlet + format**. Multicultural themes and images. Portfolio: background, position paper, news release, pitch letter — **do not send.**

### Check D — Social media (Unit 4)

PR on social channels. Same ethics. Still not a send.

### Check E — Ethics, crisis, careers (CLO 5, 7; Units 5–6)

Ethical principles in PR practice. Crisis **inside PR**, not PRDV107 as this map. Networking and job resources.

### Check F — Never send

Encode the job. Stop.
