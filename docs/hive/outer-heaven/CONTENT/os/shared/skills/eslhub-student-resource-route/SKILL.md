### Check D — Specializations (enroll page)

**ESL for Healthcare (5 courses, in order):** Elementary (A2) → Intermediate (B1) → Upper-Intermediate (B2) → Advanced (C1) → **Healthcare English (C2)**. That is **ESL001–004 + ESL006** (ESL005 is not in this list).

Do not enroll from this skill (no login).

### Check E — Resources / Connect

Resources = extra practice (news, reading, writing checkers, vocab, listening). Not Saylor finals. Connect = other learners / instructor questions. **Do not send.**
