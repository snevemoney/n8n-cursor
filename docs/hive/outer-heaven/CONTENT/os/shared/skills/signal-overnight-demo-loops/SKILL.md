## Classify (Researcher)
After ingest, label each high-signal item:
- **A BUILD** — product/app/dashboard/tool → Forge CloudAgent demo + Cloudflare/Origin preview
- **B MOTION** — Remotion/kinetic/faceless → Creative mp4 + stills validate
- **C STACK** — AI/tech feature for our stacks → Researcher minimal proof + tests
- **SKIP** — leisure, CAPTCHA/bypass, second-face installs, vanity views, NO-SKILL

Pick ≤1 A + ≤1 B + ≤1 C per night unless operator raises the cap.

## Lane contracts
| Lane | Builder | Morning sender | After approve |
|---|---|---|---|
| A BUILD | Forge + Cursor CloudAgent | Forge | `evenslouis.ca/work` project (HITL) |
| B MOTION | Creative Studio | Creative | owned motion library |
| C STACK | Researcher | **Researcher** (not Consultant) | merge into stack or park |

## Validate
Screenshots and/or video required. Motion needs **mp4** taste (not stills-only PASS). Stack needs runnable proof + test/receipt.

## Preview / ship
- Preview: Cloudflare Pages preferred when connected; else Origin/box static.
- Public `/` and `/work` adds = HITL only (live `/` HOLD).
- Building mode: morning links are CapEx proofs, not client sell.
