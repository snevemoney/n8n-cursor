# Composition II: research paper as an act of discovery (clustered)

**Use when:** a task asks how to place a Composition II question in the Saylor ENGL102 school — topic/thesis, internet and library research, annotated bibliography, argument/outline with sources, MLA draft, or polish of a research paper.

**Do not use when:** ENGL101; ENGL095; ENGL210; ENGL405; ESL*; ESLHub; CS120; sitting ACE; exam reconstruction; sending; five-unit collapse.

This is **one** skill. Six live units, one argument: **Composition II runs a research paper as discovery — topic, notes from web AND library, evaluate into an annotated bib, put sources to work, MLA draft without plagiarism, polish. Research is a tool, not a grade hoop.**

## 1. Procedure — six checks

### Check A — Identity

| Prompt smells like | Hand off |
|---|---|
| Four keys / paragraph basics | **ENGL095** |
| Conversation / PWR / academic essay as argument | **ENGL101** |
| Workplace memo / layout / visuals | **ENGL210** |
| American Renaissance | **ENGL405** |
| ESL levels | **ESL* — stay off** |
| Take the final / send | **refuse** |
| Research paper, annotated bib, MLA draft | **this skill** |

### Check B — Topic + process (CLO 1–3; Unit 1)

Pick a topic, working thesis, research questions, proposal, draft outline. Research is built into the writing process. Not ENGL101 PWR-as-the-whole-course.

### Check C — How/what/when/where/why (CLO 4; Unit 2)

**Internet-based AND physical-library** research. Notes. Not web-only.

### Check D — Evaluate (CLO 5–7; Unit 3)

Locate, evaluate, use. Quotes / paraphrases / summaries. **Synthesis.** Product: **annotated bibliography**.

### Check E — Draft + MLA + polish (CLO 6, 8–10; Units 4–6)

Put sources to work in an argument/outline. Draft with **MLA**, no plagiarism. Polish so the reader can follow. Do not send the paper.

### Check F — Never send

Encode the job. Stop.

## 2. Worked patterns (shape only)
