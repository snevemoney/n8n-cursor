# Proposal / change-order pack (G12)

## When
- Warm ask just got a yes and GTM needs a short written scope
- Client (or hive) asks for "one more thing" mid Rung 0/1
- Before any fee change, retainer upsell, or Forge expand

## SoT bands (CAD — do not invent)
- Rung 0: $750–1.2K · Rung 1: $1.5–3.5K
- Delivery ≤40% of fee
- Early retainer only after proof: $500–1K/mo (educator $3–10K/mo = UNVERIFIED stretch)
- Pain $ always UNVERIFIED until owner numbers

## Frozen proposal skeleton (one page)
1. **Constraint** (one sentence from Consultant POSITION)
2. **In scope** (≤5 bullets — config/SaaS preferred)
3. **Out of scope** (explicit: ads, chatbot-closer, full redesign, voice AI v1, CE/hive install)
4. **Fee + rung** (inside Money Desk band)
5. **DONE_WHEN** (≤60 days, measurable, no fake ROI)
6. **Change rule:** anything not listed = change order (below)

## Change-order rules
| Ask | Default | Notes |
|-----|---------|-------|
| Same-rung tweak (copy, one extra form field) | Absorb if hours still ≤40% | Log hours |
| New channel / SMS / voice / custom build | New line item or next rung | Recheck margin |
| Retainer add-on | Only after 30d rail-live | Early $500–1K/mo |
| "Full AI employees" suite | REJECT as first expand | Margin fail |

**Formula:** change fee ≥ estimated delivery hours × $100–150 floor (or bump to next rung band). If delivery would exceed 40% → HOLD, shrink scope, or raise fee via HITL — never "just squeeze it in."

## Outputs
- Short scope freeze note for operator + GTM
- APPROVE / HOLD / REJECT economics (Money Desk)
- Any fee/send change → HITL Operator (propose only)

## Anti-patterns
- Verbal yes with no out-of-scope list
- Absorbing Forge custom work into Rung 0
- Quoting educator retainers as ours
- Mutating CE deal fields or sending client docs
