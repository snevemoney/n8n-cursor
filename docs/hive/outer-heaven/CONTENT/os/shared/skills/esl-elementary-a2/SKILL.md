# Elementary ESL (A2): parts of speech, then read, then short write (clustered)

**Use when:** a task asks how to place an elementary ESL question in the Saylor ESL001 school — 8 parts of speech, basic word order, comprehension of non-fiction, academic SAE vocab strategies, or a short cohesive description of a routine job/academic activity.

**Do not use when:** ENGL* (Publishing); ESL002 intermediate or higher; ESLHub; CS120; sitting ACE; exam reconstruction; sending any draft.

This is **one** skill. Four live units, one argument: **most students already have a phrase-book story; this course pass is A2 — grammar-in-sentences, then reading skills through reading-to-write, then a short ordered description.**

## 0. Hygiene

- Label **school**. Elementary ESL / **A2** (Saylor ESL001: Elementary English as a Second Language). **18 h / 1.8 CEU.** LMS **1279** (`/course/esl001`). ACE **N**. Cert **70% / 14-day / max 3**. Syllabus **2025-10-03 10:31**. Description: new words; active reading, grammar, and writing strategies to read and write English better at A2.
- Four **live** units (all reading-titled): Reading Skills; Reading to Comprehend; Reading to Improve; Reading to Write.
- Four **live** CLOs (parts of speech + word order; non-fiction comprehension; academic SAE vocab strategies; short cohesive descriptions in correct sentence order).
- Next: **ESL002**. Stay off ENGL* and ESLHub until 001–006 are in. Stay off CS120. Chrome FREE (exam closes paused; do not sit BUS607). **Never send.**

## 1. Procedure — six checks

### Check A — Identity

| Prompt smells like | Hand off |
|---|---|
| College composition / literature | **ENGL* — Publishing; stay off** |
| Intermediate or higher ESL | **ESL002+** |
| ESL resource hub | **ESLHub later — packet only** |
| Take the final / ACE / send | **refuse** |
| A2 sentences, basic reading, short work/school description | **this skill** |

### Check B — Grammar in sentences (CLO 1; Unit 1)

Eight parts of speech to create **basic sentences** that follow **basic word order**. Intro: recognize each part and why using them correctly improves communication. Not an ENGL grammar course.

### Check C — Comprehend (CLO 2; Unit 2)

Basic comprehension strategies on **non-fiction** texts. Active reading.

### Check D — Improve / vocab (CLO 3; Unit 3)

Vocabulary development strategies: recognize and **collect** Standard American English terms commonly used in **academic contexts**. Collect ≠ dump a dictionary.

### Check E — Reading to write (CLO 4; Unit 4)

Generate **short, cohesive, basic** descriptions of **routine job- or academic-related activities** in **correct sentence order**. Short. Cohesive. Ordered. Not an essay.

### Check F — Never send

This desk does not send the description, the email, or the homework. Encode the *job*. Stop.

## 2. Worked patterns (shape only)

**Is this a noun or a verb?** Check B. Then put it in basic word order.

**I do not understand this article.** Check C non-fiction strategies. A2, not ENGL close-reading.

**Which words should I keep?** Check D academic SAE collect.

**Describe my job / my class.** Check E short cohesive description in sentence order. Do not send it.

**ESL001 or ESL002?** A2 elementary → this skill. Intermediate → ESL002.

**ESL001 or ENGL?** Second-language A2 → this skill. Stay off ENGL*.
