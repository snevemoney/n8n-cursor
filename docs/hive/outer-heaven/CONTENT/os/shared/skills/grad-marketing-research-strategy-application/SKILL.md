# Graduate marketing research: design, sample, analyze, present (clustered)

**Use when:** a task asks how a firm should **conduct or evaluate marketing research** so a marketing decision is data-driven — which ethics/purpose apply, how to write the project goal and plan, how to operationalize variables, which research design fits the goal, which sample matches the target market, how to collect and prep, which quantitative or qualitative analysis, which limitation must travel with the finding, or how the recommendation should hit the 4Ps / marketing process — in the Saylor BUS634 **graduate** marketing-research school (MMKT capstone overlay).

**Do not use when:** the job is reconstructing or taking a Saylor (or any) exam, dumping Malhotra/Qualtrics/panel item banks, running **BUS203** undergraduate principles of marketing (mix / STP / IMC; research as an *information chapter*), **BUS630** graduate consumer behavior (choose / purchase / discard; informing strategy is a BUS630 unit), **BUS631** graduate brand management (equity / audit / architecture; brand research is a BUS631 unit), **BUS602** graduate marketing *management* (MBA602 / MMKT601 / MMGT602 / MEI602), **BUS632** digital marketing / advertising as a *course* (claimed by other), **BUS633** sales as a *course* (claimed by other), **BUS615** international marketing as a *course*, **BUS204** stats-as-a-course, **BUS607** D3M as a *course*, treating the free 70% certificate as **MMKT610** 80% proctored exams, promising ACE/transfer credit, inventing **MBA634 / MMGT634 / MEI634 / MMKT634**, buying survey panels, or inventing a live SPSS/regression / grounded-theory stack.

This is **one** skill. It is not "Unit 1 skill + Unit 2 skill…". BUS634's eight live units are one argument: **insights exist to change a marketing decision — you conduct and evaluate the study (ethics → plan → operationalize → design → sample/collect → quant/qual → limitations → present/recommend), not decorate a deck or buy a panel.**

## 1. Procedure — answer a graduate marketing-research question in six checks

Run in order. Skip a check only if the user already constrained the frame.

### Check A — Identity, overlay (always)

**The course question:** is the user asking for an **intro principles / mix / STP** answer, a **consumer-behavior** explanation, a **brand-management** overlay (including brand research as a *unit*), a **marketing-management** decision, a **digital-marketing course**, a **sales process**, an **international-entry** plan, a **stats course**, a **D3M** decision, or a **research-process overlay** that has to conduct and evaluate a study so a marketing decision is data-driven?

Live test:

| Prompt smells like | Hand off |
|---|---|
| "What are the 4Ps / STP / IMC as intro" | **BUS203** |
| "Why this consumer chose / discarded; internal vs external; emotional branding as a *message*" | **BUS630** |
| "Build / measure / manage equity; audit the brand; masterbrand vs sub-brand" | **BUS631** |
| "Run the marketing function / MBA marketing management" | **BUS602** / **MMKT601** / **MBA602** |
| "Paid media / SEO / ad ops as a course" | **BUS632** |
| "Sales funnel / quota / selling process as a course" | **BUS633** |
| "Country entry / global mix" | **BUS615** |
| "t-test / regression as a *stats course*" | **BUS204** |
| "Bias vs intuition / CRM-as-decision" | **BUS607** |
| "Design / sample / collect / analyze / limit / present this marketing study" | **this skill** |

**Primary goal:** **data-driven marketing decisions** produced by a study you can defend (ethics, plan, operational definitions, design, sample, analysis, limitations, recommendation). That is not "pass Malhotra," not "buy a panel," not "why they feel" (**BUS630**), and not "define the mix" as intro (**BUS203**).

**Named live failure mode:** running a survey (or buying a panel) without ethics, operational definitions, a design that fits the goal, a sample that matches the target, limitations, or a recommendation that touches the marketing process / 4Ps.

**Named live job** (encode this; do not silently shrink it): process + methods + real-world applications; insights across 4Ps, micro/macro, customers; uncover preferences; test products; pre-test messaging.

**Level check:** if the prompt is actually undergrad homework in BUS203's principles units, **hand off BUS203** and recap only. If it is BUS630 CB homework, **hand off BUS630**. If it is MMKT610's proctored 80% exam, **refuse exam reconstruction**; this skill is the *content* overlay, not the degree exam. If they name **MBA634 / MMGT634 / MEI634 / MMKT634**, say those codes were **not found** — twin is **MMKT610 only** (capstone after core).

### Check B — Ethics, purpose, terminology, plan (when "why research / is this ethical / which terms / what's the brief" is in play)

CLO 1. CLO 2. Units 1–2.

**Describe the nature, purpose, value, and ethics of research in the marketing decision-making process.** Then **create a marketing research project goal and plan outline utilizing terminology and concepts.** Ethics is a live CLO — encode it. Terms exist so the plan can be written.

Tanner overlay (summarize): MIS vs market intelligence vs marketing research; managers need evidence. OpenStax overlay (summarize): research-plan steps; ethical issues — **unconfirmed live wording**.

Do **not** invent a live Saylor glossary (construct / reliability / validity / Likert) as doctrine until login.

**Hand off BUS203** for intro vocabulary-as-a-chapter. Stay here for "this graduate ethics/purpose, this project outline, these terms in service of the plan."

### Check C — Measurable outcomes and operational definitions (when "what exactly are we measuring / what's the goal" is in play)

CLO 3. Unit 3.

**Create research goals, objectives, and operational definitions of variables.** A goal you cannot measure is not yet a research goal. Variables have to be operationalized before design/sample. This is the live unit intro books fold into "define the problem."

Do not invent a live SMART-objectives template as doctrine until login.

**Hand off BUS204** if they want measurement-as-stats. Stay here for "this marketing variable, this operational definition, this measurable outcome."

### Check D — Research design (when "what kind of study / experiment vs survey vs qual" is in play)

CLO 4. Unit 4.

**Create research designs appropriate for marketing research goals.** Design follows the goal from Checks B–C — not "pick a survey because that is what we always run."

Tanner overlay (summarize): exploratory / descriptive / causal; primary vs secondary. **Do not freeze that triad as live CLO language.** Name the *job*: the design must fit the goal.

**Hand off BUS630** if they want the consumer's decision process as a course. **Hand off BUS632** if they want digital-analytics-as-a-course. Stay here for "this goal, this design."

### Check E — Sampling, collection, prep (when "who / how many / how do we gather / is the file ready" is in play)

CLO 5. CLO 6. Unit 5.

**Apply sampling strategies appropriate for target markets.** **Apply different data collection methods and prepare data for analysis.** Sample must match the **target market** named in the goal; collection methods are plural; **prep** is first-class.

Do not invent a live n=/quota/panel-vendor doctrine. **Do not buy a survey panel.** This course is free.

**Hand off BUS203** for intro "survey the market" as a bullet. Stay here for "this target, this sample, this collection, this prep."

### Check F — Analyze (quant + qual), limitations, present, marketing-process impact (when "what do the data say / what's the caveat / what should marketing do" is in play)

CLO 7–10. Units 6–8.

**Quantitative (Unit 6 / CLO 7).** Apply **various statistical tools**. Tools in service of the research question. Do **not** invent a live SPSS/regression/chi-square stack as doctrine until login. **Hand off BUS204** for stats-as-a-course. **Hand off BUS607** for D3M-as-a-course.

**Qualitative (Unit 7).** First-class live unit. **No dedicated CLO line** — encode from the title. Do not invent grounded theory / NVIVO doctrine until login. **Hand off BUS630** if they want attitudes / emotional branding as CB.

**Limitations (CLO 8) stay separate from present findings (CLO 9).** Presenting without limitations is the named failure mode. Unit 8 also **makes recommendations**.

**Impact (CLO 10).** Explain how research impacts **various aspects of the marketing process**. Live intro already named 4Ps, micro/macro, customers, product tests, message pre-tests. Findings exist to change a decision, not to decorate a deck.

**Hand off BUS602** for marketing-management-as-a-course. **Hand off BUS612** for comms-as-a-course. **Hand off BUS631** if they want a brand audit. Stay here for "this study, these findings, these limitations, this recommendation, this 4Ps impact."
