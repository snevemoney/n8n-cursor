# HRM staffing-cycle checks (clustered)

**Use when:** a task asks how an organization gets, shapes, pays, keeps, and legally protects people — job analysis, KSAs, recruiting, selection, training, succession, performance appraisal, compensation/benefits, OSHA/wellness, unions, or employee relations — in the standard undergrad HRM school.

**Do not use when:** the job is reconstructing or taking a Saylor (or any) exam, dumping Dessler/Noe/Mondy, running BUS208 POLC as if it were HRM, running BUS209 motivation/group-process models as the spine, treating the prompt as BUS401 strategic leadership or BUS200 business ethics, coaching SHRM-SCP/PHR, or writing a union-busting / discrimination-concealment playbook.

This is **one** skill. It is not "Unit 1 skill + Unit 2 skill…". BUS301's eight units are one argument: **HRM = strategically allocating human capital through a legal staffing cycle**, done by HR *and* line managers together.

## 0. Hygiene

- Label **school**. This is the **standard undergraduate HRM intro** (Saylor BUS301; Saylor *Human Resource Management* v1.0 CC BY-NC-SA 3.0). Spine = seven functions: staffing, workplace policies, compensation and benefits, retention, training, employment laws, worker protection. It is not the only HR theory (critical HRM, Marxist labor-process, SHRM competency bodies). Say so if the user is not inside this course.
- Label **claim vs data**. 2012-era health-care dollar figures, "90% leave because of the job/manager/culture/environment," baby-boomer retirement projections, Facebook-minutes productivity claims, pre-2023 affirmative-action doctrine (*Fisher v. Texas* is still on the live guest unit), and gender-wage-gap snapshots are **course-era illustrations**. Re-fetch if the user needs current law or numbers.
- HRM ≠ the HR department ≠ management ≠ leadership ≠ OB ≠ employment-law practice. This school uses all of them as neighbors; it does not treat them as synonyms.
- Neighbor courses — **do not merge:** **BUS208** is POLC (the manager's job; this intro says BUS208 already covered "basics of managing human capital"). **BUS209** is OB (individual/group/org behavior). **BUS401** is strategic leadership. **BUS200** is business ethics. Unit 8.3's Enron/code-of-conduct overlay is not BUS200.
- No exam items. No all-rights-reserved chapter dumps. CC OER: summarize.

## 1. Procedure — answer an HRM question in five checks

Run in order. Skip a check only if the user already constrained the frame.

### Check A — Strategic HR + legal frame (always)

**HRM** is the process of employing people, training them, compensating them, developing workplace policies, and developing strategies to retain them. Teaching contrast: **administrative HR** (payroll, forms, birthdays) vs **strategic HR** (right people, right job, right time, aligned to the business plan). Live Saylor line: organizations keep a competitive advantage by holding resources others lack; the right employees are that resource.

**Who does it:** an HR department *and* every line/team manager. Cooperation is the point. Title VII (1964) + EEOC is the origin story this school uses for why "strategic" HR is not optional.

Before naming a staffing tactic, name the **constraint**:

| Frame | Ask | Typical tools in this school |
|---|---|---|
| Strategy | What work must exist for the plan to hit? How many people, which KSAs, when? | HR plan tied to revenue/headcount; job analysis; competency model |
| EEO / diversity | Does this decision treat people fairly in employment-related activity? | EEOC; Title VII and sibling statutes; diversity as production/retention claim (course-era — re-fetch numbers); inclusion/belonging as culture, not a poster |
| Affirmative action | Is this a historical-remedy / contractor / admissions-adjacent issue? | Live unit still teaches *Fisher*. **Current U.S. doctrine has moved** (flag and re-fetch; do not give 2012 answers as 2026 law) |
| Culture / ethics / CSR | Will this practice survive daylight? | Culture as constraint on staffing; ethics as fairness + confidentiality in pay/labor/discipline. Not BUS200's full ethics stack |

If asked "what is HRM / why do we have HR?," answer Check A in one paragraph, then offer the cycle (Checks B–E). Do not start with a recruiting tactic.

### Check B — Staffing: job analysis → recruit → select

Do not post a job, then reverse-engineer the work.

1. **Job analysis** translates the role into tasks, context, and **KSAs** (knowledge, skills, abilities). Output is a **job description** (what the job is) plus specification (what the person needs). A **job posting** is a marketing artifact of the description — overlap, not identity. Sample JA questionnaires / description figures live in the OER recruitment chapter; summarize, do not dump.
2. **Attract.** Internal vs external; employee referrals; recruiting firms; web/job boards; **social media as employer brand** (deliberate or it damages culture/brand). Live unit flags virtual interviews as their own failure mode (tech, fairness, rapport).
3. **Select the job, not the pile.** The school’s warning: the interview is weak because it is too subjective. Pair it with structured devices: résumé validity/reliability checks, behavioral and situational interviews, selection tests, work samples, background checks. Validity and reliability are in-scope; I-O psychometric derivation is **not** (that is not this course).
4. **Bias is a liability**, not a personality quirk. Compiling common applicant information is the school’s anti-prejudice move. Personal preference that is not job-related is how you buy a charge.

Dunning-Kruger shows up here as an assessment obstacle (poor performers cannot self-correct). Use it to justify **better KSA measurement**, not as a dunk on the candidate.

If asked "how do we hire X?," walk JA → posting ≠ description → sourced pool → structured select → offer. Name the EEO constraint from Check A on the posting and the interview.

### Check C — Develop and appraise

Hiring without this check is renting a résumé.

**Training / development.** Inform new members of the actual job; then continuous improvement so the human capital stays current. Live unit: effective T&D is a **recruitment and retention tool**, not a cost center. Disney-as-illustration (position training + ongoing development + tuition reimbursement) is a **course-era case** — use the mechanism (specific job training + growth path), not the brand. Counter-reading on the same unit: formal "push" training can waste money; work-driven learning culture may beat a catalog of courses. Pick from the *job*: regulated/safety-critical work still needs formal training; knowledge work may not.

**Career and succession planning** maps growth and builds the bench. Even if the employer has no plan, the school still wants the individual to have one.

**Performance management ≠ annual form.** Set expectations, track, reward when met; else you have no honest standard (this is the HR version of BUS208 controlling — do not import the whole POLC stack). Failure modes named in the live unit:

- **Leniency** — too nice; avoids confrontation
- **Halo** — one bright spot (hit quota) stands in for the whole job
- Irrelevant rater bias

**360-degree** review (peers/reports rate managers too) is in-scope as one system among many; match the system to culture/strategy. **Agile PM** (relationship-based, frequent) is on the live unit as a contemporary overlay — do not treat it as the only modern answer.

Appraisals must use **pre-established criteria**. Discipline and termination without a communicated policy is how you buy a wrongful-termination fact pattern. This school wants the policy *before* the incident.

If ability is missing, train or redesign the job (Check B). If the environment is the constraint, do not "appraise" a broken printer.

### Check D — Compensate (direct / indirect / non-financial)

Pay is often the largest overhead line. The teaching objective of a compensation plan: **attract, motivate, retain**.

Always split:

| Type | Examples in this school |
|---|---|
| **Direct financial** | Wages, salary, incentives, bonuses, commission, team incentives, profit/gain sharing |
| **Indirect financial** | Health, retirement (**401(k) vs 403(b)** as employer-sponsored plans), stock, tuition, child care |
| **Non-financial** | Work itself, recognition, schedule, culture, safety, voice |

Team rewards require **trust** already in the culture; otherwise they punish the wrong people. Strategic compensation = design the mix to the talent you are trying to buy, under the **pay statutes** this course flags (minimum wage / equal pay / benefits regulation — name the constraint, re-fetch current numbers). Executive-vs-employee pay gap is in-scope as a design tension (align exec pay to firm performance) — not as a manifesto.

OER teaching claim worth keeping: **managers over-attribute quits to pay.** Check the job, the manager, culture fit, and environment before throwing money at hygiene. That is a Check C / Check E problem dressed as a Check D problem.

Retirement education (not just offering the plan) is on the live unit as an employer move.

### Check E — Protect and relate (safety, labor, employee relations)

From the live unit: send people home the way they arrived.

**OSHA (1970)** is the floor. Every workplace has industry-specific standards; inspections are a real process, not a poster. Culture of safety beats a binder. Named hazards in the OER/live mashup: stress, substance abuse, workplace violence. **Wellness / EAP** programs are taught as performance and cost tools (fewer sick days, retention, ROI) — treat dollar-ROI clips as illustrations. COVID-era wellbeing readings are on the live unit; use the mechanism (employer is in the wellbeing business now), not 2020 as current events.

**Labor relations.** Unions exist because efficiency / **equity** / **voice** got out of balance and the employer appeared to hold all the cards. In-scope: why unions form, major labor acts (teaching level), unionization process, collective bargaining, grievance administration. Not a union-avoidance clinic. Not BUS403 negotiations as a full course.

**Employee relations.** The subfield that prevents and resolves workplace challenges: poor-performance handling, discipline, policy communication, awareness of rules. Efficiency = goals with least resource (employer *and* employee have a version). Equity = stable and fair, even though the firm is not a democracy. Voice = open door, listening, anonymous complaint path. Trust between manager and employee is named as a performance condition.

**HR ethics overlay (not BUS200):** codes of conduct actually disseminated and followed; confidentiality on pay and cases; Enron as a named failure of org ethics. If the prompt is a full ethical-decision framework, send it to BUS200. If it is "does this staffing/pay/discipline practice survive Title VII + our code?," stay here.

## 2. How to answer

- Start from Check A unless the user already named the legal/strategic frame. A recruiting tactic with no job analysis and no EEO constraint is not an answer in this school.
- Use the table the check provides. Do not recite all five checks if only one is in play.
- Line manager vs HR: say who owns the move. This school refuses the "HR will handle it" shrug *and* the "I don't need HR" shrug.
- Neighbor courses: **BUS208** if the question is really POLC (plan/organize/lead/control the unit). **BUS209** if it is really attitudes, perception, group process, or culture-as-assumptions. **BUS401** if it is leader vs manager / change-as-capstone. **BUS200** if it is ethics-as-ethics. **BUS205** if it is a contracts/torts problem that only happens to involve an employee.
- Stop at undergrad HRM manager level. No exam keys, no "what will be on the Saylor final," no Dessler dump, no SHRM body-of-competency recitation.

## 3. Worked micro-patterns

**"What is HRM / why isn't this just payroll?"**
Check A. Administrative vs strategic. Seven functions. Title VII as the reason "treat people fairly" is a business system, not a vibe. Point at the cycle (B–E).

**"Write the job / hire someone."**
Check B. JA → KSAs → description vs posting → source → structured select. Tag Check A (EEO on the posting and the interview). Do not start with a LinkedIn ad.

**"They aren't performing."**
Check C identity: ability vs role perception vs environment vs motivation-to-the-*job-standard*. If no pre-established criteria, you do not have an appraisal, you have a complaint. Leniency and halo are rater bugs. Policy before discipline.

**"What should we pay / what benefits?"**
Check D split (direct / indirect / non-financial). Attract-motivate-retain as the test. Name the statute constraint. If they are quitting, test the OER claim that pay is not the real reason before raising the band.

**"Is this legal / is this safe / should we unionize?"**
Check A + Check E. EEOC/Title VII for employment decisions; OSHA for physical and health hazards; labor acts + bargaining/grievance if a union is in play. Efficiency/equity/voice as the diagnostic when there is no union yet.

**"Diversity problem."**
Check A, not a poster. Legal floor (EEO) is not the same as a diversity strategy. Live unit claims a production/retention correlation — label as course-era and re-fetch. Do not import BUS209's culture-as-assumptions stack unless the user wants that school.

## 4. Refuse / redirect

- Exam reconstruction, item dumps, or "what will be on the Saylor final."
- Verbatim Dessler, Noe, Mondy, or any all-rights-reserved textbook. CC OER: summarize only.
- BUS208 POLC, BUS209 OB, BUS401 leadership, or BUS200 ethics as if they were this course.
- SHRM-SCP / PHR / SPHR item banks (OER mentions HRCI certs as a career path, not as this course's exam).
- Exploit-adjacent requests: how to hide discrimination, dodge OSHA, bust a union illegally, or rig an appraisal to fire a protected employee. Redirect to lawful process (policy, documentation, EEO, bargaining) or refuse.
