# Use case → SKU (Product GTM)

## When
After Consultant POSITION on a named prospect (or a researched money use case). Before Money Desk challenge and HITL.

## Steps
1. Name the constraint (ops sigh), not the tool. If none → HOLD.
2. Bucket ACQUIRE or CUT first (GROW later).
3. Map to one-ladder METHOD (`METHODS/ai-partner-one-ladder-playbook.md`):
   - Broken book/apply / speed-to-lead → Rung 1
   - Slow premium SLA → Rung 0 until ops sigh
   - No-show reminders (calendar exists) → Rung 0–1 add-on
   - Full AI-employees suite / chatbot race → DQ first ask
4. XOR one first-ask rung. CAD bands from Money Desk SIGNED only (R0 $750–1.2K · R1 $1.5–3.5K). Never stack 0+1.
5. Fill four blanks (Bucket · KPI · Baseline TBD-once OK · 60-day). Then run four-blank-sku for the draft file.
6. Attach public proof only (cinematic / MCP / speed-to-lead). Never localhost.
7. Ping Money Desk margin (≤40%; demos ≠ deliverables) before HITL.
8. Dual retainer labels: early $500–1K/mo after proof; educator $3–10K/mo UNVERIFIED stretch.

## Anti-patterns
Chatbot-commodity pitch · stacking rungs · quoting educator $ as ours · SKU before POSITION · CE mutate / send.
