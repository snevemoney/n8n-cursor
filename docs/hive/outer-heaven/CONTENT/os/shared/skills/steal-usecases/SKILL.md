# Steal usecases (catalog only)

**Owner:** Researcher. Remap of "Use Case Directory Curator" — **catalog only**. Consultant / Product GTM may later run `use-case-to-sku`. Researcher **stops at the catalog**.

## When
After a video L2 **or** a bookmark true-read. Also when a packet names machines but the one steal sheet was not appended.

Thesis-only = not done. SKU-only (a four-blank or price with no catalog row) = not done.

## Recipe
1. Find the **one** steal sheet already in play. If present, prefer `CONTENT/watch-later/STEAL_SHEET.md`; else a dated `watchlater-*/STEAL_APPEND.md` under research. Do not fork a second sheet. If neither exists, write the rows in the current packet and say so — do not invent a vault path as a required step.
2. Extract machines from the tape / cluster. **Bookmarks = clusters**, not one row per tweet.
3. Append **one row per machine** (not per video, not per tweet):

   | field | meaning |
   |---|---|
   | machine | the job, in operator language |
   | who sighs | the person who feels the leak (not a new ICP name) |
   | steal as | an **existing** skill / workflow id |
   | kill-do-not | what we refuse (farm, closer, voice-SDR, new lane) |
   | lane tag | existing lane only (`hive-os` / `ai-partner-websites` / `amazon-own-store`) |

4. Label claims: tape `$` = **UNVERIFIED**. Who-sighs without a named prospect = **INFERENCE**. Existing skill id = **FACT** only if that workflow exists.
5. Hand off in one line: "catalog appended — Consultant/GTM may run use-case-to-sku." Researcher does not mint the SKU.
