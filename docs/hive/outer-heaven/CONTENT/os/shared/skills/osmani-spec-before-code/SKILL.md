# Osmani spec before code

Source: addyosmani/agent-skills `spec-driven-development` (MIT).

## When
Non-trivial feature, CapEx slice, or ambiguous ask.

## Do
1. Write a short spec: problem, DONE_WHEN, out-of-scope, HOLD list.
2. File under CONTENT/topics or the CapEx plan before implementation.
3. Implement only what the spec names. Drift needs a new card.

## Don't
Code first then invent the bar. Live `/` without Big Boss ship.
