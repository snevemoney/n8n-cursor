# Osmani spec before code

Source: addyosmani/agent-skills `spec-driven-development` (MIT).

## When
Non-trivial feature, CapEx slice, or ambiguous ask.

## Do
1. Write a short spec: problem, DONE_WHEN, out-of-scope, HOLD list.
2. File under CONTENT/topics or the CapEx plan before implementation.
3. Implement only what the spec names. Drift needs a new card.

## Don't
Code first then invent the bar. Live `/` without Big Boss ship.

# Superpowers writing plans

Source: obra/superpowers `writing-plans` (MIT).

## When
Multi-step feature or CapEx slice before touching code.

## Do
1. Write a short plan: files, checks, DONE_WHEN, HOLD list.
2. Save under `CONTENT/topics/` or CapEx plan note (not Claude `docs/superpowers/plans` as hive SSOT).
3. One vertical slice at a time. L4: reproduce → evidence → implement → critic.
4. Live `/` HOLD unless Big Boss says ship.

## Don't
One-shot the product. Fan-out subagents for plan authoring. Install Superpowers hooks.
