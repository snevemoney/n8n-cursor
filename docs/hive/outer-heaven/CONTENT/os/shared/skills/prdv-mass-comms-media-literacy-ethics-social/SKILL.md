# Mass comms: media functions, literacy, ethics — never post (clustered)

**Use when:** a prompt needs **mass communication** — functions of mass media, roles in various contexts, ethical responsibilities in a diverse society, media literacy, and ethics when using social media — in the Saylor PRDV215 **Mass Communication** school (8 h). Across platforms. **Never send. Never post.**

**Do not use when:** reconstructing exams; **PRDV211** foundations *survey*; **PRDV214** professional social-media *advantages* as org comms; **PRDV107** crisis tweet; **PRDV201** find/judge/cite sources (CRAAPO); **ENGL***; **ESL** (Creative HOLD); promising ACE; **sending** or **posting**; treating intro journalist/marketer/filmmaker lines as a production course.

## 1. Procedure — six checks

Run in order. Stop if Check A says another school or send.

### Check A — Identity overlay (always)

| Prompt smells like | Hand off |
|---|---|
| "How communication works as a survey" | **PRDV211** |
| "Should the company be on LinkedIn (advantages)" | **PRDV214** |
| "Tweet the outage / holding statement" | **PRDV107** (still refuse post) |
| "Find/evaluate this source / CRAAPO" | **PRDV201** |
| "Essay / composition" | **ENGL*** (leave) |
| "ESL" | Creative HOLD — leave |
| "How does mass media work / media literacy / social ethics" | **this skill** |
| "Publish / post / send this" | **HITL — refuse send** |

**Primary goal:** a literate, ethical reading (and producing) of mass media. Named failure mode: posting, collapsing into 201/214/107, or treating filmmaker-aspiration as a shoot.

### Check B — Functions of mass media (when "what is mass media for" is in play)

CLO 1. Unit 1.

**Describe the functions of mass media and mass communication.** Live: evolution of mass media; impact on culture, politics, everyday life.

Shape: name the function in *this* context. Do not dump an invented four-functions roster unless a guest page named it.

### Check C — Roles in context (when "what is this platform doing here" is in play)

CLO 2. Unit 1.

**Explain the roles of mass communication in various contexts.** Live one-liner: across various media platforms.

Shape: context first (news, ads, entertainment, politics), then the role. Journalist/marketer/filmmaker in the intro are *who might use this*, not a career-scout (Demkinn 44 only if operator asked).

### Check D — Media literacy (when "how do I read this feed / is this the whole story" is in play)

CLO 4. Unit 2.

**Describe key concepts and the significance of media literacy.**

Shape: literacy as *reading the landscape*, not PRDV201's research-process/CRAAPO loop. If they need to find and cite a source, hand 201. Stay here for mass-media literacy.

### Check E — Ethics in a diverse society (when "is this coverage fair / who is left out" is in play)

CLO 3. Unit 2.

**Describe the ethical responsibilities of communicators in a diverse society.**

Shape: ethics of *mass* communicators, not PRDV104 workplace D&I CLO and not PRDV211 survey ethics. Do not write SOC101. Do not send.

### Check F — Social-media ethics (when "can I post this / is this tweet okay" is in play)

CLO 5.

**Apply ethics when using social media.**

Shape: an ethics check, **not a post**. Hand 214 if the question is org *advantages* of being on social. Hand 107 if it is a sudden-event plan. **Refuse post.** Publishing Engine if they later want to publish — still HITL.

## 2. Worked patterns (shape only)

**"What is this news site actually doing?"**
Check B (functions) then C (roles) then D (literacy).

**"This Reel is misleading. How do I think about it?"**
Check D then E. If they then want to *find a better source*, hand PRDV201. Do not invent facts.

**"Can I quote this story on the company Twitter?"**
Check F (social ethics) then A: **refuse post**. 214 if it is org-channel strategy. 107 if it is crisis.

**"I want to be a filmmaker like the intro said."**
Aspiration overlay only. Not a production course. Creative Studio if they want actual craft — still not ESL, not ENGL.
