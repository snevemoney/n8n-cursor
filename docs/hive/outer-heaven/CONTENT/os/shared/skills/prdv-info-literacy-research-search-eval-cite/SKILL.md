# Information literacy: research, search, evaluate, attribute (clustered)

**Use when:** a prompt needs **information literacy** — research process, pick a tool, search strategy, evaluate (lateral reading or CRAAPO), ethical/legal use with attribution — in the Saylor PRDV201 **Information Literacy** school (7 h). **Never send.**

**Do not use when:** reconstructing exams; **PRDV010** evaluate-and-cite *into a piece of writing*; **PRDV002** professional writing as a document course; **ENGL*** composition (Publishing — leave); promising ACE; inventing what CRAAPO's **O** means; **sending** the paper or the citation dump.

This is **one** skill. Five live units, five CLOs. Loop: **process then tool then search strategy then evaluate then ethical/legal use.**

## 1. Procedure — six checks

Run in order. Stop if Check A says another school.

### Check A — Identity overlay (always)

| Prompt smells like | Hand off |
|---|---|
| "Integrate this source into my report / cite in the draft" | **PRDV010** |
| "Write the email / report / blog" | **PRDV002** |
| "Essay / composition" | **ENGL*** (Publishing — leave) |
| "How do I find, judge, and use information" | **this skill** |
| "Send / publish the paper" | **HITL — refuse send** |

**Primary goal:** an ethical research loop driven by a real question. Named failure mode: googling first, skipping evaluation, or inventing CRAAPO's O.

### Check B — Research process (when "I don't know where to start" is in play)

CLO 1. Unit 1.

**Explain the steps in the research process, including identifying your topic, gathering background information, locating material, evaluating sources, and citing sources.** Live intro: start with the research process that informs information-seeking behavior; develop an effective question.

Shape: question, background, locate, evaluate, cite. Do not skip to a link dump.

### Check C — Tool and search strategy (when "where do I look / how do I query" is in play)

CLO 2–3. Units 2–3.

**Identify the appropriate research tool for your information need.** **Design an effective search strategy to find relevant information sources.** Live: where to search; finding relevant sources; appropriate search tools.

Shape: need first, then tool, then strategy. Type of information needed is live. Do not treat Google as the only tool.

### Check D — Evaluate (when "is this source any good / is this fake" is in play)

CLO 4. Unit 4.

**Implement evaluation criteria such as lateral reading or the CRAAPO test to determine the value of an information source.** Live overlay: misinformation.

Shape: pick **lateral reading** and/or **CRAAPO** as named live methods. Do not expand CRAAPO's letters unless a guest page states them. Hand PRDV010 if they then need to weave the source into a written argument.

### Check E — Ethical and legal use (when "can I copy this / how do I attribute" is in play)

CLO 5. Unit 5.

**Use information ethically and legally, including creating proper attributions.** Live: ownership and attribution; ethical user of any source; online and print.

Shape: ownership then attribution. Do not dump a style-manual. Do not send the paper. Not legal advice.

### Check F — Writing vs literacy vs send

If they already have sources and need a document, PRDV002/010. If they need a gradeable essay, ENGL (leave). **Refuse send.**

## 2. Worked patterns (shape only)

**"I need sources on X by Friday."**
Check B (question) then C (tool + strategy) then D (evaluate). Do not dump unverified links as if evaluated.

**"This viral post says it is real."**
Check D (lateral reading / CRAAPO as live names). Misinformation overlay. Do not invent the CRAAPO expansion.

**"Can I paste this paragraph if I footnote it?"**
Check E. Ethical/legal + attribution. Not legal advice. Not send.

**"Put these sources into my grant / report."**
Check A: PRDV010 (writing II) or PRDV009 (grants). Recap D–E here first.
