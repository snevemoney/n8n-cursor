# One story into 20 angles (Demkinn #3)

Owner: Creative Studio. Status: partial → runnable.

## When
After a strong tape, bookmark, research packet, or news item. Not for raw 50-item lists.

## Steps
1. Take **one** source (transcript, bookmark packet, still, article). Name it.
2. Extract **≥10 angles** (hooks, cuts, CTAs, objections, visuals, before/after). No invented numbers.
3. Pick **3 for this week**; queue the rest in a dated note under `/workspace/research/packets/` or the vault THEMES folder.
4. If an angle needs motion/map/coded walkthrough → Remotion (`when-remotion`). Do not invent CSS or default to AE.
5. Hand finished draft assets to Publishing Engine. HITL before any public post.

## Done when
A short angle list artifact exists (markdown with source + 10+ angles + top 3), not a chat essay.

## Never
- Mint agents
- Auto-post / auto-send
- Invent stats or engagement numbers
- New SKU or business-lanes row without operator yes

## Tools
| Need | Path |
|---|---|
| Draft | Grok — **PROVE** |
| Publish | HITL / X **BLOCKED** |
