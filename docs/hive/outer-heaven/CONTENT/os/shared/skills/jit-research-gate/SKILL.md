# JIT research gate

Self-teach before unfamiliar or high-impact work.

## Steps
1. Estimate confidence 0–1; note if knowledge may be stale or visual/procedural.
2. Run knowledge-policy if available; else use thresholds: ≥0.85 proceed, 0.65–0.85 quick verify, 0.40–0.65 research, <0.40 deep research.
3. Prefer official docs → primary data → expert sources → video (metadata→transcript→frames) → forums.
4. Cross-check important claims; label UNVERIFIED income/ARR.
5. Execute only when sufficient; validate actual result.
6. Promote durable LESSONS/FACTS to Librarian — never store full transcripts in OPERATOR_MEMORY.

## Success
Saying KNOWLEDGE_GAP / need Research packet is success, not failure.
