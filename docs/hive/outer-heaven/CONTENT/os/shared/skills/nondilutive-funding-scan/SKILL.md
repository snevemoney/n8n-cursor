# Nondilutive funding scan

**Owner:** Money Desk + Researcher. **HITL:** Tier 3 before any application or paid tool.
**Source:** yt:L8pR2YAV8Fw Google Cloud Tech / The Agent Factory — watch-page **PROVE** (timedtext CAPTION_GAP). Guest Thierry Lindor / Happly.ai. Remap guest product → Grok + Cursor research + propose.

## When
Operator (Canada / startup) wants a cheap read of grants, loans, procurement, wage subsidies, or tax credits that do **not** sell equity. Not a buy-automation SKU. Adjacent to nate-five-buy-workflows.

## Do
1. **Match programs only.** Profile (jurisdiction, stage, sector, identity-adjacent eligibility as stated on official pages) → short candidate list. Prefer official Canada / provincial / federal pages over a SaaS pitch.
2. **Draft only.** One-page checklist: program · deadline · fit · docs needed · next human step. No autofill-to-submit.
3. **Cheap read.** Scanning is cheap-read-expensive-decide. Submitting, paying Happly, or treating traction $ as FACT is expensive.
4. **Propose-first.** Happly.ai signup, Chrome extension, grant-writer marketplace, or any paid scan = **Tier 3**. Do not install. Do not store API keys in notes.
5. Label guest/creator $ and pool sizes **UNVERIFIED** until a desk proves them (84k users · $90M landed · $2T NA pool · Black Entrepreneurship Program $265M = FACT-as-stated, not re-audited).

## Don't
- Auto-submit grants or click-apply via an extension
- Install Happly / Gemini-inside-Happly / any autofill agent
- Dilute early "because sharks" without a scan (guest OPINION — keep as caution, not a rule to raise)
- Quote traction $ as hive FACT
- Mint a new business lane from this tape

## Done when
Dated draft checklist on disk (packet or Money-desk note) + operator yes/no on next step. Not a submitted form.
