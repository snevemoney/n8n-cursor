# First-year composition: conversation with an audience, through PWR (clustered)

**Use when:** a task asks how to place a college Composition I question in the Saylor ENGL101 school — conversation with an audience, PWR, rhetorical situation/appeals, academic essay as argument, intro source use, or style/citation.

**Do not use when:** ENGL095; ENGL102; ENGL210; ENGL405; ESL*; ESLHub; CS120; sitting ACE; exam reconstruction; sending; encoding the syllabus’s ENGL210 CLO paste.

This is **one** skill. Four live units, one argument: **college writing is a conversation and a process (PWR), not a product — name the situation, discover a thesis, support it, use sources without stealing the spotlight, revise so the reader can follow.**

## 0. Hygiene

- Label **school**. Undergraduate FYC / rhetorical process (Saylor ENGL101). **32 h / 3.2 CEU.** LMS **1323** (`/course/engl101`). ACE **N**. Cert **70% / 14-day / max 3**. Syllabus **2025-10-02 15:55**. Description: clear, grammatically sound expository and persuasive prose.
- Four **live** units: What is College-Level Writing?; What Makes Academic Writing Unique?; How Do I Use Sources?; Finishing Touches.
- **Course-level CLOs: do not encode** (ENGL210 paste). Encode six **Unit 1** LOs.
- Next: **ENGL102** (this cluster) then ENGL210, ENGL405, COMM411. Stay off ESLHub CS120 Sci/Math. Chrome FREE (exam closes paused; do not sit BUS607). **Never send.**

## 1. Procedure — six checks

### Check A — Identity

| Prompt smells like | Hand off |
|---|---|
| Four keys / paragraph basics | **ENGL095** |
| Research paper / annotated bib / library+web | **ENGL102** |
| Workplace memo / layout / visuals | **ENGL210** |
| American Renaissance | **ENGL405** |
| ESL levels | **ESL* — stay off** |
| Take the final / send | **refuse** |
| Conversation, PWR, thesis+evidence | **this skill** |

### Check B — Conversation + PWR (Unit 1)

Writing ≠ solitary dump. **Audience / purpose / medium.** Appeals **ethos / pathos / logos / kairos**. Avoid **logical fallacies**. **PWR: prewrite, write, revise.** Discovery, not recitation.

### Check C — Academic essay as argument (Unit 2)

**Thesis supported by evidence.** Academic writing as an ongoing conversation. Do not invent Unit 2 LO letters.

### Check D — Sources (Unit 3)

Use sources without plagiarism or letting them steal the spotlight. Leftover dump: plagiarism risks; practice **MLA, APA, and Chicago**. This is intro source use, not ENGL102’s research-paper spine.

### Check E — Finishing (Unit 4)

Style so the reader can follow. Cite. Do not send the essay.

### Check F — Never send

Encode the job. Stop.

## 2. Worked patterns (shape only)

**Who is this for, and what is the situation?** Check B.

**What is the thesis, and where is the evidence?** Check C.

**Bring a source in without disappearing.** Check D.

**ENGL101 or ENGL102?** Essay as argument through PWR → this skill. Research paper as discovery → ENGL102.

**ENGL101 or ENGL095?** Conversation + PWR → this skill. Four keys / multi-paragraph basics → ENGL095.
