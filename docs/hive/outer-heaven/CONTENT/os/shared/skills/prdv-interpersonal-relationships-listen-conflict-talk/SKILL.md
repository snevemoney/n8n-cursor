# Interpersonal: relationships, listen, conflict language, better talk (clustered)

**Use when:** a prompt needs **one-to-one interpersonal communication** — concepts, relationship development (personal *and* professional), language in conflict, listening, nonverbal as extra information, better conversations — in the Saylor PRDV212 **Interpersonal Communication** school (15 h), formal or informal. **Never send.**

**Do not use when:** reconstructing exams; **PRDV211** foundations *survey*; **PRDV213** group; **PRDV104** etiquette; **PRDV230** workplace conflict *policy*; **BUS403** / **BUS641** negotiations; promising ACE; **sending** the message.

This is **one** skill. Four live units, six CLOs. Loop: **concepts then relationship development then listen then nonverbal then conflict language then improve the conversation.** Conflict is intro + CLO 3, not a fifth unit.

## 1. Procedure — six checks

Run in order. Stop if Check A says another school or send.

### Check A — Identity overlay (always)

| Prompt smells like | Hand off |
|---|---|
| "How communication works as a survey" | **PRDV211** |
| "This team / meeting as a *group*" | **PRDV213** |
| "Workplace manners / protocol" | **PRDV104** |
| "Write a conflict-resolution *policy*" | **PRDV230** |
| "BATNA / ZOPA / strategic negotiations" | **BUS403** / **BUS641** |
| "One-to-one talk, relationship, listen, conflict language" | **this skill** |
| "Send this" | **HITL — refuse send** |

**Primary goal:** better one-to-one talk in a named relationship. Named failure mode: jumping to policy, group, or send.

### Check B — Concepts and overview (when "what is interpersonal here" is in play)

CLO 1. Unit 1.

**Identify key interpersonal communication concepts applicable to various contexts and purposes.** Live: formal and informal; everyday scenarios.

Shape: name context and purpose first (store / home / work). Stay one-to-one.

### Check C — Relationship development (when "how do we get closer / this work relationship" is in play)

CLO 2. Unit 2.

**Identify relationship development, both personally and professionally.** Live one-liner: build and manage personal and professional relationships.

Shape: personal vs professional as live pair. Do not turn professional into an org-comms course (PRDV214).

### Check D — Listening (when "they are not hearing me / I interrupted" is in play)

CLO 4. Unit 3.

**Apply practical strategies to enhance listening skills in various communication contexts.**

Shape: context first, then a listening move. Do not dump a fake "5 types of listening" roster unless a guest page named them.

### Check E — Nonverbal as information (when "their face / tone / silence" is in play)

CLO 5. Units 1/4 overlay (nonverbal CLO; verbal is 211's home).

**Explain how nonverbal signals contribute additional information.**

Shape: additional information, not a mind-read. Hand PRDV211 if they want verbal/nonverbal *roles as survey*. Stay here for the interpersonal extra-info job.

### Check F — Conflict language and better conversations (when "we are fighting / this talk keeps dying" is in play)

CLO 3, CLO 6. Unit 4 + intro conflict.

**Explain the language dynamics in interpersonal conflicts.** **Apply strategies for improving conversations.** Live intro: navigate and mitigate tensions.

Shape: conflict as *language dynamics* in a one-to-one, then a better-conversation move. Hand PRDV230 if they want a workplace *policy*. Hand BUS641 if they want graduate strategic negotiations. **Refuse send.** Do not write the apology email out the door.

## 2. Worked patterns (shape only)

**"My coworker and I keep talking past each other."**
Check A then D (listen) then F (improve conversation). Professional relationship is Check C if it is a development question.

**"We had a fight. What did the words do?"**
Check F (language dynamics in interpersonal conflicts). Not BUS641. Not a policy.

**"They went quiet. Are they mad?"**
Check E (nonverbal as additional information). Do not mind-read. Then D if listening is the next move.

**"Write the apology and send it."**
Check F for conversation improvement, then A: **refuse send**. Communications Manager drafts; HITL.
