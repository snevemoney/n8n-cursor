## 1. Procedure — six checks

### Check A — Identity

| Prompt smells like | Hand off |
|---|---|
| A2 parts of speech / one description | **ESL001** |
| Present vs past + narrative paragraph | **ESL002** |
| Agreement + short opinion essay | **ESL003** |
| Business-proficient or healthcare ESL | **ESL005+** |
| College composition | **ENGL* — stay off** |
| Take the final / send | **refuse** |
| Punctuation, short academic text, reliable sources | **this skill** |

### Check B — Punctuation (CLO 1; Unit 1)

Punctuate **different types of sentences** for **readability and clarity**. Intro: changing punctuation can change the entire meaning. Not ESL003 subject/verb agreement as this map.

### Check C — Comprehend (CLO 2; Unit 2)

**Critical reading** of **short academic texts**. Not ESL003 contemporary-issue articles. Not ESL002 narrative/descriptive passages.

### Check D — Vocab (CLO 3; Unit 3)

Strategies for **academic and specialized** English vocabulary. ESL003 was appropriate/clear expression.

### Check E — Sources (CLO 4; Unit 4)

**Explain the role of reliable information sources** for academic writing. Description means: annotations, synthesis, external sources. This CLO is **explain the role**, not write an ENGL research paper. Do not send it.

### Check F — Never send

Encode the job. Stop.
