**Primary goal:** literacy on JS I enough to program page behavior with values, control flow, objects/DOM, and debug. Named failure mode: ES6 dumps, treating Unit 1 as 251, or sending.

### Check B — HTML/CSS prerequisite (when "I don't know HTML" is in play)

CLOs 1–3. Unit 1.

**Explain the use of HTML5 tags; model HTML page structure; create a simple webpage using HTML and CSS.** **HTML5 is live.** If the whole prompt is markup/styling with no JS, hand **251**. Here it is recap so JS can attach.

Shape: recap, do not dump a tag roster. Then continue to JS.

### Check C — JS as interactive behavior (when "what is JS for" is in play)

CLO 4. Unit 2.

**Explain how JavaScript is used to program the behavior of webpages as an interactive tool.** Live: client-side scripting for interactive content in a web browser; conditions and events (description).

Shape: behavior of pages, not a server language. Do not invent Node as live.

### Check D — Values, variables, statements (when "what goes in the program" is in play)

CLOs 6–7. Unit 3.

**Utilize steps for writing a JS program with proper values, operators, expressions, and keywords; list and explain types of values and variables.** Type *names* not listed.

Shape: values/operators/expressions/keywords as a job. **Do not invent** number/string/boolean/undefined dumps or let vs var vs const.

### Check E — Control flow (when "if this, then that" is in play)

CLO 11. Unit 4.

**Construct appropriate control structures based on conditions.** Description also names events. Guest named **no** if/for/while keywords as a list.

Shape: control structures from conditions. Do not invent a keyword roster. Functions (Unit 5) overlay here if they ask "wrap this in a function" — no dedicated function CLO.

### Check F — Internal vs external JS (when "where does the script go" is in play)

CLO 8.

**Explain the proper use of internal and external JavaScript.** Live CLO.

Shape: internal vs external as a job. Do not invent module/bundler names.

### Check G — Objects and the DOM (when "change what's on the page" is in play)

CLO 9. Unit 6.

**Utilize objects including the structure of the DOM (Document Object Model).** **DOM is live.** Dynamically display and manipulate HTML elements.

Shape: objects + DOM. Do not invent querySelector/getElementById as live unless a later harvest shows them.

### Check H — Write and debug (when "it doesn't work" is in play)

CLOs 5 and 10.

**Utilize the tools to write and debug JavaScript programs; identify the debugging process to correct code.** Tool *names* not live. Exception handling is intro overlay, not a CLO.

Shape: write + debug as a process. **Do not invent** Chrome DevTools as live. **Refuse send** of the "fixed" file.
