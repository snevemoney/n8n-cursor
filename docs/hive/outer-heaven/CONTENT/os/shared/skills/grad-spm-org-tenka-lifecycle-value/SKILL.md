# Graduate strategic PM: org context → ten KAs → lifecycle → value (clustered)

**Use when:** a task asks how a manager should deliver **business value** through a **temporary unique** effort — how to read the organizational context, which method (agile vs traditional; small vs mega) fits, how to initiate/plan/execute/monitor/close as five distinct stages, which of the **ten named knowledge areas** is the bottleneck, how **integration** holds the ten together, how stakeholders should be involved, or how to mitigate risk to schedule/scope/budget so the project is a competitive advantage rather than a busy unique effort.

This is **one** skill. It is not "Unit 1 skill + Unit 2 skill…". BUS605's seven live units are one argument: **strategic project management is how the manager turns temporary unique work into business value, inside an organizational context, by integrating five process groups across ten named knowledge areas.**

## 1. Procedure — answer a graduate strategic-PM question in six checks

Run in order. Skip a check only if the user already constrained the frame.

### Check A — Identity, level, overlay (always)

**The course question:** is the user asking for an **undergrad intro-PM recap**, **POLC as the manager's job**, **ongoing operations**, a **PMP dump**, a **firm-strategy case**, or a **strategic project decision** that is supposed to deliver business value through temporary unique work inside an organization?

Live test:

| Prompt smell | Hand off |
|---|---|
| "What is a project / five groups / people skills as the course" | **BUS402** |
| "What does a manager do (POLC nine units)" | **BUS208** |
| "Capacity, inventory, the standing process" | **BUS300** |
| "ITTO / PMP item / CAPM cram" | **refuse exam reconstruction**; this skill is not PMP prep |
| "Should the firm acquire / five forces / VRIN" | **BUS501** |
| "NPV / WACC this capital project as finance" | **BUS601** |
| "This org, this method, these ten KAs, so we capture advantage" | **this skill** |

**Primary goal:** the unique result **and** the **business value / competitive advantage** the live intro names. On time / on budget with a deliverable nobody uses is not success in this school. Culture, method fit, stakeholders, and a multi-project organization constrain the path.

**Think as a project manager of a strategic bet** (graduate overlay). CLO 1: **organizational context**. CLO 9: productive **stakeholder involvement**. CLO 8/10: risk to **schedule, scope, and budget**. Integration is how the ten KAs stay one project.

**Level check:** if the prompt is actually undergrad homework in BUS402's five units, **hand off BUS402** and recap only. If it is MBA605's or MMGT605's proctored 80% exam, **refuse exam reconstruction**; this skill is the *content* overlay, not the degree exam.

### Check B — Org context, what a project is, and which method (Unit 1)

CLO 1, 3.

Live intro: workers/firms undertake projects to solve problems, create advantage, or deliver consumer value. Most companies have **more than one project going at the same time**.

Encode at manager depth (Darnall ch.1 overlay, summarize):

- **Project (PMI-class definition this school uses):** a **temporary** endeavor to create a **unique** product, service, or result. Temporary ⇒ defined start and finish (you must start up *and* close down). Unique ⇒ not the standing production line.
- **Not operations.** Operations managers improve existing processes over a long horizon. Project managers are goal- and milestone-oriented. That is why BUS208 POLC and BUS300 OM are neighbors, not this course.
- **Organizational context (CLO 1):** org type changes the time horizon; who charters the work; whether a **PMO** exists (project management / center of excellence / **portfolio** / functional support — Watt/Darnall PMO overlay at *name* depth). Portfolio is a *seed* ("more than one project"), not a portfolio-management *course*.
- **Method choice (live intro):** **agile** (software as the named example) vs **traditional**; **small** vs **mega**. Watt Scrum overlay at *name* depth (sprint, product owner, Scrum Master, development team) — pick the method that fits the work. Do not baptize every project "agile." Do not run a Scrum certification.
- **Ten named KAs** with **integration** as the spine. List them in live syllabus order when the user needs the set. Stakeholder is the 10th (BUS402's CC spine folded it into comms).
- PMI is a **named standards body**. Following PMI principles ≠ sitting PMP.

**Hand off BUS402** the moment they need intro-PM as a *course* or the ACE exam. **Hand off BUS300** if the object never ends. Stay here for "this project's context and method have to create advantage."

### Check C — Lifecycle vs process groups (Unit 2)

CLO 2: **compare** initiating, planning, execution, monitoring and controlling, and closing.

- **Process groups** are kinds of work that **repeat and overlap**. They are not a strictly linear calendar.
- **Phases** (Watt/Darnall: initiation → planning → implementation → closure) are a coarser, more sequential story. Do **not** collapse "implementation" into "executing" without naming **monitoring and controlling** — this live course split them (Units 5 and 6). BUS402 combined them.
- Method from Check B constrains the story: a Scrum-class effort still initiates, plans a sprint, executes, inspects, and closes a sprint. A mega-project still closes.

**Hand off BUS402 Unit 1–2** if they need intro process-group literacy as *the course*. Stay here for "which stage are we in, and are we pretending a phase is a group?"

### Check D — Initiate and plan the baseline (Units 3–4)

CLO 3–8, 9 seed, 10 seed.

**Initiate (Unit 3):** assign the PM; write the **reason** (problem / advantage / value); identify **stakeholders**; get **authorization** (charter-class document). Alignment / kickoff. If stakeholders are not aligned, spend time here or pay later. Selection = "why this, why now, given the org's other projects" — not BUS601's NPV lab, not BUS501's industry case.

**Plan (Unit 4) is a baseline you will control against, not a wish list.**

- **Scope:** WBS-class decomposition; exclusions/constraints/assumptions. **Scope creep** is the named failure.
- **Time (CLO 4):** activities, dependencies, **critical path**, float; crashing as a *named* option, not heroics.
- **Cost / quality / delivery (CLO 5):** conceptual → ROM → detailed; budget baseline; quality as spec + assurance + control.
- **Resources (CLO 6):** select and **prioritize critical** resources. Temporary team; matrix; right skills at the right time.
- **Comms (CLO 7):** audience / channel / cadence so the ten KAs can integrate. **Hand off BUS210** for genres as a *course*.
- **Risk (CLO 8, 10):** identify / analyze / respond against **schedule, cost, and scope**. Documentation, reporting, mitigation, contingency.
- **Procurement + stakeholder plans:** named KAs. Partners vs vendors vs commodities at *name* depth.

Constraint triangle this school expects: **scope, time, cost** (quality as the usual fourth; risk/resources as competing constraints). Change one, the others move.

**Hand off BUS402 Unit 2** for intro initiate+plan as one undergrad unit. Stay here for "the baseline is how this org will spend money and time for advantage."

### Check E — Execute, then control against the baseline (Units 5–6)

CLO 5, 6, 7, 8, 9, 10.

**Execute (Unit 5):** coordinate people and resources to **produce deliverables**; manage stakeholder engagement; acquire/develop/manage the team; perform quality; conduct procurements. Most of the hours and most of the variance live here. Agile overlay: a sprint *is* execution against a short plan — still not "no plan."

People overlay (spent here, not as BUS402's standalone people-skills unit): temporary team, political sensitivity, client expectations. **Hand off BUS401 / BUS603** if the prompt is leadership theory or people-management as a *course*.

**Monitor and control (Unit 6):** compare **actuals to the baseline**; run **change control**. Scope creep is the failure mode. Control schedule, cost, quality, risk. CLO 8/10: risk to schedule/scope/budget via documentation, reporting tools, and response/mitigation. Earned-value *vocabulary* (PV / EV / AC; SPI/CPI) at definition level only — **do not dump PMP formula sheets**. Report status honestly. Variance hidden until the end is not control, and it is not "strategic."

Ethics floor: fake-progress, hidden variance, or a change that was never authorized → refuse / rewrite the plan.

**Hand off BUS402 Unit 3** for intro execute+monitor as one undergrad unit. Stay here for "control is how the strategic bet stays a bet instead of a drift."

### Check F — Close and ask whether value actually landed (Unit 7 + always)

CLO 2 close. Live intro's last move: how the company **completes** projects can be a competitive advantage.

- Accept deliverables; close contracts (punch lists, performance tests; pay what was earned).
- Lessons-learned; archive; release resources; **celebrate** (Watt/Darnall name it — part of closing, not a skippable party line).
- Prevent the project from living past the baseline ("operations by another name"). **Hand off BUS300** for the standing process that receives the result.
- Strategic close: did this project deliver the **business value / competitive advantage** Check B promised, or only a busy unique effort?

Before you lock a recommendation, run CLO 1 / 9 / 10 again:

- If the only way to hit the date is unauthorized scope cut, hidden variance, or abusive overtime as a plan, **change the plan**.
- Stakeholders are a **decision input** (CLO 9), not a slide. Diversity of interest (who can block, who must accept) is not a slogan.
- Incomplete information is normal. Name the gap; do not invent a critical path or a stakeholder map you have not built.
- Method from Check B still has to fit: do not "waterfall a discovery problem" or "scrum a one-shot mega plant."

## 2. Worked micro-patterns

**"What is strategic project management / how is it not intro PM?"**
Check A in one paragraph. Past vs decide-what-to-do-as-a-manager. Hook: temporary unique work that is supposed to create **advantage**. Name the overlays: BUS402 teaches the five groups; this course *spends* them as seven units with **ten named KAs**, **integration** as the spine, org context, and method choice.

**"Agile or waterfall for this software / product / mega build?"**
Check B method choice + Check C (groups still exist). Software as the live intro's agile example is a *default smell*, not a law. Mega + vast budget is a traditional/phase smell. Do not run a Scrum certification. **Hand off** a dedicated agile *course* if they need ceremonies as the object.

**"We don't have a charter / stakeholders are fighting / why are we doing this?"**
Check D Unit 3. No authorization, no project — just work. CLO 9 starts at initiate. If the real object is firm strategy, **hand off BUS501**. If it is capital rationing math, **hand off BUS601**.

**"The date is impossible / what is the critical path?"**
Check D CLO 4 then Check E control. Critical path and float as *named* tools. Crashing is a named option with cost/quality consequences (CLO 5). Do not dump a PMP scheduling item set.

**"Scope keeps growing / nobody will sign off."**
Check D scope + Check E change control + Check F close. Scope creep is the named failure. Integration (change control) is the spine. Stakeholders who never accepted the exclusions were never initiated (Unit 3).

**"Status is green and the work is red."**
Check E. Hidden variance is not control and not strategy. CLO 7 comms + CLO 8/10 risk reporting. Ethics floor.

**"Are we done / should we keep a team on it?"**
Check F. Close, hand off to operations (**BUS300**), capture lessons, ask whether value landed. A project that never ends became operations by another name.

**"Walk me through undergrad intro PM as five units / ACE BUS402."**
Wrong course. **BUS402**. Recap a term only if this prompt still needs it. SAYA-0039 is not this course.

**"POLC the department."**
Wrong course. **BUS208**. Planning/executing/controlling *words* touch this skill; the object does not.

**"PMP / ITTO / dump PMBOK."**
Refuse dumps. Name the ten KAs and five groups; summarize CC Darnall/Watt; do not paste PMI.
