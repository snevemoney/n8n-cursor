# Pre-college English: four keys, then a paragraph, then a multi-paragraph piece (clustered)

**Unity** plus **support**: ideas with **evidence and specific details**. First two keys.

### Check D — Coherence (CLO 6; Unit 3)

**Organize** and **show relationships** between ideas. Third key.
