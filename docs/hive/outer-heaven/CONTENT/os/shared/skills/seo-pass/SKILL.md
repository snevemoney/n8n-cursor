# SEO pass

## Steps
1. Implement `generateMetadata` (or Astro equivalents) per page from brief titles/descriptions.
2. Add sitemap + robots.
3. Add JSON-LD for Organization/WebSite/Article as relevant.
4. OG images for key pages.
5. Canonical URLs; no index on preview/staging.
6. Spot-check titles ≤ ~60 chars, unique descriptions.

## Done when
- Metadata present on all public routes
- Sitemap reachable
- Staging not indexed
