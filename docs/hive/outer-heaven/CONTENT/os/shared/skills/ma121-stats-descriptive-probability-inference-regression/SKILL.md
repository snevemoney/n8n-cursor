### Check B — Descriptive (when "mean / spread / population" is in play)

CLOs 1–3, 8 overlay. Unit 1.

**Descriptive vs inferential; population vs sample; measures of location, variability, and skewness.** Analyze data sets using descriptive statistics (CLO 8 start).

### Check C — Probability and random variables (when "chance / discrete vs continuous" is in play)

CLOs 4–5. Unit 2. Intro: combinatorial probability and random distributions.

**Simple principles of probability. Probabilities for discrete and continuous random variables.**

Shape: probability then RV type. Distribution family names (normal, binomial) are **not** in the guest CLO list — do not mint them as live titles. Intro says “random distributions” only.

### Check D — Sampling and CIs (when "sample mean / interval" is in play)

CLOs 6–7. Units 3–4.

**Sampling distributions for statistical inferences. Confidence intervals for means and proportions.**

Shape: sampling distribution then CI. Means and proportions both live. Do not invent z/t interval names as Saylor-titled.

### Check E — Hypothesis tests and CLT (when "is this significant / CLT" is in play)

CLOs 8–10. Unit 5 titled **Hypothesis Test** (singular).

**Parameter estimation and hypothesis testing; interpret results of hypothesis tests; explain how the central limit theorem applies in inference.** CLT is live by name.

Shape: state the inferential job, then CLT if the prompt is about large samples. **Test-statistic names (t, z, p-value, ANOVA) are not live.** If the prompt already uses them, treat as hypothesis-testing CLO without claiming Saylor titled them.

### Check F — Regression (when "relationship / predict" is in play)

CLOs 11–12. Unit 6.

**Relationships between two variables using simple linear regression. Use regression equations to make predictions.** Intro also says “two or more variables, known as regression” — CLO is **simple** linear (two variables). Encode the intro/CLO overlay: intro allows “or more”; CLO is two-variable simple. Do not mint multiple regression as live.

Shape: two-variable line, then predict. GPA-salary / stock examples are color — **not a forecast to send, not trading advice.**
