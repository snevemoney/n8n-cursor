# Intermediate ESL: present vs past, then read, then a paragraph (clustered)

**Use when:** a task asks how to place an intermediate ESL question in the Saylor ESL002 school — present/past on common activities, short narrative/descriptive reading, vocab growth, or a short narrative paragraph about daily or past events.

**Do not use when:** ESL001 A2; ESL003+; ENGL*; ESLHub; CS120; sitting ACE; exam reconstruction; sending.

This is **one** skill. Four live units, one argument: **most students already have ESL001 sentence-order; this course pass is intermediate — tense changes meaning, active reading (skim/scan/intensive), then a short paragraph, especially about the past.**

## 0. Hygiene

- Label **school**. Intermediate ESL (Saylor ESL002). **15 h / 1.5 CEU.** LMS **723** (`/course/esl002`). ACE **N**. Cert **70% / 14-day / max 3**. Syllabus **2025-10-03 10:37**. Description: writing accuracy and fluency; grammar, writing, reading, vocabulary.
- Four **live** units: Language Skills; Reading to Comprehend; Reading to Improve; Reading to Write – Writing About the Past.
- Four **live** CLOs.
- Next: **ESL003**. Stay off ENGL* and ESLHub. Stay off CS120. Chrome FREE (exam closes paused; do not sit BUS607). **Never send.**

## 1. Procedure — six checks

### Check A — Identity

| Prompt smells like | Hand off |
|---|---|
| A2 parts of speech / one description | **ESL001** |
| Upper-intermediate or advanced ESL | **ESL003+** |
| College composition | **ENGL* — stay off** |
| Take the final / send | **refuse** |
| Present vs past, short paragraph, skim/scan | **this skill** |

### Check B — Tense (CLO 1; Unit 1)

Present and past in **simple statements about common activities**. Past vs present **changes meaning**. Not ESL001 eight-parts drill as this map.

### Check C — Comprehend (CLO 2; Unit 2)

Short **narrative or descriptive** passages. Intro: **skim, scan, and read intensively** — three moves, one unit.

### Check D — Vocab (CLO 3; Unit 3)

Strategies to **enlarge** SAE vocabulary. ESL001 was recognize/collect academic terms; this is enlarge.

### Check E — Paragraph, especially past (CLO 4; Unit 4)

**Short narrative paragraphs** on a **familiar** topic: daily activities **or past events**. Unit title is Writing About the Past. Paragraph ≠ ESL001 short description. Do not send it.

### Check F — Never send

Encode the job. Stop.

## 2. Worked patterns (shape only)

**Did vs do.** Check B tense meaning.

**I need the gist / a date / every word.** Check C skim / scan / intensive.

**Write about yesterday.** Check E past-event paragraph. Unit 4.

**ESL002 or ESL001?** Paragraph + present/past → this skill. A2 sentence order → ESL001.
