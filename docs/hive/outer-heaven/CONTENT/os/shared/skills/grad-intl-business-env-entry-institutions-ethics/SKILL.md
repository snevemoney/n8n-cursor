# Graduate advanced international business: read the environment, then enter (clustered)

**Use when:** a task asks how a firm should **operate across borders** — what opportunities and risks the interconnected global market creates, which trends change the entry decision, how culture changes communication and negotiation, what role international institutions play in trade, how the global financial *system* clears a cross-currency deal, how emerging-market geopolitics and development constrain the bet, which entry mode (export / M&A / partner) fits, or which CSR/ethical dilemma global operations create — in the Saylor BUS613 **graduate** advanced-international-business school.

**Do not use when:** the job is reconstructing or taking a Saylor (or any) exam, dumping Hill/Cavusgil/Hofstede/IMF item banks, running **BUS610** graduate advanced BI, **BUS611** graduate data management, **BUS612** graduate data-driven communications, **BUS614** international finance *as a course* (parity, hedging programs, multinational capital budgeting), **BUS615** international marketing *as a course* (mix, branding, marketing research as the course), **BUS101** intro survey, **COMM311** intercultural comms as a course, **ECON101/102** trade theory as econ, **BUS200 / BUS608** ethics as a course, treating the free 70% certificate as **MBA613** 80% proctored exams, promising ACE/transfer credit, inventing a live Hofstede/WTO/FCPA stack, or inventing an undergrad IB course that is not in the catalog.

This is **one** skill. It is not "Unit 1 skill + Unit 2 skill…". BUS613's seven live units are one argument: **read the environment so the entry decision is defensible — through culture, trade, financial plumbing, institutions, named entry modes, and CSR.**

## 1. Procedure — answer a graduate IB question in six checks

Run in order. Skip a check only if the user already constrained the frame.

### Check A — Identity, environment, overlay (always)

**The course question:** is the user asking for a **data-stack** answer (BI / DBMS / viz), an **international finance course**, an **international marketing course**, an **intro survey**, **trade theory as econ**, **intercultural comms as comms**, **ethics as a course**, or an **IB-environment + entry decision** that has to survive culture, institutions, plumbing, and CSR?

Live test:

| Prompt smells like | Hand off |
|---|---|
| "Stand up BI / pick a DBMS / dashboard the finding" | **BUS610 / BUS611 / BUS612** |
| "PPP, interest-rate parity, hedge the receivable, multinational capital budget" | **BUS614** |
| "Global marketing mix / brand / marketing research as the course" | **BUS615** |
| "What is business / who is Buffett" as intro | **BUS101** |
| "Comparative advantage diagram / tariff welfare as econ" | **ECON101 / ECON102** |
| "Intercultural communication as a comms course" | **COMM311** |
| "Ethics survey / ethical-and-strategic management as a course" | **BUS200 / BUS608** |
| "SCM network design as a course" | **BUS606** |
| "Read the global environment / name opp-and-risk / pick an entry mode / institutions / culture on the deal / MNC CSR" | **this skill** |

**Primary goal:** a defensible cross-border decision — opportunities **and** risks, then an entry path the environment can carry. That is not "pass CFA," not "ship a global campaign" (**BUS615**), and not "define globalization" as intro (**BUS101**).

**Named live failure mode:** treating "international" as a marketing slogan (the intro's marketing sentences are a **claim vs data** flag) or as a finance problem, without reading culture, institutions, plumbing, and CSR.

**Level check:** there is **no live undergrad IB course** in the catalog. If the prompt is actually BUS101 homework, **hand off BUS101**. If it is MBA613's proctored 80% exam, **refuse exam reconstruction**; this skill is the *content* overlay, not the degree exam.

### Check B — Culture, communication, negotiation (when "they don't get us / the meeting went sideways / language" is in play)

CLO 3. Unit 2.

Culture is an **operating constraint on communication and negotiation style**, not a tourist briefing and not COMM311 as a course.

Name:

1. **What must be negotiated** (the Unit 1/6 entry decision).
2. **Which cultural/language difference** is actually in the room (confirm live labels; do not dump Hofstede dimensions as doctrine).
3. **How that changes the communication or the negotiation style** — both verbs are in the CLO.

Carpenter overlay (summarize): culture as how the deal is heard. **Hand off COMM311** for comms-as-a-course. **Hand off BUS403 / BUS641** for negotiations-as-a-course. Stay here for "this IB environment, this negotiation style."

### Check C — Trade as the interconnected engine (when "tariff / FTA / we buy from / we sell to" is in play)

CLO 1 overlay. Unit 3.

Trade is why the market is interconnected. Encode **what is being traded, under which barrier or opening, with what effect on opportunity and risk** — not the welfare triangle.

OpenStax/Suranovic overlay (summarize): comparative advantage and protectionism change the feasible set. Carpenter ch.2 overlay: trade **and** FDI. FDI also feeds Check F (entry).

Do **not** require Heckscher–Ohlin as live CLO language. **Hand off ECON101/102** for theory-as-econ. Stay here for "this trade regime, this IB decision."

### Check D — Global financial system as plumbing (when "how do we get paid / which currency / central bank" is in play)

No dedicated CLO; Unit 4. **Search-indexed residue** (guest 303 this harvest; confirm on login): countries **cannot operate independently** financially; categorize system components by **function**; describe **cross-currency company transactions**; analyze **central banks' effects on exchange and interest rates**. Named: **balance of payments / current account**; **SWIFT**; FX markets.

Encode as *can this deal clear*. Not "build the hedge book" (**BUS614**). Not "intro TVM" (**BUS202**).

**Hand off BUS614** the moment they want international finance *as a course*. Stay here for "this IB plumbing, this currency, this central-bank regime."

Do **not** guess a live uncovered-interest-parity doctrine as Saylor language until login.

### Check E — Institutions, geopolitics, development (when "WTO / the bloc / emerging market / the roads don't work" is in play)

CLO 4 + CLO 6. Unit 5.

Two jobs, one unit: **justify institutions as trade support among nations**, and **evaluate infrastructure and economic development** plus the **geopolitics of emerging markets**.

Encode:

- Which institution (or gap) makes this trade possible? Do **not** invent a WTO/IMF/World Bank list as live doctrine until login names them — name the *job*.
- What development/infrastructure level changes the opportunity?
- What emerging-market political risk sits on the bet?

**Hand off POLSC221 / POLSC402 / GEOG101** for poli-sci or geography as *those* courses. Stay here for "this institution, this emerging-market geopolitics, this IB decision."

### Check F — Entry modes, then CSR / ethical dilemmas (when "export or buy them / partner / is this even responsible" is in play)

CLO 2 + CLO 5 + CLO 7. Units 6–7.

**Named search-indexed entry set** (encode these; do not silently expand): **direct exporting, mergers and acquisitions, partnering.** Also named: **industry trends** that favor one mode; **analyze an M&A plan**; **interdependence of global supply chains and markets**. Partnering residue: track record in the target market, **culture**, right fit, **trust** (Unit 2 feeds this).

CLO 5 is **opportunities and risks** of the mode — both sides. CLO 2 is the **decision steps** to enter.

**CSR (Unit 7).** CLO 7: social responsibility of **international corporations** + **ethical dilemmas** of **global operations**. Encode the dilemma that is actually in play. Confirm live labels. Do not dump FCPA articles as doctrine.

**Hand off BUS615** to market after entry. **Hand off BUS614** to finance the entry. **Hand off BUS606** for SCM as a course. **Hand off BUS200 / BUS608** for ethics as a course. Stay here for "this mode, this opp/risk, this MNC dilemma."

Do **not** freeze franchising / licensing / greenfield as live Saylor doctrine. Carpenter names more — that is parallel. Name the *job* and leave extra modes until login.

## 2. Worked patterns (shape only — not exam items)

**"Should we export to this emerging market or buy a local competitor?"**
Check A (environment: opp and risk) → Check E (institutions / development / geopolitics) → Check B (culture on the deal) → Check D (can we get paid) → Check F (export vs M&A vs partner; then CSR). Do not turn it into BUS615's campaign or BUS614's valuation course.

**"The negotiation keeps failing and they want to skip the bloc's rules."**
Check B (culture → negotiation style) → Check E (institutions support *trade among nations* — skipping the institution is a risk, not a shortcut) → Check F (if the mode is partnering, residue already named trust/fit/culture). Not COMM311 as a course. Not POLSC as a course.

**"How do we pay them in another currency / SWIFT / the central bank moved."**
Check D. If they want a hedge program or capital-budget, **hand off BUS614**. Stay here for plumbing of the IB environment.

**"Is this a marketing problem or an IB problem?"**
Check A. Live intro *mentions* marketing research/trends — that is **claim vs data**. If the job is mix/brand/research as the course, **hand off BUS615**. If the job is environment + entry, stay here.

**"MBA613 / MMKT613 / MMGT613 / MEI613."**
Only **MBA613** exists as this title-family (and it drops "Advanced"). MMKT606 is International Marketing. MEI610 is a seminar. Do not invent twins.
