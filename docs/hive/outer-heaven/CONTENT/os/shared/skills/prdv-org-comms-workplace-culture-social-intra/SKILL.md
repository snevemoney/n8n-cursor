# Org comms: workplace culture, competencies, professional social (clustered)

**Use when:** a prompt needs **organizational communication** — business-comms concepts, competencies *in organizations*, improve workplace talk, interpersonal *in the workplace*, professional social-media *advantages*, with Unit 2 intrapersonal overlay — in the Saylor PRDV214 **Organizational Communication** school (13 h). Foster a positive, productive communication culture. **Never send. Never post.**

**Do not use when:** reconstructing exams; **PRDV211** foundations *survey*; **PRDV212** one-to-one interpersonal; **PRDV213** small group; **PRDV107** crisis social *plan* / posting; **PRDV104** etiquette or D&I as a *course*; **PRDV215** mass; promising ACE; **sending** or **posting**.

This is **one** skill. Two live units, five CLOs. Loop: **concepts then org competencies then improve then workplace-interpersonal (plus intrapersonal overlay) then professional social advantages.** Inclusivity is intro overlay, not a sixth CLO.

## 1. Procedure — six checks

Run in order. Stop if Check A says another school or send.

### Check A — Identity overlay (always)

| Prompt smells like | Hand off |
|---|---|
| "How communication works as a survey" | **PRDV211** |
| "One-to-one / we two" | **PRDV212** |
| "This small project team / committee" | **PRDV213** |
| "Crisis tweet / holding statement" | **PRDV107** (still refuse post) |
| "Manners / D&I as etiquette course" | **PRDV104** |
| "How does *the workplace* talk as a system" | **this skill** |
| "Send / post this" | **HITL — refuse send** |

**Primary goal:** a productive workplace communication culture. Named failure mode: posting, collapsing into 212/213, or lecturing D&I as if this were PRDV104.

### Check B — Business-comms concepts (when "what even is workplace comms" is in play)

CLO 1. Unit 1.

**Describe key concepts for effective business communication.** Live: fundamental communication principles and essential organizational communication elements.

Shape: name the org context, then the concept. Do not skip to a Slack rant.

### Check C — Org competencies (when "what should people here be able to do" is in play)

CLO 2. Unit 1.

**Identify competencies for effective communication that occurs in organizations.**

Shape: competencies *in organizations*, not small-group facilitation (213) and not one-to-one (212). Stay org-level.

### Check D — Improve workplace communication (when "our culture of talk is broken" is in play)

CLO 3. Units 1–2.

**Apply strategies to improve workplace communication.** Live one-liner: tools and strategies for a positive, productive culture. Intro: challenges individuals face; inclusivity overlay.

Shape: a workplace-level strategy. Inclusivity as overlay if the prompt is exclusion-at-work. Hand 104 if it is manners. **Refuse send.**

### Check E — Interpersonal (and intrapersonal) at work (when "how I talk to people here / how I talk to myself before the meeting" is in play)

CLO 4. Unit 2.

**Explain the importance of interpersonal communication in the workplace.** Unit 2 title also: **intrapersonal** business communication.

Shape: workplace-interpersonal as *why it matters here*, not a 212 harvest. Intrapersonal overlay: how the person prepares internally — not therapy, not PSYCH101 (Creative). If it is truly a dyad fight, hand 212.

### Check F — Professional social media advantages (when "should we even be on LinkedIn / Slack as the org" is in play)

CLO 5.

**Describe the advantages of employing social media within a professional setting.**

Shape: advantages, not a content calendar, not a crisis tweet. **Refuse post.** PRDV107 if it is a sudden-event plan. HITL if they still want something public.
