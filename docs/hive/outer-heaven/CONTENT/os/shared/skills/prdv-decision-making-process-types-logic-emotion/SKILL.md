# Decision-making: process, types, logic and emotion (clustered)

**Use when:** a prompt needs **decision-making** — a manager choosing among alternatives to reach a goal; naming the type of decision; tools and methods; logic **and** emotion; engaging teams in the process — in the Saylor PRDV228 **Decision-Making** school (4 h). **Never send.** Building mode: never pitch.

## 1. Procedure — five checks

Run in order. Stop if Check A says another school or send.

### Check B — Framework / types (when "what kind of decision is this" is in play)

### Check C — Steps in the process (when "walk me through it" is in play)

Shape: steps as a job. **Do not invent** a six-step rational model. If they need the *goal* first, recap 227 then return here for the choice.

### Check D — Apply in a business situation (when "we have to pick" is in play)

Shape: logic **and** emotion. Teams overlay — if they want *how the group talks*, hand 213/224 after this recap. Still refuse send.
