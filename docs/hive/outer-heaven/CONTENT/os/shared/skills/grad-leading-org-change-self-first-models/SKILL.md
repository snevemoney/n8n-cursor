# Graduate leading change: self first, then model, size, staff, implement (clustered)

## 1. Procedure — answer a graduate leading-change question in six checks

Run in order.

### Check A — Identity overlay (always)

| Prompt smells like | Hand off |
|---|---|
| "Leadership styles / motivation / three-level conflict / teams as advanced OB" | **BUS640** |
| "Negotiate / mediate / bargain as a *course*" | **BUS641** |
| "Lead vs manage / theory families as undergrad capstone" | **BUS401** |
| "HR cycle / managing people / culture as a managing-people unit" | **BUS603** |
| "Intro OB culture/change homework" | **BUS209** |
| "MBA leadership capstone" | **MBA609** (different course) |
| "Lead yourself first, size this change, pick a model, staff it, plan with measures, learn from a failed change" | **this skill** |

**Primary goal:** facilitate **positive change** that is **understood before followed**. Named failure mode: implementing before people understand, or skipping self-leadership.

If the prompt is MMGT609's proctored 80% exam, **refuse exam reconstruction**.

### Check B — Self first, then people (when "I am the leader / they will not follow" is in play)

CLO 4. Unit 1 / Unit 4.

Lead **yourself first**. Engage employees. Change must be **understood by all** before they follow. Analyze **critical people skills** to lead others through change. Unit 4 is **talent management and facilitating change**. Human element, straightforward leadership, culture.

**Hand off BUS640** for OB-as-a-course. **Hand off BUS603** for HRM. Stay here for "this leader, this change, these people skills."

### Check C — Apply well-known models (when "which model / which method" is in play)

CLO 1. Unit 2.

**Apply well-known change models to drive organizational change in a given organization.** Verb is *apply*, to a *given* organization. **Do not freeze a named list** (Kotter, Lewin, ADKAR, Bridges) as live Saylor CLO language until login. Encode the *job*: pick and apply a well-known model that actually drives this change.

**Hand off BUS401** for leadership-theory families as a capstone. Stay here for "this model, this organization, this change."

### Check D — Scale, scope, failure, global (when "how big / why did the last one fail / we are global" is in play)

CLO 2, CLO 3, CLO 7. Unit 3.

**Determine the scale and scope.** **Interpret the reasons organizations fail at implementing change and mitigation strategies.** **Analyze change-management practices in a given situation within a global context.** Live intro: review **failed changes**.

Stay here for "this size, this failure, this global situation." Do not invent case facts.

### Check E — Plan with measurements, long-range, transitions (when "what's the plan / how do we implement / how do we know it worked" is in play)

CLO 5, CLO 6. Unit 5.

**Differentiate long-range strategies** to lead the organization to successful outcomes. **Analyze methodologies to plan change initiatives with appropriate measurements.** Unit title: planning, implementation, and **managing transitions**.

Stay here for "this plan, these measures, this transition." Not BUS607 D3M-as-a-course and not BUS608 ethics+strategy-as-a-course.

### Check F — Resistance and the understood-before-followed test (overlay)

Live intro: impact of change on employees; **mitigate resistance**; understood by all before they follow. Run Checks B–E through this test. If the plan cannot be understood, it is not ready.
