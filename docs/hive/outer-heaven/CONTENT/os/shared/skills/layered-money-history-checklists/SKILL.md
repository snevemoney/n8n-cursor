# Layered-money / monetary-history checklists (clustered)

**Use when:** a task asks which *layer* a monetary instrument sits on, whose balance sheet issued it, how the money hierarchy evolved from 16th-century Europe to the dollar/Eurodollar system, how the Fed and private banks create different layers, how Bitcoin compares to gold/currency/deposits, or how stablecoins and CBDCs function inside a monetary system — especially in an ECON120 / *Layered Money* / Mehrling-hierarchy frame.

**Do not use when:** the job is taking or reconstructing a Saylor exam; defining value, the action axiom, or diamond-water (`austrian-intro-checklists` / ECON103); running socialist calculation, originary interest, fiduciary-media *theory*, or ABCT mechanics (`austrian-capital-cycle-checklists` / ECON104); answering FRB-on-Bitcoin, mining-as-kWh security, fiat-food, kill-shots, or Lightning-as-scaling (`hard-money-qa-checklists` / ECON105); framing "what is money" as an energy network or splitting crypto-asset vs crypto-currency (`what-is-money-framing` / ECON135); operational wallets/KYC (PRDV151); or a pure ECON102 M1/M2 homework with no hierarchy overlay requested.

This is **one** skill. It is not "Unit 1 skill + Unit 2 skill…". ECON120's seven units are one argument: map the layers → walk the historical pyramid → place Bitcoin, stablecoins, and CBDCs on that map.

If the user still needs subjective value / praxeology, **hand off to `austrian-intro-checklists`**. If they need interest-as-TP, money-vs-credit typology as *theory*, or boom–bust mechanics, **hand off to `austrian-capital-cycle-checklists`**. If they asked "what *is* money?", **hand off to `what-is-money-framing`**. If they asked whether FRB can live on Bitcoin or why mining burns energy, **hand off to `hard-money-qa-checklists`**. ## 1. Procedure — run three checklists

Run in order unless the user already constrained the frame. Skip a checklist only when the question is already inside it. **Traveling between layers** (runs, par, LOLR) is a satellite after A, not a separate skill.

### Checklist A — Place the instrument (Units 1–2; LOs 1–2)

**Question this checklist answers:** what *is* this thing as money, and **which layer** is it on?

Humans use monetary *systems* (LO 1) because coins-as-sole-settlement do not scale across distance and counterparties. Layers exist so people can hold **claims** that are cheaper to use than the settlement asset — at the cost of **counterparty risk**.

| # | Test | What to write |
|---|---|---|
| A1 | **Whose liability?** | If **no one** owes it, it is a candidate **L1** (gold coin; BTC on-chain). If a **central bank** owes it, it is **L2** (currency, reserve deposits, most CBDC designs). If a **commercial bank / exchange / stablecoin issuer** owes it, it is **L3** (or a parallel private L2). Securities that pay later sit **below** deposits. |
| A2 | **Final settlement for whom?** | What looks like money at one level is credit from the level above (Mehrling). A household settles with **deposits**; a bank settles with **reserves/currency**; an international system once settled with **gold**. Always name the *who*. |
| A3 | **Counterparty + duration** | Every IOU has issuer-default risk and a convertibility promise (on demand vs later). L1 has **no issuer**; it still has theft, physical, or key risk — say so, don't pretend L1 is risk-free. |
| A4 | **Par / price to the layer above** | Deposits trade at par to currency until they don't. Bills/notes trade at a **discount** (interest = the price between layers). FX is the price of one L2 in terms of another. |
| A5 | **Do not flatten into M1** | Adding currency + deposits hides that they are **different balance sheets**. If the user brought an M1/M2 problem, give the textbook stock, then show the pyramid. |

**Simple pyramid to recite (Unit 2 / Mehrling teaching sketch):**

1. **Gold** (or another no-liability settlement asset) — L1
2. **Currency / CB reserves** — L2, promise to the layer above (historically gold; today often *nothing* after 1971)
3. **Bank deposits** — L3, promise to pay L2 on demand
4. **Securities / longer credit** — further down; money *later*

Saylor Unit 2's three-layer classroom version is **gold, currency, deposits**. Use four layers when securities or eurodollars matter; say you added a rung.

**Worked micro-pattern — "Is a checking account money?"**
A1–A2: it is money **to the depositor** (L3) and a **liability of a bank**. It is not L1. In a run you find out L3 ≠ L2.

**Worked micro-pattern — "The Fed prints all the money."**
A1 + LO 3: the Fed issues **L2**. Non-central-bank institutions issue **L3** (and offshore dollar claims). Both are "money creation"; they are not the same layer.

### Satellite — Traveling between layers (Unit 2.3; feeds Units 3–4)

Run when the question is a bank run, "cash," clearance/settlement, or why central banks exist.

1. **Up the pyramid** = toward better settlement / less counterparty (deposits → currency → gold/BTC). This is a **dash for cash**.
2. **Down the pyramid** = toward elasticity / yield / convenience (currency → deposits → securities). This is the boom, when credit *looks like* money.
3. **Clearance vs settlement:** netting promises is not final settlement. Central banking is the historical fix for a money market that needed a **par conversion** backstop (LOLR makes L3 look like L2).
4. **Disciplinary constraint:** convertibility into a scarce L1 (gold historically) limits how far L2/L3 can expand. When L1 is retired, discipline is political/regulatory, not a vault.

Do **not** restart ECON104's fiduciary-media debate. Here a run is a **layer break**, not a proof that FRB is illegitimate.

### Checklist B — Walk the historical pyramid (Units 3–5; LOs 2–3)

**Question this checklist answers:** how did the hierarchy evolve from **16th-century Europe until today**?

Walk the spine. Skip rungs only if the user already named a date.

| # | Rung | What to write |
|---|---|---|
| B1 | **16th–19th c. money market (U3)** | Bills of exchange and a **bourse** make **L2 paper** liquid. Discounting prices time between layers. Metal remains the settlement asset further up. Double-entry / Medici / bills (Unit 2) are the accounting technology that lets IOUs travel. |
| B2 | **Central banking** | A privileged bank's liabilities become the system's L2. LOLR / Bagehot function: lend against good collateral in a scramble up the pyramid. Confirm LMS names (Bank of England vs others) when logged in; the *function* is what LO 2 needs. |
| B3 | **Fed 1913–1944 (U4)** | After 1907, the US installs a central bank. It **formalizes a three-layer dollar**: Fed L2, member-bank L3. **Non-CB money creation** = private deposits. Unit window ends at **Bretton Woods 1944** (dollar as official reserve layer, still gold-linked at the official top). |
| B4 | **Eurodollar 1944–present (U5)** | Dollar **claims booked offshore** — same unit, different perimeter. Another layer of bank IOUs, not a new currency. Regulation and reserve requirements at home are why the layer grew; place the claim (whose books, which LOLR in a crisis — often Fed swap lines). |
| B5 | **Retiring gold / 1971** | Official gold convertibility ends. In this school that is a **layer swap**: gold leaves public L1; CB dollars sit at the top of the *used* pyramid. Do **not** pivot into ECON105's IMF/BoP/developing-world lecture — one-line handoff after the map is drawn. |

**Worked micro-pattern — "Summarize the money hierarchy since the 16th century."**
B1→B5 in one paragraph: liquid L2 paper in early-modern money markets → central-bank L2 → Fed-formalized dollar pyramid → Bretton Woods dollar-as-reserve → eurodollar offshore L3 → 1971 gold off the public L1 → stacked dollar claims with no metal rung.

**Worked micro-pattern — "Who creates money if not the Fed?"**
B3–B4 + A1: commercial banks (deposits) and offshore dollar banks (eurodollars). LO 3 is this fact, not a money-multiplier worksheet. If they want the multiplier algebra, that is ECON102 — give it *then* overlay layers.

### Checklist C — Digital overlay (Units 6–7; LOs 4–6)

**Question this checklist answers:** how does **Bitcoin** compare to the layered system, and how will **stablecoins and CBDCs** function inside it? What does that portend for holders?

| # | Test | What to write |
|---|---|---|
| C1 | **Bitcoin vs the pyramid (LO 4)** | Course claim: BTC is a **candidate L1** — bearer, no issuer, on-chain final settlement between holders. Compare to gold's *slot*, not to Visa's *speed*. Do not restart ECON135's energy-network or seven-layer security grid. |
| C2 | **Layered Bitcoin** | BTC grows **its own IOU pyramid** the moment someone issues an exchange balance, wrapped token, or custodial note. Those are L2/L3 **on BTC**, with counterparty. Lightning/channels are L2 *mechanisms* (faster, less final). Scaling thesis → `hard-money-qa-checklists`; here only **placement**. |
| C3 | **CBDC (LO 5)** | Usually a **CB liability** (digital L2). Can be wholesale (banks only) or retail (public). Retail CBDC can **compete with L3 deposits** (disintermediation). That is an architecture choice. Not "crypto." |
| C4 | **Stablecoin (LO 5)** | Usually a **private par claim** on a CB unit (L3 or parallel L2). Function: 24-7 programmable dollar-like IOU. Failure mode = reserve / issuer / peg, i.e. **counterparty**, not protocol issuance of an L1. |
| C5 | **Other cryptocurrencies** | Do not auto-file them as L1. Ask A1–A3. App-platforms and meme tokens are not "the new gold slot" in this course. Taxonomy detail → `what-is-money-framing`. |
| C6 | **What it portends (LO 6)** | More **choice of denomination and layer**; more need to know **whose IOU you hold**; possible decline of anonymous cash L2; possible mix of BTC (neutrality), CBDC (tax/benefits), stablecoin (convenience/yield). **Course claim, not a forecast to trade.** |

**Worked micro-pattern — "Is a USDC balance the same as Bitcoin?"**
C1 vs C4: USDC is an issuer's promise of dollars (place it next to deposits). BTC L1 is not a promise. A BTC *balance on an exchange* is back to C2 (IOU).

**Worked micro-pattern — "A CBDC is just digital cash."**
C3: cash today is a **CB bearer L2**. An *account-based* retail CBDC may be closer to a **deposit at the Fed** (still L2, but identified, possibly interest-bearing, possibly squeezes banks). Token vs account, wholesale vs retail — name the design before slogan.

**Worked micro-pattern — "Bitcoin broke the layered system."**
C1–C2: it *adds a candidate L1*. It does not delete L2/L3. Historically, new L1s still grow banks. Gold's failure mode (public holds notes, metal centralizes) is the warning ECON105 U10 also uses — **handoff** for the scaling/custody sermon; here just place it.
