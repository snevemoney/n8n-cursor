# Austrian intro checklists (clustered)

**Use when:** a task asks what value is, why people trade, why diamonds cost more than water, how economists should reason about human behavior, why time/saving/capital matter, how prices coordinate, whether a plan can calculate, or how coercion differs from exchange — especially in an ECON103 / Austrian / Mises / Menger / Rothbard / Ammous frame.

**Do not use when:** the job is taking or reconstructing a Saylor exam; running ABCT / interest-rate / fiduciary-media mechanics (that is ECON104); operational Bitcoin (ECON135 / PRDV151); or a pure ECON101 graph-shifting homework with no school overlay requested.

This is **one** skill. It is not "Unit 1 skill + Unit 2 skill…". ECON103's ten units are one argument: subjective value → economizing acts (labor, time, capital, trade, money) → market prices and entrepreneurial calculation → intervention vs progress.

## 0. Hygiene

- **Label school.** This is the **Austrian School** as taught in Saylor ECON103 (Menger 1871, Mises praxeology, Rothbard treatise, Ammous pedagogy). Hayek is adjacent; Kirzner is named as not covered. It is **not** Keynesian, **not** Walrasian/Jevons mathematical neoclassical, **not** Marxist labor-value, **not** Chartalist/MMT on money's origin.
- Mises called the science **value-free**: it traces consequences of action. Rothbard/Hoppe often add a political-property overlay. Keep **positive claim** vs **normative overlay** separate.
- **Ordinal, not cardinal.** No utils, no constants in human action, no "the price level did X therefore people must…" without persons.
- **Claim vs data.** "No natural resources have been depleted" (course LO) is the Simon/Austrian *economic* claim (knowledge and capital change what counts as a resource). Do not recite it as a geology paper. GDP critiques are methodological, not a live macro series.
- No investment advice. No exam items. Do not dump copyrighted treatise text.

## 1. Procedure — run three checklists (plus the value on-ramp)

Run in order unless the user already constrained the frame. Skip a checklist only when the question is already inside it.

### On-ramp — Subjective value at the margin (Units 1, 5)

Before the three named checklists, pin **what is being valued**.

1. Who is the **acting person**? (No group mind. "The market" does not value.)
2. What **end** is ranked higher than the alternative?
3. What **means** are scarce relative to that end? If not scarce → free good, not an economic good.
4. **Opportunity cost** = next-best forgone use of those means (including time).
5. Value of a unit = value of the **least important** use that unit still satisfies (**diminishing marginal utility**). This is why **essential goods can be cheaper than luxuries** (diamond-water): water's marginal unit covers a trivial use when it is abundant; a diamond's marginal unit covers a high-ranked use.

Trade is possible when two people **reverse ranks** over the same pair of goods. Equal objective value is not required. That is LO 1.

If the user only asked "what is value?" or "why are diamonds expensive?", you can stop after this on-ramp. Otherwise continue.

### Checklist A — Human action (praxeology) (Unit 2; LO 4)

**Question this checklist answers:** is this an *economic* phenomenon, and what method is allowed?

Walk the action test. A phenomenon is **action** only if all of these hold:

| # | Test | Fail → |
|---|---|---|
| A1 | A person (or persons, severally) **chooses** | Mechanical / biological process; tides; reflexes |
| A2 | They imagine a **more satisfactory** state than now | No uneasiness, no end |
| A3 | They believe some **means** can cause that state | Wish without causal belief |
| A4 | The act takes **time** and is under **uncertainty** | Instantaneous optimization fiction |
| A5 | Means are **scarce** (incl. the actor's time) | Free-good story, not economics |

**Method rules (Austrian, this course):**

- Start from the action axiom and **deduce** consequences. Do not import physics-style constants or regression-as-theory.
- **Methodological individualism:** explain GDP, inflation, "the firm," "the state" as names for patterned individual actions (including coercive ones). Aggregates do not act.
- Ends are **data**. Economics does not grade the end as moral or rational in the everyday sense; it asks what follows if people pursue it with scarce means.
- Counterfeit methods to flag: (1) treating statistical correlation between aggregates as causal law; (2) assuming cardinal utility; (3) assuming equilibrium already obtained so that entrepreneurship disappears.

**Worked micro-pattern — "Is X economic behavior?"**
Run A1–A5. If it is action, name the end, the means, the opportunity cost, and whose value scale. If the user wanted a policy verdict, say that is **outside** value-free praxeology unless they asked for Rothbard's overlay.

### Checklist B — Time preference (Units 3–4, 10; LOs 5–7)

**Question this checklist answers:** why wait, save, build capital — or why not?

Time preference (TP) = the acting person's discount of **later** satisfaction relative to **sooner** satisfaction of the same kind, other things equal. It is a **category of action**, not a "rate the Fed sets." (The market interest rate as a TP phenomenon, credit, and ABCT = **ECON104**. Here you only need the intro.)

Run:

| # | Test | What to write |
|---|---|---|
| B1 | **Absolute vs relative scarcity** | Human **time** is absolutely scarce. Particular natural materials are relatively scarce and can become *less* economically scarce as knowledge/capital rise (Simon-style LO 5). Do not conflate a mine running low with "resources in general ran out." |
| B2 | **Present vs future** | Same good now vs later: the actor prefers now unless a premium (more later) compensates. High TP → consume; low TP → save. |
| B3 | **Saving → capital** | Capital goods = produced (higher-order) means. They exist only if someone **did not consume** and was willing to wait through roundabout production. |
| B4 | **Cost of capital** | Waiting, depreciation/maintenance, error, obsolescence, expropriation risk. Accumulation is not free. |
| B5 | **Value of human time** | As capital and technology multiply what an hour can buy, the real value of labor-time rises. "Progress" in this school is more want-satisfaction **per unit of time**, not a bigger GDP print. |

**Worked micro-pattern — "Should we just print capital / stimulus?"**
B3: printing claims is not saving real means. Without withheld consumption, extra "investment" is a **re-ranking of existing means**, often toward longer projects people did not choose to wait for. Full malinvestment story = ECON104; here it is enough to refuse the identity "more spending = more capital."

**Worked micro-pattern — "We're running out of X."**
B1: X-the-mineral vs X-the-service-to-humans. If knowledge and capital can substitute or find more, the economic good can cheapen even as tons in one deposit fall. Label as Austrian/Simon claim; invite geology if the user wants physical stocks.

### Checklist C — Economic calculation (Units 6–9; LOs 8–9)

**Question this checklist answers:** can this social order **know** whether a production plan wastes resources, and what happens if exchange is replaced by violence?

Calculation, in the Misesian sense used by this course, is **appraising alternative uses of scarce capital goods in money prices**.

Run:

| # | Test | Fail → |
|---|---|---|
| C1 | **Private property** in the relevant means of production? | No owner, no bid; factor prices are fake or absent |
| C2 | **Money** as a common medium (indirect exchange)? | Barter: no common unit; coincidence-of-wants problem |
| C3 | **Free-market prices** formed from many ordinal scales? | Price controls, administered prices, "shadow prices" from a bureau |
| C4 | **Entrepreneur** who can profit **or lose**? | Residual goes to a planner who cannot go bankrupt in the same way |
| C5 | Interaction **voluntary** (exchange) vs **coercive** (intervention)? | Different consequences: shortages, queues, diversion, calculation noise |

**Money (C2) — intro only:**
Money **emerges** as the most marketable commodity (Menger), because it solves coincidence of wants, indivisibility, and the need for a calculation unit. It is an **economic good**, not a "shared hallucination." State-token / tax-receivable stories (Chartalism) are a rival school — **say so**. Bitcoin, stock-to-flow, and Mises's money-vs-credit typology are **ECON104/135**.

**Profit and loss (C4):**
Profit = the entrepreneur's direction of means beat the next-best uses **as consumers later revealed in prices**. Loss = the opposite. Both are **information**, not moral labels. Capitalism in this course = the order in which property + money prices + P&L make calculation possible.

**Intervention (C5) — Rothbard typology (as commonly taught; confirm LMS wording later):**

- **Autistic** — imposed on the subject's own person/property without a market counterpart.
- **Binary** — hegemon vs subject (tax, conscription, confiscation).
- **Triangular** — hegemon dictates terms *between* two subjects (price ceiling/floor, prohibition, licensing).

Coercive economizing is still "action" (Checklist A) but it **breaks or distorts C1–C4**. Do not call it "the same allocation with a transfer."

**Worked micro-pattern — "Could a planner just use computers / labor hours?"**
C1–C4: without private bids for *particular* capital goods, there is no discovery of opportunity cost in a common unit. Cardinally adding labor hours repeats the classical error the marginalists (Menger) rejected. This is Mises's calculation argument as **ECON103 must be able to state it**; ECON104 Unit 1 expands it.

**Worked micro-pattern — "Is this trade worth it?"**
On-ramp (reversed ranks?) → C2 if money is used → C5 if a third party is forcing the terms. Comparative advantage (even the "worse" producer) explains why trade is widespread (LO 8). *I, Pencil* is the picture of dispersed knowledge: no one person knows the whole chain.

## 3. School-contrast cheat sheet (use when the user mixes courses)

| Topic | ECON101-ish default | ECON103 Austrian |
|---|---|---|
| Value | Often MU as a number | Ordinal rank by an actor |
| Method | Models, curves, stats | Deduction from action |
| Money | Token / M1-M2 | Most marketable good |
| Capital | K in a production function | Higher-order goods that cost waiting |
| Profit | Residual / markup | Calculation signal under uncertainty |
| Policy gap | Market failure → intervene | Intervention is another action with its own costs |
| Growth | ΔGDP | More satisfaction per unit of **time** |

If the user is **not** inside ECON103, give the left column first, then the right, labeled.
