# Interview: prepare, formats, follow up, compensation literacy — never send (clustered)

**Use when:** a prompt needs **job-interview literacy** — prepare, know the format, run the conversation and follow-up, and treat compensation as a *named stage* — in the Saylor PRDV103 **Interviewing Skills** school (4 h). **Never send. Never apply. Never quote operator pay as FACT.**

**Do not use when:** reconstructing exams; **PRDV102** résumé/cover letter; **PRDV104** etiquette as a course; Demkinn **#43** JD-vs-résumé *gaps + mock loop* (same desk, different recipe); **#44** scout; **BUS403** undergrad negotiations; **BUS641** graduate strategic negotiations; promising ACE; **sending** a thank-you or application; naming a live salary number as operator FACT; treating hive factory work as a job-search signal unless the operator said so.

This is **one** skill. Three live units, four CLOs. Loop: **before → during (types + process/follow-up) → compensation literacy.** Unit 2 holds two CLOs. Do not mint a fifth CLO for "confidence/finesse" from the intro.

## 1. Procedure — six checks

Run in order. Stop if Check A says send/apply or a different school.

### Check A — Identity overlay (always)

| Prompt smells like | Hand off |
|---|---|
| "Fix the résumé / cover letter" | **PRDV102** |
| "Which fork / thank-you card / dress code as etiquette course" | **PRDV104** |
| "JD vs résumé gaps + score this mock" | Demkinn **#43** (same desk; that loop) |
| "Scout / rank openings" | Demkinn 44 — standing only if operator wants |
| "BATNA / ZOPA / workplace conflict as a *course*" | **BUS403** / **BUS641** |
| "What should *I* actually ask for (my number)" | **Personal CFO** FACT + **Researcher** comps; HITL |
| "How does a job interview work — prepare, sit, follow up, talk pay as literacy" | **this skill** |
| "Send the thank-you / apply / accept" | **HITL — refuse send** |

**Primary goal:** a two-way interview: they learn you; you learn them. Named failure mode: sending, quoting a fake salary, or treating the interview as only "impress them."

### Check B — Before (when "how do I prep" is in play)

CLO 1. Unit 1.

**Describe key factors to consider when preparing for a job interview.** SNLS parallel: prep includes learning about the company and questions about future responsibilities; later, choosing among offers.

Shape: role + employer research, logistics, stories from *receipted* work (UNVERIFIED if no number), questions you will ask them. Do not invent accomplishments. Materials exist in PRDV102 — do not rebuild the résumé here.

### Check C — Types / formats (when "phone vs panel vs case" is in play)

CLO 2. Unit 2 (first half).

**Describe different types of job interviews and their characteristics, purposes, and methodologies.** Live intro: different interview formats.

Shape: name the format first (screen, panel, behavioral, technical, case, etc. as *types*, not as an exam list). Purpose and method follow the type. Do not dump a secret question bank.

### Check D — Process and follow-up (when "what do I do in the room / after" is in play)

CLO 3. Unit 2 (second half).

**Explain the process of conducting a job interview and follow-up steps.** SNLS parallel: optimize time with interviewers; do not focus exclusively on impressing; decide whether *you* want them.

Shape: open, answer, ask, close, then follow-up as a *step in the school* — a drafted thank-you is still **not send**. HITL if they want it out.

### Check E — Compensation literacy (when "salary / benefits / what's your number" is in play)

CLO 4. Unit 3.

**Describe key factors to consider when negotiating salary and other forms of compensation.** SNLS parallel: the question can appear in a phone screen or later; research comparable pay; be prepared even if the plan is to avoid an exact figure.

Shape: name the *factors* (comps, other compensation, timing, whether to give a number). **Do not invent operator pay.** Pull comps via Researcher packet. Pull FACT via Personal CFO. Live ask/accept is HITL. This is not BUS403 BATNA and not BUS641 workforce-conflict negotiations.

### Check F — Mock vs send vs scout

A same-day scored rehearsal is Demkinn **#43** / mock-score-loop — use that recipe, not this course dump. Scout is 44 only if operator asked. **Refuse send.** Do not auto-promote to calendar or apply.

## 2. Worked patterns (shape only)

**"I have a panel Thursday. What do I do tonight?"**
Check A then B (prep factors) then C (panel as a type) then D (process). Do not send a pre-emptive email.

**"They asked my salary on the phone screen."**
Check E. Factors + "be prepared even if you avoid an exact figure." If they want *their* number: Personal CFO + Researcher. HITL before they say a figure live.

**"Write the thank-you and send it."**
Check D for follow-up as a step, then F: **refuse send**. Draft ≠ delivery.

**"Score this mock against the JD."**
That is Demkinn 43, not this CLO list. Point there. Still do not send.

**"Negotiate this offer with BATNA/ZOPA."**
Check A: BUS403/641 if they want that school. Here: compensation *factors* only, plus CFO/Researcher for numbers.
