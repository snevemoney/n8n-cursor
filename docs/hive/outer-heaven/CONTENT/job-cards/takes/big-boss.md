## 15. `f4mI3d-nTrI` — packet 15

**Transcript said:** The speaker explains MCP’s new spec: the protocol is stateless. Old flow minted a session ID on initialize, which pinned you to one server instance — scale-out and restarts became “session not found” unless you added sticky sessions or Redis. The dated spec drops the handshake and the session header; each request is independent, so any replica can serve, workers can scale to zero, and gateways can route on new HTTP headers without parsing JSON. Server follow-ups are no longer a surprise push down an open stream; the server returns `input required` plus a request-state payload, the client asks the human, then reissues. **Big Boss take:** This is Forge/Watchdog architecture, not a business. Stateless tools, explicit handles, confirm-as-a-round-trip — that is how I want every desk tool to fail.
