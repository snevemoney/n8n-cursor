## D. Procedures
1. Ask: does this tool help me sell, ship, or close books — or is it a feed demo?
2. If a founder is in setup instead of selling, name the displacement.
3. Ignore graph animate as evidence.
4. Put ops in a folder: invoices, payouts, Drive, bookkeeping, scheduled posts.
5. Use AI to write the automation once; let code run without an agent loop.
6. Watch token burn mid-month; tighten prompts and use-cases.
7. Voice brief only if it replaces a person (VA, clinic), not for a status read.

Questions: Does this move the needle? Does it require tokens every run? Would a short text update do? Signals: MRR screenshots that bounce; animate-button demos. Qualify: repetitive ops → no-token automation.
