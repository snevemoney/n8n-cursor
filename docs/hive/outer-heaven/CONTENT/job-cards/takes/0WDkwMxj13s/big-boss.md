1. **Week-plan test** a fresh session. If the answer is generic, stop adding skills; add context and one connection.
2. **Default shift:** try the task in the working tab before Chrome.
3. **Audit connections** from where you already look (revenue, customers, calendar, comms, tasks, projects, meetings, knowledge). One source at a time.

6. **Cadence last.** Nothing that can send / pay / publish runs with the lid closed.
7. **Organize only to find.** Daily `claude.md` edits are fine. Other Worlds + path notes. Fail = unfindable.
8. **Review use** on a cadence (`/insights` analog). Change the OS from the report, not from a bench.
9. **North Star gate** before a dashboard, a new skill, or a new connection: does this move the month-end number?
10. **Send off the ring.** If a to-do can be read as “send,” the send tool is not in the harness.
