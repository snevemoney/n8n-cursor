## C. Mental Models

Intent shows up in prompts, in what you ask the model to build, and in the story you sell a manager. Human attention is the non-inflatable currency in an agent-majority web. ## D. Procedures
1. Do not install Claude Code, Codex, ClickUp, or Skool. Do not send the coupon. Cursor + Grok.

5. Tool FOMO: does this take **weight off my actual load**? If no, skip. If no goal, do not pick opportunities.

8. Cost: auto-router before “no more AI this month.”
9. Dinner table: listen; answer with specific useful stories, not dunks.

## F. Decision Rules
- IF selling is hard → the story is unclear, not “they aren’t bought into AI.”
- IF the demographic is offline (HVAC) → you are not competing with agents for attention; go where they are.
- IF a tool drop does not take weight off *your* load → skip it (his Codex/Mac exception is personal).
- IF no goal → do not choose among opportunities.
- IF domain is foreign → AI-native public + domain-expert AI, then tool vs new IP.
- IF enablement = credits only → electricity-without-factory; refuse.
- IF token spend spikes → router before cutoff.
- IF no passionate team leaders / no weekly 1:1s → org-wide “AI native” will not stick.
- IF CEO does not use the tools → do not expect the org to.
- IF headline is “AI took the jobs” → check ZIRP overhang + uncreative boards; jobs ≠ tasks.
- IF content looks like everyone else’s → taste is the zag, not more generation.
