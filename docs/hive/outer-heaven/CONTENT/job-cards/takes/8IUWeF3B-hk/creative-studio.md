## C. Mental Models
Selling without eval is guessing. Subjective re-run is the enemy. Sheets hold expected truth. Averages are secondary to row-level right/wrong.

## D. Procedures
1. State hypothesis (if I change X, Y improves).
2. Keep a labeled set (here: six, category + priority).
3. Run the set.
4. Write outputs back.
5. Read right/wrong per row + averages.
6. Stop on the table, not on a feeling.

Avoid: one-off execute as “eval.”
