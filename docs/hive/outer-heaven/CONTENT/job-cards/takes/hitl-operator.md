## Roll-up

- **Skills:**
  - `ask-principal` — act, then ask Evens, then resume; never close the book or the charge.
  - `agent-as-hire` — onboard → one SOP → review → connect tools (send still gated) → score a real number.
  - `solo-then-consult` — one Path A install before any delivery bench; HITL send on the first outreach.
  - `info-gain-cite` — one honest page from a run we did; HITL publish; check the cite.
  - `list-anneal-funnel` — 50 → score a mid-high fit band → rewrite exclusions; contacts last; send never automatic.
  - `session-bootstrap` — one long dump, then short loops (Karpathy 2.0 / Nate yap).
  - (proposed) `tier-3-card` — every money / send / deploy / secret / delete item is ACTION / WHY / AGENT / RISK / REVERSIBILITY before Evens sees it.
  - (proposed) `input-required-gate` — destructive tools return a confirm payload any instance can resume; no push-prompt, no silence-means-yes.
  - (proposed) `sandbox-then-live` — Stripe/test domain/waitlist first; live keys, live domain, live charge are a separate Tier 3 card.
  - (proposed) `send-removed` — if the workflow has Send, strip it; do not rely on “never send” in the prompt (Manila panel, Jarvis book, Clay sheet).
  - (proposed) `callback-before-book` — gather, report, wait; second action only after Evens. Steal from Jarvis; do not steal the dialer.
  - (proposed) `one-job-one-test` — slice a Tier 3 so a fail rolls back one job, not the estate (Godot / Nate isolated worktrees).

- **Other business (parked — not a hunt):** Device-farm OFM / Instacaster OTP; Polymind-class prediction-market helper; Jarvis + Retail/Twilio auto-dial; Glenn Coco outbound marketplace and AI-SDR voice; Julian indexer + rank-everywhere farm; Nate School / Plus as a lane; Client Pack as our SKU; LeadGrow install as a vendor; betting; mass-DM seduction. - **Leverage:** Parallel isolated workers with one human gate; waitlist and sandbox as proof before live keys; director review before ship; factory primitives so the next product does not rebuild auth/pay; needs-review column on every outbound batch; protocol-level `input required` on delete/pay/send.

- **QoL / values:** Visible → efficient → automatic → then judgment. Width of drafts can grow; risk tier does not. Evens keeps attention, taste, and the last yes. I would rather hold a boring queue than explain a discount email that went to the list.

- **Never:** This desk will not operate a send, charge, deploy, book, or publish that can complete without Evens’ confirm — including restaurant close, live Stripe cutover, domain buy, Gmail/Telegram fire, warm outreach, and “the agent already asked in the prompt.” Looking at farms, OTP, auto-dial, and betting tapes is allowed. Running them is not.
