### Autonomy to pick, then a fixed path
- **Claim:** Even his agent example becomes a workflow once the tool is chosen — and that predictability helped performance.
- **Reasoning:** Full autonomy the whole way is how agents get sloppy.
- **Mechanism:** Agent chooses among tools → each tool is a fixed workflow → may loop to pick again.
- **Evidence:** Once it chose the right path we basically wanted it to stay super predictable and that helped with the agents performance a lot more.
- **Conditions:** You think you need an agent.
- **Exceptions:** A truly open environment (no fixed tools) is rare and expensive.
- **Action:** If we ever use an 'agent,' the tools should be fixed packs. Publish still HITL.
