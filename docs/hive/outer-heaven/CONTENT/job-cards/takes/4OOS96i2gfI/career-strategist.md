## C. Mental Models
Title yourself problem-solver. Autonomy is expensive. Determinism is a feature. Tools under an agent should often be fixed workflows (he saw better performance). Feedback after real runs beats the first flowchart. Existing SaaS can be the win. Coaching frame: keep their cost low and get a quick win so they stay.

## D. Procedures
Decision tree (preserve order):
1. Do I need to be in the loop every time? Yes → custom GPT / project / gem.
2. Are the steps 100% logic (filter, code, black-and-white)? Yes → no-AI workflow.
3. Is the order of operations fixed? Yes → AI workflow (narrow AI inside a path).
4. Else → AI agent (goal + choose tools/order).
5. After runs: scale up or down; “you don’t know what you don’t know.”
6. Extra check: if happy-path is fixed but tool-count varies (0–N KB searches), agent may still win.

Qualify questions: What is the root problem? What is the cheapest quick win? Would an existing SaaS do it? Signals: “we need an agent” with no trigger named.
