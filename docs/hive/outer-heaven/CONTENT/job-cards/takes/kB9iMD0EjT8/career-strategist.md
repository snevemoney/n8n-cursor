## C. Mental Models
Portability over loyalty. The OS is the shared folder; vendors are guests. AI can research its own docs to port itself. Maintenance is dual-write when the instruction file changes. Codex subagents are explicit, not automatic — do not assume the same agency. Terminal over extensions. Two seats are insurance, not a personality.

## D. Procedures
1. Keep shared knowledge (archives, audits, brand, decisions, references) outside tool folders.
2. Mirror instructions: `CLAUDE.md` ↔ `AGENTS.md`.
3. Put skills in the folder each tool expects (`.claude` vs `.agents`); files stay markdown.
4. Port agents md → TOML (or ask the tool).
5. Convert with one prompt: research both official docs; create the missing folders/files.
6. After a major instruction change, update the twin file.
7. When stuck: run session-handoff → paste into the other tool.
8. Do not let two agents edit the same file without a lock.
9. Prefer CLI: `claude` / `codex` in the project.

Questions: Is this shared knowledge or tool config? Did the twin file drift? Signals: stuck loop, outage. Qualify: same repo, second door.
