## 15. `f4mI3d-nTrI` — packet 15

**Transcript said:** MCP’s new spec drops the initialize handshake and the session-ID header so every request is independent HTTP. The old stateful flow pinned you to the instance that minted the session; a load balancer or a dead pod returned session-not-found unless you added sticky sessions or Redis. Stateless means round-robin, scale-to-zero on Workers / Cloud Run, and no Durable Object required to speak the protocol. New headers let a gateway act without parsing JSON; cache hints ride on list calls. State, if you want it, is an explicit handle you pass as an argument — the way APIs always did. Server follow-ups are no longer a surprise push down an open stream; the server returns input-required plus serialized request state, the client reissues, any instance can resume. Long work becomes tasks you poll. SDKs major-bump; twelve-month deprecation window.

**Product GTM take:** Time-to-aha dies if login pins the user to a dead host — that is the Client Pack domain bug in protocol form. Path C plumbing should be boring HTTP: any instance serves the click. Do not sell MCP, a handshake, or “agent protocol” as the offer. Evidence is the live URL after domain cutover, clicked end-to-end. If a tool needs “are you sure?”, that is a HITL gate, not a hidden stream into the user’s face.
