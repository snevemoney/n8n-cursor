## D. Procedures
1. Scope (ask if vague).
2. Five (or N) lenses in parallel.
3. Contradiction map: who conflicts, whose evidence is weak.
4. Synthesize into a fixed HTML template.
5. Adversarial cite-check: confirm / correct / demote.
6. Name the missing lens; optional V3.
7. Tailor takeaways to the business; test on a topic you know.
Avoid: 103-agent default; Skool as SSOT; “PhD” as FACT.
