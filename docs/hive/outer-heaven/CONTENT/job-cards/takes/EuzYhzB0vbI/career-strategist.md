## D. Procedures
1. Ask: does this task even need a loop?
2. Write done (metric if you can) and the check (visual, test, tone).
3. Give the tools for that check.
4. Prefer solo reason-act-observe; maker-checker if grade is hard; manager only if split work.
5. Hard cap passes / hours.
6. If 12h and not useful, do not repeat.
7. Overnight = experiment → morning human pass.
8. Do not marry a tweet.

Questions: What is done? How will it check? Is 24/7 even a benefit? Signals: “until satisfied”; no cap. Qualify: knowledge work vs product codebase.
