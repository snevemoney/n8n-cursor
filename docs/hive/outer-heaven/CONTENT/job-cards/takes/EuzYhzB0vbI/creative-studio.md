## D. Procedures
1. Name done (metric if you can) + how it will check (visual / test / tone).
2. Give the observe tools.
3. Hard stop (pass cap or metric).
4. Prefer solo verify; add checker or manager only if needed.
5. Overnight = experiment → morning human pass.
Avoid: 24/7 idle farm; “until satisfied” as the only stop; game-studio 3.js as a SKU; Skool library as hive default.
