## C. Mental Models
You are good at naming the end, bad at sitting the iterate. Loops are only as good as the fork test. Tweet ≠ your job.

## D. Procedures
1. Write done (metric=Y if you can) + hard cap.
2. Give the tools the check needs (browser, tests, transcript-align).
3. Prefer solo+verify; add checker/manager only if needed.
4. If scores are vibes → a separate eval’d scorer.
5. Log; watch cost; kill 12h zombies.
Avoid: 24/7 swarm as status; “until satisfied”; cargo-cult Steinberger.
