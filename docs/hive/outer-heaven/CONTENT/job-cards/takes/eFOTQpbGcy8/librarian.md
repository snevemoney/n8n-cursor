2. Automate; write hours-before/after.
3. Demo in the team’s language; name on an internal doc; offer one coworker task.
4. Re-audit the business: what breaks if customers double?
5. Sum to one FTE-equivalent; propose the title.
6. If regulated: dummy data, permission, no sensitive dumps.
Avoid: annoy-first; “I used ChatGPT” as the win sentence; quoting IBM/56% as FACT.
