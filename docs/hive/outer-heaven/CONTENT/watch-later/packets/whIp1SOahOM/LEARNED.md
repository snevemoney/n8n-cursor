## B. Atomic Knowledge
- **Claim**: Outbound voice agents must set `begin_message` to an empty string (`""` or `null`).
  - **Why**: Setting a greeting causes the AI agent to speak over the call recipient upon pickup; an empty string forces the agent to wait for the human recipient to say hello.
  - **Conditions**: Retell AI outbound voice agent deployment.
  - **Evidence**: Visible in starter pack document at frame 21:44 ("`begin_message` to an EMPTY STRING on outbound agents. Null means it talks over the pickup").
  - **Label**: SOURCE
- **Claim**: Financial documents generated by LLMs must have all arithmetic recomputed in Python code.
  - **Why**: LLMs are prone to arithmetic errors when multiplying unit prices and summing subtotals.
  - **Conditions**: Automated LLM quote and invoice generation workflows.
  - **Evidence**: Starter pack PDF at frame 21:54 ("recompute the total from `qty * unit_price` in Python and OVERRIDE the model's number - arithmetic is ours, not the model's").
  - **Label**: SOURCE
- **Claim**: Inbound voice agents must gate access using a hard-coded security PIN check executed before sending input to the LLM.
  - **Why**: LLM guardrails alone can be bypassed via prompt injection over voice calls, exposing private tools or data.
  - **Conditions**: Public or private inbound telephony hotlines connected to AI assistants.
  - **Evidence**: Frame 20:04 log toast and frame 21:56 security rules ("Gate inbound with a code and never reveal the code exists... Refuse SSN, card, password... BEFORE any AI reasons about them").
  - **Label**: SOURCE
- **Claim**: Headless Google Chrome CLI provides accurate HTML-to-PDF rendering for AI agent document generation.
  - **Why**: Standard PDF libraries lack modern CSS styling support, while headless Chrome renders exact web design templates cleanly.
  - **Conditions**: Generating polished PDF invoices/quotes from local HTML scripts.
  - **Evidence**: Starter pack PDF code prompt at frame 21:54.
  - **Label**: SOURCE

## C. Procedures as Ordered Steps
1. **Configuring Retell Outbound Booking/Inquiry Voice Agents**:
   - Create a Single Prompt Agent inside the Retell AI dashboard.
   - Structure prompt sections into `Identity`, `Guardrails`, `Task steps`, `Edge cases`, and `Hard rules`.
   - Explicitly clear `begin_message` (`""` or `null`) so the agent listens for recipient pickup.
   - Attach custom tools (`end_call`, `press_digit`, `gcal_add`).
   - Enforce hard rules: never provide credit card details, never agree to charges, and decline upsells.

2. **Voice Note to Formatted PDF Quote Pipeline**:
   - Receive voice message via Telegram Bot webhook.
   - Pass transcript to Anthropic API (`claude-3-5-sonnet` / `claude-opus-4-8`) requesting strict JSON schema containing document metadata and line items.
   - Run Python post-processing script to compute `qty * unit_price` totals programmatically, overriding LLM arithmetic.
   - Inject verified JSON into custom single-page HTML template featuring styled CSS typography.
   - Call Google Chrome binary in headless mode to render HTML directly to output PDF:
     `/Applications/Google Chrome.app/Contents/MacOS/Google Chrome --headless --print-to-pdf=out.pdf --no-pdf-header-footer file://{html_path}`.
   - Upload generated PDF to Google Drive, generate an editable Google Doc copy, log the lead in Google Sheets, and send document links back to Telegram user via `sendDocument` API.

## G. Decision Points (IF -> THEN)
- **IF** an outbound voice agent makes a call -> **THEN** set `begin_message` to empty string so the agent waits for the recipient's greeting before speaking.
- **IF** a call counterparty requests payment or credit card details -> **THEN** reply "My boss handles payment directly" and invoke `end_call` tool.
- **IF** generating client quotes or invoices -> **THEN** calculate all arithmetic in Python and override any LLM-generated totals.
- **IF** an inbound caller dials the private line -> **THEN** prompt for security PIN and terminate call if authentication fails before exposing LLM tool context.
