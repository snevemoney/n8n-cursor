## Q&A LOG

### A. Memory continuity — definition then three scenarios then judgment

**Definition:** “Continue memory” means a later sitting can use what Evens already said without him re-explaining.

1. **Wish:** ChatGPT and Claude keep the same thread-memory as Cursor and Grok, automatically.
2. **Fake wire:** Connectors / MCP / plugins so those UIs pull the repo. Violates hive-funnels-stack (on-tape only; do not install).
3. **Honest wire:** Cursor + Grok read `hot.md` → index → GRAPH → said-* + SESSION-INDEX + live CLIs. ChatGPT/Claude get PASTE-PACK if Evens pastes.

**Judgment:** 3. The wish is rejected. Continuity is a shared **index**, not four product memories.

### B. Shared Obsidian — definition then three scenarios then judgment

**Definition:** One folder of notes both execute desks treat as canonical.

1. **Four mounts:** Each vendor app opens the vault. ChatGPT/Claude do not; we will not install them to make them.
2. **Two vaults:** Cursor cache vs Grok cache as SSOT. Already forbidden (one write target).
3. **One vault:** Mac awake = live folder. Mac closed = SSH `n8ncloud` Path B. Syncthing keeps devices identical. Cursor and Grok both read it.

**Judgment:** 3. Yes, Cursor and Grok share Obsidian. ChatGPT/Claude do not unless Evens pastes.

### C. Paste-summaries vs repo-reachable sessions — definition then three scenarios then judgment

**Definition:** How a desk learns the last sitting.

1. **Always paste:** Evens copies summaries into every chat. That is the failure mode we are killing for Cursor/Grok.
2. **Repo dump:** Commit every JSONL/blob. Forbidden (secrets, size, not the vault).
3. **Heads in vault + one-id CLI:** session-matrix writes heads; desks `read --id` only when named.

**Judgment:** 3 for Cursor/Grok. 1 (paste pack) only for ChatGPT/Claude sittings Evens chooses to open.

### D. Same actions on every surface — definition then three scenarios then judgment

**Definition:** Workflows, tools, CLI, installed repo, skills, system matrix.

1. **Identical everywhere:** ChatGPT/Claude run Remotion, skills-sync, repo CLI. Forbidden and false.
2. **Cursor MCP everywhere:** Grok calls Cursor browser MCP. Forbidden (Grok uses Grok browser/computer).
3. **Same SSOT, host-local tools:** Skills in git; Grok mirrors generated; Grok desktop `desk-checkout.sh`; each host’s own browser/shell.

**Judgment:** 3. Same matrix **content**. Not the same **tool sockets**. ChatGPT/Claude: no execute path.

### E. What “wired” means — definition then three scenarios then judgment

**Definition:** A desk can act from shared truth without Evens re-seeding.

1. **Feeling wired:** “I pasted once, so they remember.” That is not a system.
2. **Execute wired on all four:** Same as D1. Reject.
3. **Read wired vs execute wired:** Read = vault + index (Cursor + Grok). Execute = Cursor Mac + Grok desktop. Paste pack = optional on-tape sitting.

**Judgment:** 3. After this PR: read path landed on main; execute path unchanged; ChatGPT/Claude execute still NOT wired.
