# Hunt log — append every Today session

**Default city:** Greater Montreal (unless Evens names another).  
**Rule:** Every **Today** block ends by appending at least one row here. Do not leave URLs only in chat.

## Row schema

| date | icp_id | city | url | leak | contact | MUST | next | owner |
|------|--------|------|-----|------|---------|------|------|-------|

**Fields:**
- **date** — YYYY-MM-DD
- **icp_id** — from catalog (do not invent)
- **city** — default `Greater Montreal`
- **url** — named prospect URL, or `—` for list-only work
- **leak** — one sentence (constraint hypothesis)
- **contact** — email / form / IG path (public only)
- **MUST** — PASS / HOLD / stub / —
- **next** — one action (e.g. margin, warm draft, session 2 anneal)
- **owner** — Lead Hunter · Consultant · Forge · etc.
