# ICP runbook: `creator-longform`

**Who:** Podcasters, YouTubers, course creators with long-form catalog  
**Pain:** Long episode dies after publish; no clip pipeline  
**Path:** A (named creator) or C (our Publishing Engine proof)  
**Machine:** `clip-factory`  
**SKU:** Clip factory pilot · R0–1 · $750–2K CAD  
**Owners:** Lead Hunter · Creative Studio · Publishing Engine · Consultant  
**Default city:** Greater Montreal (Path A) · Path C = our channel

## Route here / not here

**Route here:** Long-form YT/pod with no Shorts/Reels cadence, manual editor bottleneck.  
**Not here:** Short-form-only creators · “AI content agency” mass-DM · no source material.

## Leak signals

- Long YT/pod · no Shorts/Reels cadence · manual editor bottleneck

## Disqualify

- Wants “AI content agency” · mass-DM · no long-form source material · Opus/Descript as our stack

## Offer sentence

“I help [creator type] ship N retention-first shorts per week from their long episodes — you review and publish.”

## Landmines

- Cursor + Grok only — no Opus/Descript install
- Publish to **their** channels = HITL (Evens ships)
- Named URL = money spine before pilot build

## Proof in drafts

Path C proof on our channel. Public portfolio URLs only in client drafts — no localhost.

## Path A — skill chain (named creator — money spine first)

1. `lead-web-find` → MUST
2. `prospect-must-score` — MUST=0 → HOLD
3. `constraint-position` — time per ep vs clips shipped
4. `four-blank-sku` + `usecase-to-sku` — KPI: clips/week · baseline TBD
5. `pricing-margin-roi-guardrails` → PASS/HOLD
6. Pilot: transcript → hooks → cut list → captions/thumbs/copy
7. **Evens ships** (Publishing HITL)
8. Optional: `competitive-teardown` on two channels same niche
9. `warm-draft-hitl` if outreach · `proof-30-60-90`

## Path C — skill chain (our proof)

1. Pick our channel URL
2. Researcher: one ep transcript → 5 hook candidates
3. Creative: one sample cut brief
4. Publishing: ship one clip (HITL)

## Hard step (HITL)

Publish to their channels · any spend on ads · client send
