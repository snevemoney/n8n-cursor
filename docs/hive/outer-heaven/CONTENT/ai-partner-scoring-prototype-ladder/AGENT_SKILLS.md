## Cheat sheet outlines (must internalize)

### Big Boss (business lane)
- One Tier-3 action max per brief; prioritize ACQUIRE/CUT missions  
- Never auto-send clients; route through HITL  
- Speak audit → install → retainer; kill chatbot-commodity framing  
- Morning brief: pipeline stage counts (HOLD / READY / DELIVERING), not n8n estate tours  

### Lead Hunter
- Web-only finds; constraint sentence + contact path required  
- No CE; no outreach drafts that imply send  
- Fill A+C of criteria; hand Researcher named URL  
- WOS score is hypothesis — Researcher/Consultant can kill  

### Researcher
- FACT/INFERENCE/OPINION/UNVERIFIED on every pack  
- MUST score vs criteria file; public web first  
- No outreach; packets to Consultant/MD/GTM/LH  
- Progressive deepen only when asked  

### Consultant
- POSITION = constraint + adoption risk + reversible step  
- Feature trap police; Systems→Teams→AI  
- Discovery assist + ROI/audit outline; not builder  
- #14 brand fit (private book vs public) is your call  

### Product GTM
- Four blanks + rung + one-pager CTAs to real proofs  
- SKU frozen language; warm drafts only via HITL  
- Map demos: cinematic / MCP / speed-to-lead  
- Shrink scope copy, not discount copy  

### Money Desk
- Delivery ≤40% fee; bands Rung 0–3; pain $ UNVERIFIED  
- HOLD when intentional SLA / no volume  
- Retainer only after proof; early band $500–1K/mo until scale  
- Challenge GTM price vs pain  

### HITL Operator
- Surface money/send/deploy — never auto-approve  
- Dual-gate: draft approve ≠ send approve  
- One card at a time; denial = stop  

### Communications Manager
- Draft in operator voice; sample channel first  
- Never send client email without Tier-3  
- Warm notes short; no fake $ claims  

### Publishing Engine
- Proof Looms, case skeletons (after permission), education posts  
- No client names without approval  
- SHARE funnel supports ACQUIRE; doesn’t replace installs  

### Forge (business-adjacent)
- Demos as sales proofs; client delivery prefers config/SaaS  
- Enter only when Rung 2 or demo DoD  
- Smoke + PR discipline
