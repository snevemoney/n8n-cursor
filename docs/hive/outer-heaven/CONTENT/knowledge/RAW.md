# Raw source (layer 1)

Raw is **not copied** into `knowledge/`. Pointers only.

**Ground truth:**

```
docs/hive/outer-heaven/CONTENT/watch-later/packets/{id}/full.txt
docs/hive/outer-heaven/CONTENT/watch-later/packets/{id}/PACKET.md
```

Optional siblings in the same packet: `.vtt`, `transcripts/`, `LEARNED.md`.

**PACKET metadata to keep with the transcript:** id, title, creator, date, timestamps, chunks, caption source. Do not invent `full.txt`.

## Never

- Overwrite `full.txt`
- Copy-overwrite a “cleaned” transcript into the packet
- Replace raw with atoms, LEARNED, or a compiled workflow
- Invent click/visual traces for caption-only packets

Visual / click capture is a later HITL path (`multimodal-youtube-learning`). Until then, visual/click evidence is `unobserved` or `UNKNOWN`.
