## What “train” means here

**Not weights.** No fine-tune, no overnight `program.md` rewrite, no daemon that edits skills while Evens sleeps.

**Desks.** A desk is trained when it can **independently reproduce** one demonstrated signal task with the hive stack (Cursor + Grok), a named skill, the tools we already have, and a checkable-stop. Learned = reproduced + verified ([[SIGNAL-TO-CAPABILITY]]). Transcript-only is not learned. Caption-only visual/click = `UNKNOWN`.

Skills store **semantic goals + expected result**, never click x,y.

## Loop — one signal per sitting

Wake default five (Forge · Watchdog · HITL · Researcher · Comms). Add **Consultant** when the named TASK is consult-vs-build / doctor-vs-pharmacist / audit-first / receipt-vs-decorator. Not all-17. Not a daemon.

1. **Retrieve theme.** `python3 scripts/hive/os/signal-retrieve.py --prompt "<the task>"` → one domain or `NONE`. Do not dump [[SIGNAL_INDEX]] / [[STEAL_SHEET]] / dossiers.
2. **Open ≤3 local refs** from the map hit. Refuse `/workspace`. If `NONE` or a path is missing → TRIAGE / UNKNOWN. Stop.
3. **Name the TASK** the tape demonstrated (semantic goal + expected result). One sentence. If you cannot name it, you are still in TRIAGE.
4. **Hold-outs Watchdog-only**, written **before** Forge works. Builder must not read the exam (`dark-factory` card).
5. **Forge attempts** with **existing** tools and skills. Walk numbered D if it is a build tape (`ingest-is-steps`). One system. Hard steps stay Evens.
6. **Watchdog GRADE** vs those hold-outs (other session). Missing Piece Hunter required. Then status **LEARNED → TESTING → GRADE → PROVEN**. Mint **only** if the machine slug is new and distinct (`skill-from-session` shape; auto-mint law already exists). Merge/skip if the slug already exists. **Do not remint 325.** `skill-from-session` HITL only if Evens wants a mint sitting — it is not a second gate in front of the law.

Hit the stop. Cap unmet → halt and report. Next sitting is a **new** pick, not a raise.
