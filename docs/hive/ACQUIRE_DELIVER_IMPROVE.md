# Acquire / Deliver / Improve

Thread from YouTube learning + CE Tom-style ops chats.

## Loop

```
Sources (YouTube, Docs, ops chat, research)
  → Learning proposals (human review — never auto-apply to production)
    → Playbooks / SOPs / scripts

```

## Rules

- Tag knowledge with revenue / path link where possible (no junk drawer).
- Human gates promotion of prompts, SOPs, and production behavior.
- Failures must be visible (status, retries, interventions) — Tom-style.
