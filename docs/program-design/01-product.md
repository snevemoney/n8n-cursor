# Stage 1 — Product

No databases. No frameworks. User-visible only.

## Required

- **User problem** — who hurts and how
- **Measurable success** — a number or experiment the agent can optimize toward
- **Working-backwards post** — how you would announce this to users before code
- **HTML mock / sketches** — what screens look like (plain HTML OK)

## Anti-patterns

- Jumping to schema or folder structure
- "Make it better" with no measure
