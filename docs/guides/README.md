# Documentation Guides

This directory contains guides, contracts, and playbooks for development workflows.

## Structure

- **Cursor Guides** - AI coding assistant workflows and best practices
- **Contracts** - Mandatory consistency rules and standards
- **Deployment** - Deployment guides and checklists
- **Task Management** - Templates and workflows for task tracking

- `CODING_WITH_CURSOR.md` - How to use Cursor effectively

- `CURSOR_RELIABILITY_CONTRACT.md` - Reliability standards for AI assistance
- `CURSOR_SYSTEM_PROMPT.md` - System prompt guidelines

### Contracts
- `../contracts/GLOBAL_CONSISTENCY_CONTRACT.md` - Global consistency rules

### Deployment
- `DEPLOYMENT-GUIDE.md` - Deployment procedures
- `N8N_SMTP_CONFIGURATION.md` - n8n email configuration

### Task Management

- `TASK_TICKET.md` - Task ticket template
- `PROMOTION_GUIDE.md` - Promotion workflow guide

## Usage

These guides are referenced by:
- CI/CD pipelines
- Development workflows
- Code review processes
- AI coding assistants
