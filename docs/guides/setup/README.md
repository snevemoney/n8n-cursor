# Setup Guides

This directory contains setup and quick start guides for various components.

## Files

- `ACCESS_GUIDE.md` - Access and authentication setup
- `LOCAL_SETUP.md` - Local development environment setup
- `QUICK_START_LOCAL.md` - Quick start for local development
- `QUICK_START_BACKEND.md` - Quick start for backend services
- `SETUP_INSTRUCTIONS.md` - Detailed setup instructions
- `SETUP_STATUS.md` - Setup status tracking
- `SMTP_QUICK_START.md` - SMTP/email configuration

## Usage

Follow these guides in order for initial setup:
1. `LOCAL_SETUP.md` or `QUICK_START_LOCAL.md` - Get started quickly
2. `SETUP_INSTRUCTIONS.md` - Detailed configuration
3. `ACCESS_GUIDE.md` - Configure access and authentication
4. `SMTP_QUICK_START.md` - Set up email (if needed)
