# Data Analytics Knowledge Base

- Trend identification

- Data visualization (charts, graphs)

- Sales performance reports
- Website traffic analysis
- Customer behavior tracking

**Why did it happen?**
- Root cause analysis
- Correlation analysis
- Drill-down investigations
- Anomaly detection

**Tools & Techniques:**
- Regression analysis
- Hypothesis testing
- A/B testing
- Cohort analysis

**Use Cases:**
- Understanding sales dips
- Identifying conversion bottlenecks
- Analyzing customer churn reasons
- Performance issue diagnosis

**What will happen?**

**Use Cases:**

- Optimization algorithms

**Use Cases:**

## Data Visualization Best Practices

### Chart Selection Guide

**Line Charts:** Time series, trends, continuous data
**Bar Charts:** Comparisons, categorical data, rankings
**Pie Charts:** Proportions, percentages (use sparingly)
**Scatter Plots:** Correlations, relationships between variables
**Heat Maps:** Patterns in large datasets, density visualization
**Box Plots:** Distribution, outliers, statistical summaries

### Visualization Principles

1. **Clarity:** Keep it simple, remove clutter
2. **Accuracy:** Don't mislead with scale manipulation
3. **Accessibility:** Consider color blindness, use labels
4. **Context:** Provide titles, legends, annotations
5. **Consistency:** Use uniform styling across dashboards

## ML System Data Pipelines

### Pipeline Stages

1. **Data Ingestion**
   - Batch vs. streaming
   - Data sources (databases, APIs, files)
   - Data validation

2. **Data Processing**
   - Cleaning (handling nulls, outliers)
   - Transformation (normalization, encoding)
   - Feature engineering

3. **Model Training**
   - Training data preparation
   - Model selection
   - Hyperparameter tuning
   - Cross-validation

4. **Model Evaluation**
   - Metrics (accuracy, precision, recall, F1)
   - Validation sets
   - Error analysis

5. **Model Deployment**
   - Model serving (batch, real-time)
   - A/B testing
   - Monitoring and retraining

### Data Quality Checks

- **Completeness:** No missing required fields
- **Accuracy:** Data matches source of truth
- **Consistency:** Same data across systems
- **Timeliness:** Data is up-to-date
- **Validity:** Data conforms to rules/formats
