# Documentation

This directory contains documentation for the Agent Factory system.

## Documents

- `SETUP.md` - Instructions for setting up the Agent Factory system
- `PHASE1_COMPLETE.md` - Documentation for Phase 1 completion milestones
- `PHASE2_COMPLETE.md` - Documentation for Phase 2 completion milestones

## Project Phases

### Phase 1
Initial setup and basic functionality implementation, including:
- Setting up the n8n instance
- Creating basic agent templates
- Implementing the core workflow logic

### Phase 2
Advanced features and optimizations, including:
- Enhanced template customization
- Support for additional agent types
- Performance improvements and scaling capabilities

## Contributing to Documentation

Please follow these guidelines when contributing to the documentation:
- Use Markdown format for all documentation files
- Include clear, step-by-step instructions
- Add screenshots or diagrams where helpful
- Keep the documentation up-to-date with the latest code changes
