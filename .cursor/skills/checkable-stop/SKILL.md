# Checkable stop (Cursor)

Load `scripts/hive/grok-skills/checkable-stop.md` and follow it.

**Card:** `DONE-CHECK` · `CAP` · `COST` · `STOP-KIND` — write it before the loop runs.  
**Wired job:** `coverage-loop` — one tape or one model row this session.  
**Spawn:** `hive-spawn-desks` / `tape-self-teach` prompts carry the same card.

Weak stops: until-satisfied · looks-good · overnight default.  
Hard step: send / pay / deploy / book / publish stay Evens.
